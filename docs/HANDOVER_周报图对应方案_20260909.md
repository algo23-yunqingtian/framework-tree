## 二、给 Windows 本地 agent 的任务

### 任务：周报图 ↔ 网页图 对应匹配

**目标**：把周报里的图和我们网页上的图对应起来，统计匹配率。

### 2.1 匹配规则

周报图的命名规律：
```
品种_节点编号_主题
例：AL_2_3_价格, LI_3_2_1_产量, AO_4_4_库存
```

网页图的命名规律：
```
品种_节点编号_主题.html
例：al_2_3.html, li_3_2_1.html, ao_44_mill_inventory.html
```

**匹配逻辑**：
1. 提取周报图标题的品种 code（AL/AO/CU/LI/NI/PB/SI/SN/ZN）
2. 提取周报图的节点编号（2.3/3.2.1/4.4 等）
3. 在网页图中找同品种+同节点的图
4. 若找到 → 匹配；若找不到 → 不匹配
