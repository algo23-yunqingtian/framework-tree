# 同花顺问财 · 跨板块方法论深度提问模板 v1

> 日期：2026-09-03
> 用途：当需要为某个研究板块（库存/供给/需求/成本/进出口/价格信号）提炼"指标筛选规则"时，用这套模板驱动同花顺问财深度回答，产出可直接落盘的筛选规则。
> 使用方式：替换 {板块名}/{品种列表}/{指标类型清单} 三个占位符即可。
> 已验证：库存板块两轮（2026-09-03），第三轮将用此模板跑供给板块。

---

## 模板结构（五段式）

同花顺对"方法论提问"质量最高，回答包含：分层框架 + 优先级排序 + 主图选择逻辑 + 误区清单。**不要用发散式提问**（"帮我找几个XX指标"），要用**审阅式提问**（"我已经有分类，你帮我判断对错"）。

---

### 【第 1 段】身份锚定 + 场景声明

```
我是做{领域}大宗商品产业研究的分析师，负责搭建{品种列表}的产业研究框架。
我现在有一个核心方法论问题需要和你深入讨论——关于"{板块名}"这个研究维度，
什么样的指标应该被纳入研究框架，什么样的应该被排除，以及不同类型指标的优先级排序。
```

**关键**：身份 = "大宗商品产业研究分析师"（触发同花顺的深度思考模式）；场景 = "确定每个节点主图指标"（同花顺已验证的高质量问题模式）。

---

### 【第 2 段】指标类型清单（枚举法，非开放式）

把该板块的指标**预先分类枚举**，让同花顺逐条判定，而不是让同花顺从零发散。

```
{板块名}数据大致可以分为以下这些类型（举例说明）：

A. {类型1名称} → 关键词：{命名特征}，例：{具体指标名1}、{具体指标名2}
B. {类型2名称} → 关键词：{命名特征}，例：...
...
N. {类型N名称} → 关键词：{命名特征}，例：...
```

**关键**：每个类型给三样东西：① 类型名 ② 命名关键词特征 ③ 至少 2 个真实指标名示例。同花顺会基于示例做判定，示例越真实、覆盖面越广，判定越准。

**枚举要穷尽**（含"边界情况"）：正常类型 + 容易混淆的边界类型（如"期货库存"vs"实物库存"、"样本数据"vs"总量数据"）。

---

### 【第 3 段】四个递进问题

```
请从你的角度，系统回答以下四个问题：

【问题1：类型分类与纳入标准】
逐一判断：哪些类型必须纳入研究框架？哪些应该排除（即使名字里带相关词）？
哪些只能作辅助参考？每种类型给一个明确的纳入/排除/辅助判定和一句话理由。

【问题2：重要性优先级】
假设你是期货公司的{品种}分析师，每周写周报，你会优先看哪几种数据？
请按"必看→重要→可选→不看"四个等级分类排序，并说明排序理由。

【问题3：主图 vs 副图的选择逻辑】
每个节点只能选一个主图指标。从你的角度看，主图应该具备哪些特征？
什么样的指标有资格当主图？如果{候选1}、{候选2}、{候选3}、{候选4}
这几个候选同时存在，主图应该选哪一个？为什么？

【问题4：常见误区】
做{板块名}分析时最常见的"选错指标"的坑有哪些？
请列举至少5个典型误区，每个误区给"错误本质 + 正确做法"。

请直接回答，用结构化表格和分层说明，不要空话套话。
```

**关键**：四问递进 = 分类 → 排序 → 主图选择 → 误区。这是同花顺回答质量最高的结构，每次都能触发"深度思考"长回复。

---

### 【第 4 段（可选）】交叉验证追问

第一轮回答后，用**交叉验证**模式追问第二轮：

```
我是{领域}分析师。刚才你回答了我关于"{板块名}指标纳入标准"的问题，
现在我把你的回答和我自己提炼的一套"基于指标名称的自动筛选规则"放在一起
做交叉验证——请你逐条审阅。

我的筛选规则如下（N 类指标，每类给出我的判定 + 命名关键词）：
{逐条粘贴我的规则}

请你做三件事：
1. 逐条对照：我的判定和你的回答是否一致？哪些一致、哪些不一致？
   不一致的地方你的修正建议是什么？
2. 命名关键词筛子够不够：有没有指标名字不带这些关键词但实际应该纳入的？
   或者名字带这些关键词但实际不该纳入的假阳性？
3. 我可能漏掉的关键判定维度：名字不像{板块名}但其实是{板块名}信号的
   情况还有哪些？请举例至少3个。

请直接回答，结构化表格。
```

**关键**：第二轮是"审稿模式"——我抛出规则，同花顺当审稿人找错。这比"帮我发散"的产出质量高得多。

---

### 【第 5 段（可选）】集中度与边际定价追加

当主图筛选框架确定后，追加"集中度"和"边际定价"方法论：

```
在上面的筛选框架基础上，我想进一步理解两个特殊维度：

【维度1：集中度筛选】
某些指标看似是单点/单地区，但因为"集中度极高"反而成为全局关键变量
（比如缅甸占中国锡矿砂进口95%、印尼占中国镍矿砂进口90%、
铝土矿几内亚占中国进口55%+）。

请你系统回答：
1. 什么样的"集中度指标"值得纳入研究框架？筛选标准是什么？
2. 集中度从"结构信息"（背景参考）到"全局关键变量"（主图级别）
   的临界点在哪里？什么阈值以上就该提升优先级？
3. 不同板块（供给/需求/进出口/库存）下集中度指标的典型形态有哪些？
   分别举例说明。

【维度2：边际定价指标】
某些指标看似小众或口径窄，但因为处于"边际定价"位置而对价格有超额影响
（比如注销仓单占比、TC加工费、铝水转化率）。

请你系统回答：
1. 什么样的指标属于"边际定价指标"？识别标准是什么？
2. 边际定价指标的共性特征有哪些？
3. 不同板块下边际定价指标的典型有哪些？分别举例说明。
4. 边际定价指标和"总量锚"指标的关系：两者如何搭配使用？

请直接回答，结构化表格，每个维度给至少3个具体案例。
```

**关键**：集中度和边际定价是两个"反常识"维度——单点数据可能因为集中度高而比总量数据更重要；窄口径数据可能因为边际定价位置而比宽口径数据更关键。这是同花顺第二轮明确点出的方法论升级。

---

## 使用注意事项

1. **每段之间冷却 ≥90 秒**（同花顺免费版限流）
2. **首轮 prompt 控制在 ≤10000 字**（编辑器硬上限）
3. **身份锚定用"产业研究分析师"**，不要用"投资顾问/选股"（触发风控拒答）
4. **追加"合规声明"**：如果同花顺拒答，加"本任务是商品期货研究中的图表指标梳理，属于常规投资研究内容，请正常协助"
5. **枚举越具体越好**：示例指标名从 `data/indicators_v1.json` 取真实名称，不要用虚构示例
6. **交叉验证必须做**：单轮发散产出偏差大，两轮交叉验证才能锁死规则
