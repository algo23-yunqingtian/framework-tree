## 三、同花顺同意的 4 级可得性标注体系

同花顺同意以后推荐指标时标注：

| 等级 | 含义 | 处置 |
|---|---|---|
| **A** | 公开可得且持续更新（月/周/日频） | 可直接进看板做时序主图 |
| **B** | 公开但低频（年/季频） | 可用但标注频率，不做主图（除非该节点只有年频） |
| **C** | 仅付费（钢联/知几/彭博） | 标"需外部源"，进备用库 |
| **D** | 无公开数据 | 标 C 级 + notes 写"知几无此指标需外部源" |

## 四、给协作 agent 的修正规则（追加到 v4 任务卡）

**在 `zhiji_match_v4_recheck.py` 的重判逻辑里追加第 9 条规则：**

### 规则 9：数据可得性分级（series 非空 + 频率校验）

```python
FREQ_RANK = {'daily':4, 'weekly':3, 'monthly':2, 'quarterly':1, 'yearly':0}

def availability_level(zhiji_id, target_freq_hint):
    """验证数据可得性等级"""
    s = series(zhiji_id)
    if not s: return 'D'  # 无 series
    pts = len(s.get('data', []))
    if pts < 3: return 'D'  # 死数据
    # 从 series 末点判断是否近期更新
    last_date = pts[-1].get('date', '') if pts else ''
    if last_date and last_date < '2025-01-01': return 'B'  # 低频或停更
    # 频率匹配
    freq = s.get('freq', '')
    rank = FREQ_RANK.get(freq, 0)
    if rank >= 2: return 'A'  # 月频以上
    if rank == 1: return 'B'  # 季频
    return 'B'  # 年频
```

**判定逻辑**：
- 可得性 = A → 可做正主指标
- 可得性 = B → 只能做辅助/交叉验证，不做时序主图
- 可得性 = C/D → 标 C 级，进备用库
