## 优先级排序（按"数据可靠性风险"从高到低）

1. **供给端** — 错误率最高（锌实测旧映射正确率 < 10%）
2. **成本利润** — 个股 vs 行业口径问题严重
3. **库存** — 巴林仓单 vs LME 全仓问题
4. **进出口** — 海关口径、HS 编码问题
5. **需求** — 终端消费定义问题
6. **价格信号** — 相对最准确，但也要查

## 完成标准

每个节点完成后必须留 4 份文件：
1. 发给同花顺的 prompt 原文 → `{品种}_{板块}_prompt_{节点}.txt`
2. 同花顺回复原文 → `{品种}_{板块}_iwencai_reply_{节点}.md`
3. 知几搜索结果 → `{品种}_{板块}_zhiji_search_{节点}.json`
4. 最终对照表 → `{品种}_correct_{板块}_{日期}.md`

保存路径：`translation-workspace/correction/{品种}/`
