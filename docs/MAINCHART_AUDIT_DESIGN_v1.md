# 主图核验机制设计（v1.0）

> 核心目标：91 个节点的主图选择，机器自动判 ≥85%，人工只审 <15 条标红。
> 依据来源：同花顺官方 4 条精确匹配规则（CDP 登录态获取）+ 假阳性检测五重校验（skill: indicator-cross-source-matching）+ "迪拜分库"踩坑教训。

---

## 一、同花顺官方 4 条精确匹配规则（已固化）

这 4 条来自同花顺问财 AI 对话官方回复（2026-09-01 CDP 登录态获取，存于 skill: indicator-cross-source-matching）：

1. **指标名称必须与平台实际命名完全一致**（不是近似名），就像在平台搜索框里能直接搜到一样
2. **必须说明该指标的频率**（日频/周频/月频/季频）**和可得性**（公开/付费/仅VIP）
3. **如果平台没有统一口径，直接说"无统一口径"**，不要给近似替代
4. **如果两个平台命名不同，分别列出各自平台的最可能命中名称**

→ **转化为机器判据**：`name_exact_match`（精确名匹配，非模糊）+ `freq_documented`（频率已知）+ `scope_declared`（口径已声明，含"无统一口径"标记）

## 二、四层漏斗核验流程

```
每次 build 后 / 每次 correction 更新后
  → audit_mainchart_v3.py
     ├─ 层 1: 硬性自动判（直接定档，0 人工）
     ├─ 层 2: 同花顺原文匹配（5 重校验打分）
     ├─ 层 3: 口径可信度评分（防迪拜式误替换）
     └─ 汇总 → 人工仲裁池（<15 条/批）
         你裁 → 写 MAIN_METRIC → 重跑 → 门禁
```

### 层 1：硬性自动判（0 人工）

| 判据 | 自动结论 | 处置 |
|---|---|---|
| 主图含地名分库词（迪拜/埃及/巴林/刚果/单矿区/单企业名）且不含总量词 | **SCOPE-ISSUE** | 标红，进层 3 评分 |
| 主图是价格类（收盘价/升贴水/基差/价差）+ 节点非 2.x 价格板块 | **PLACEHOLDER** | 标红，自动找替换候选 |
| 主图 ID 在 `MAIN_METRIC` 显式覆盖里 | **TRUSTED-MAIN** | 直接通过（你已确认过的白名单） |
| 主图 ID verified=False | **UNVERIFIED** | 自动降级为辅助，不进主图位 |
| 主图 ID `_nodes` 不含当前节点 | **NODE-LEAK** | 串台指标，标红 |

**地名分库词库**（来自踩坑 + skill 已有）：
```python
SCOPE_CITY = ['迪拜','香港','埃及','巴林','光阳','鹿特丹','釜山','新加坡',
              '马来西亚','印尼','缅甸','菲律宾','哥伦比亚',
              '伦丁矿业','阿尔法明','天马',' nickel28','镍28公司']
SCOPE_TOTAL_KW = ['总量','总计','总库','全口径','全部','global','total','总库存','合计','27家样本']
```

### 层 2：同花顺原文匹配（5 重校验打分）

对每条 correction 文档里的 A 级正主，用 skill 已有的 5 重校验打分：

| 校验维度 | 规则 | 分值 |
|---|---|---|
| 品种词命中 | 概念含"镍"→注册名必须含"镍/Ni/Nickel" | +2 / 不命中直接淘汰 |
| 字段词命中 | 概念含"库存"→注册名必须含"库存/仓单/在途" | +2/个 |
| 交易所前缀强校验 | 概念含 LME → 注册名必须含 LME；含 SHFE → 必须含 SHFE/上期所 | 不匹配 -3 |
| 国家方向过滤 | 概念"中国进口"→ 命中"美国/澳大利亚→中国"算分国别子集 ≠ 总量 | 直接淘汰 |
| 官方源加权 | SMM/Mysteel/LME/SHFE 官方口径 | +1 |

**阈值**：≥5 且覆盖度 ≥50% = **OK-原文背书**（自动通过）
**低于阈值** = 进层 3

### 层 3：口径可信度评分（防迪拜式误替换 — 核心新增）

对每个候选主图给一个 `scope_score`（0-10 分）：

| 评分维度 | 加分 | 减分 |
|---|---|---|
| 含总量词（中国/全国/全球/合计/27家样本） | +2 | — |
| verified=True + series 实测有数据 | +1 | verified=False -2 |
| 频率日/周（高频=市场关注度高） | +1 | 频率年 -1（低关注） |
| 序列名完整且不含地名分库 | +1 | 含地名分库 -3 |
| 跨节点挂载数 ≤3（专属性） | +1 | 挂载 >10 个节点 -2（万能指标嫌疑） |
| SMM/Mysteel/LME 官方口径 | +1 | 单企业/单矿区 -2 |

**scope_score ≥ 6** = **OK-TRUSTED**（可自动替换）
**scope_score 3-5** = **NEEDS-REVIEW**（进人工仲裁池）
**scope_score < 3** = **REJECT**（不替换，保留现状并标注）

### 层 4：人工仲裁池（只收这几种，预计 <15 条/批）

| 收入条件 | 你需要做什么 |
|---|---|
| scope_score 3-5 的边界候选 | 看审计器给的"候选 vs 当前"对比表，选一个 |
| 同花顺原文与候选都缺失 | 触发一次同花顺追问（用 4 条官方规则提问） |
| 跨板块边界争议（如 NI.5.3 需求/库存之争） | 你定该节点的主题归属 |
| 新品种/新节点首次建页 | 首次必审，后续同类可复用 |

## 三、同花顺深度提问模板（只在层 4 触发时用）

当层 4 需要追问同花顺时，用以下模板（基于官方 4 条规则）：

```
我是做有色金属大宗商品产业研究框架的分析师。
我需要为 [品种] 的 [节点] 确定"主图"指标——该节点最核心、
最能代表这个主题、被市场分析师广泛认可的单一时序指标。

在 [SMM/Mysteel] 平台中，搜索 [具体指标名称]，
要求：
1. 指标名称必须与平台实际命名完全一致（不是近似名）
2. 说明该指标的频率（日频/周频/月频）和可得性
3. 如果平台没有统一口径，直接说"无统一口径"，不要给近似替代
4. 如果两个平台命名不同，分别列出各自平台的最可能命中名称

补充问题：
- 当可选指标有"总量"vs"分国别"vs"单企业"时，你们选哪个？
- 判断口径过窄的标准是什么？
- 被市场广泛认可的高认可度指标通常有什么特征？
```

**配额控制**：每个节点最多问 1 次，每批 <10 个节点触发追问。

## 四、自动替换 vs 保留现状 的决策矩阵

| 层 1 状态 | 层 2 原文 | 层 3 scope_score | 决策 |
|---|---|---|---|
| PLACEHOLDER | 有原文背书 | ≥6 | ✅ 自动替换 |
| PLACEHOLDER | 有原文背书 | 3-5 | 🟡 人工审 |
| PLACEHOLDER | 无原文 | ≥6 | ✅ 自动替换（口径可信） |
| PLACEHOLDER | 无原文 | 3-5 | 🟡 人工审 |
| PLACEHOLDER | 无原文 | <3 | ❌ 保留现状+标注"待补指标" |
| SCOPE-ISSUE | — | — | 🟡 人工审（必须标"仅XX分库"或换总量） |
| WRONG-MAIN | 有原文背书 | ≥6 | ✅ 自动替换 |
| WRONG-MAIN | 有原文背书 | 3-5 | 🟡 人工审 |
| WRONG-MAIN | 无原文（AI噪音） | 任意 | ⚪ 保留现状（同花顺AI推荐本身错） |
| TRUSTED-MAIN | — | — | ✅ 直接通过 |
| OK-A / OK-FALLBACK | — | — | ✅ 直接通过 |
