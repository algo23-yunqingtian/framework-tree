# 跨品种通用·指标筛选规则 v1（基于名称的筛子）

> 日期：2026-09-03
> 设计原则：**只看名称**，不需要相关性/有效性论证。名称本身就是筛子。
> 数据基础：指标库 1290 条，库存类 159 条，供给 281，成本 123，进出口 169，需求 79。

---

## 一、核心理念：三个优先级 + 五条排除规则

**优先级**（同板块同品种内的排序逻辑）：
1. **总量口径优先** — "全球""中国""总计""合计"的永远排在分点前面
2. **高频优先** — 日度 > 周度 > 月度 > 季度（同一口径下）
3. **官方源优先** — LME/SHFE/COMEX/海关/统计局 > SMM/Mysteel/第三方调研

**五条排除规则**（看到即降级，不用论证）：
| # | 名称特征 | 动作 | 理由 |
|---|---|---|---|
| 1 | 含具体单点地名（单仓/单港/单矿/单企） | 降级为副图，不做主图 | 样本偏差，不代表行业 |
| 2 | 含"价格""升贴水""盈亏""价差" | 库存/供给节点直接排除 | 价格类是结果变量，循环论证 |
| 3 | 含"样本""样本企业""N家" | 降级，只能做辅助 | 口径窄且未加权汇总 |
| 4 | 含"期货""持仓""合约" | 库存节点排除，属价格端 | 期货持仓≠实物库存 |
| 5 | 含"月/季/年度"但板块要高频 | 仅作月度锚，不做主图 | 频率太低，无法定节奏 |

### 库存板块筛选流程（四步筛）

```
第1步 · 硬排除（名称即否）
  ❌ 含"期货"+"库存"(COMEX 期货库存除外) → 期货持仓，非实物
  ❌ 含"价格"/"升贴水"/"盈亏" → 价格类，归成本/价格节点
  ❌ 仅含单一仓库名(迪拜/新加坡/巴林)且无"合计" → 单分库
  ❌ 含"样本企业"/"N家"且无加权总量 → 窄样本

第2步 · 定 P0（总量锚，只取 1-2 个）
  ✅ "LME"+品种+"库存总计" 或 "LME"+品种+"库存"(无地名)
  ✅ "SHFE"+品种+"仓单"(无地名) 或 "上期所库存"
  ✅ "COMEX"+品种+"期货库存"(无地名) ← 铜/铝/锌有
  → 三地合计 = 全球显性库存，P0 主图

第3步 · 定 P1（节奏信号，1 个）
  ✅ "注销仓单"（LME，日度）→ 领先 3-5 日
  ✅ "注册仓单"（LME，日度）→ 交割压力
  → 注销仓单占比 = 主副图搭配

第4步 · 定 P2-P4（结构 + 地面实况）
  ✅ P2: "社会库存""社库"+地名 → 主要消费地(上海/天津/广东/江苏)
  ✅ P2: "到港量""港口库存"+品种原料 → 物流前瞻
  ✅ P2: "保税区" → 边缘库存
  ✅ P3: "冶炼企业""再生铅企业""铅蓄电池企业"+库存 → 行业结构
  ✅ P3: "LME分仓库/分地区"+单点 → 地理分布
  ✅ P4: "在途库存""铝水转化率""隐性变量" → 结构性失真
```

## 三、供给板块（281 条 → 筛选）

### 命名模式扫描

| 名称特征 | 典型 | 归属 |
|---|---|---|
| 品种+"产量"+全球/中国 | ICSG:电解铜产量:全球(月)、Mysteel 原生铅产量(中国) | **P0 总量** |
| 品种+"开工率"+总/无地名 | SMM:电解铝开工率(周/月)、SMM 铅蓄电池开工率:总 | **P1 节奏** |
| 品种+"产能利用率" | Mysteel 原生铅产能利用率、电解铝产能利用率 | **P1 弹性** |
| 品种+"冶炼"+企业/厂 | SMM电解铜供需平衡表、SMM精炼铅成本 | 视名称 |
| 海外+原料产地(几内亚/印尼/菲律宾) | SMM:海外铝土矿产量:几内亚、MHP产量:印尼 | **P2 扰动** |
| 单地省市(青海/云南) | NBS 铅精矿产量-青海 | **排除(单点)** |
| TC加工费/加工费 | 铅精矿加工费(国产) | **P1 成本端锚** |

### 供给筛选流程（三步）

```
第1步 · 硬排除
  ❌ 含单省市(青海/云南/广西/山东)且无"全国/中国" → 单点
  ❌ 含"利润/成本/价差" → 归成本节点
  ❌ 含"进口/出口/盈亏" → 归进出口节点

第2步 · P0 定方向
  ✅ "产量"+全球/中国 → 官方源(统计局/ICSG/USGS/ILZSG)优先
  ✅ 全球产量 + 中国产量 → 双口径对比

第3步 · P1 定节奏
  ✅ "开工率""产能利用率"+总/全国(无地名)
  ✅ "TC加工费"/"加工费" → 冶炼利润压缩领先信号
  ✅ 海外原料产地产量(几内亚铝土矿/印尼镍/菲律宾镍矿)
```

  ② TC/RC加工费(日频) → 行业锚
  ③ 完全成本指数(月/日) → 成本曲线
  ④ 期现价差/精废价差(日频) → 套利空间

## 六、通用排除清单（所有板块共用，见名即否）

| 名称关键词 | 排除理由 |
|---|---|
| 期货+库存（COMEX 除外） | 期货持仓 ≠ 实物库存 |
| 期货+持仓+CFTC | 投机头寸，非基本面 |
| 单一仓库/港口/矿区地名（无"合计/总计/汇总"） | 样本偏差 |
| 样本企业 / N家样本 | 口径窄 |
| 对外承包/进料加工/特殊监管 | 贸易方式细分 |
| 产值/销售额/金额 | 价格污染 |

## 七、通用入选排序规则（同板块同品种内）

**得分卡**（满分 10，≥7 入主图，4-6 副图，<4 排除）：

| 维度 | 加分条件 | 分值 |
|---|---|---|
| 口径宽度 | 全球+1 / 中国+1 / 华东等大区+0.5 / 单点+0 | +0~1 |
| 频率 | 日+2 / 周+1 / 月+0.5 / 季+0 | +0~2 |
| 源头 | LME/SHFE/海关/统计局+2 / SMM/Mysteel+1 / 第三方+0 | +0~2 |
| 名称纯度 | 直接度量该板块物理量+2 / 间接代理+1 / 价格污染+0 | +0~2 |
| 非重复 | 名称中不含其他板块关键词+2 / 有交叉+1 | +0~2 |
| 系列连续性 | 隐含日频+2 / 月频+1 | +0~2 |

**主图门槛：≥7 分且 ≥4 条排除规则均未触发**

## 八、用法

1. **发散新指标时**：拿到同花顺/AI 返回的指标名 → 用「五条排除规则」筛掉噪音 → 用「得分卡」排优先级 → 选 ≥7 分入主图
2. **做主图核验时**：把当前主图名称过一遍排除规则 → 触发即标红 → 从副图池选替代
3. **新增品种时**：把品种名替换速查表里的铜/铝/锌/镍/锡/铅 → 名称模式自动匹配

**关键前提**：筛子只看名称，不验证数据序列。注册到指标库时再走知几 API 查序列连续性（`zhiji_api.py search`）。
