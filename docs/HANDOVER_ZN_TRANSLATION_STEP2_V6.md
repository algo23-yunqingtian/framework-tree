## 二、Step2 分词机制 v6（最终版）

**3 个核心函数**：

### 2.1 `clean_name(name) -> clean`

三层过滤，去噪声保留主干：
1. **图表规范黑名单**（`SPEC_RULE_KEYWORDS`）："避免双轴""坐标轴""不宜""建议""暂无""无统一口径"等 → 直接返回空字符串，不参与搜索
2. **元数据说明黑名单**（`META_DESC_KEYWORDS`）：同上
3. **有效指标名清洗**：去来源前缀（SMM/Mysteel/安泰科/Zn50 等）、去单位/频率/浓度代码（日/周度/月度/2025/48%Zn 等），用空格合并片段

### 2.2 `build_search_terms(variety, name) -> terms[]`

四级策略，按优先级排列：
1. **策略0 查库回退（6层约束）**：查 `data/indicators_v1.json` 中已有 zhiji_id 的指标，按品种词→核心关键词→来源(LME/SHFE/国内)→产品形态(矿/锌锭/镀锌)→城市→最短名逐层过滤，命中后直接返回 `__DB__{id}|{name}`
2. **策略1 分词+核心关键词优先**：按 `/；，` 分词，≤6字且含核心词（TC/加工费/库存/盈亏等）的 token 直接加 `锌 {token}`
3. **策略2 中文长词拆短**：6+字中文 token，取 2-3字前缀独立搜索（防"七地锌锭社会库存"只搜整句），并围绕核心关键词切 2-5字短窗口
4. **策略3 英文带品种前缀**：英文 token 加 `锌 {token}`

### 2.3 `grade_hit(variety, name, results) -> (grade, hit, score)`

遍历知几返回的全部结果（limit=10），找品种词+核心关键词双匹配的最优命中：
- **A 级**：命中名含品种词 AND 含核心关键词
- **B 级**：品种词匹配 + 有衍生词弱相关（如"锌精矿"对"TC"）
- **C 级**：全部结果都不匹配
