# 同花顺问财 · 分类范式提示词模板 v2（总→分批量版）

> 日期：2026-09-03
> 用途：让同花顺对"品种 × 板块"做**总→分分类**（地区/工艺/口径/形态），并推荐每个子类里的重点指标。
> 与 v1 的区别：v1 是"判断我给的分类对不对"（审阅式）；v2 是"你按什么标准分类 + 每个子类推荐什么"（生成式分类）。
> 核心范式：**总量 → 子类拆分 → 每个子类的重点地区/工艺/指标 → 优先级排序**。

---

## 一、范式核心：总→分的五种拆法

问同花顺时，先给它这五种分类维度，让它按品种×板块挑适用的：

| # | 分类维度 | 问法 | 适用板块示例 |
|---|---|---|---|
| 1 | **按地区拆分** | 这个板块的总量应该看哪些重点地区？哪些地区库存/产量/消费最集中？ | 库存(新加坡/高雄/上海/广东)、供给(云南/内蒙古/智利) |
| 2 | **按工艺拆分** | 这个板块的产量/成本/利润按工艺怎么分？各工艺占比多少？ | 供给(盐湖/云母/辉石、原生/再生、火法/湿法) |
| 3 | **按口径拆分** | 同一物理量有几种统计口径？各口径差异在哪？ | 库存(注册/注销/非注册、交易所/社会/保税)、产量(统计局/协会/调研) |
| 4 | **按形态拆分** | 按产品形态怎么分？各形态的流动性和定价差异？ | 库存(电解镍/镍豆/镍球、铝锭/铝棒)、供给(精矿/精炼/中间品) |
| 5 | **按产业链环节拆分** | 上下游各环节的库存/利润/开工怎么分布？ | 库存(矿山/冶炼厂/贸易商/终端)、成本(矿端/冶炼/加工) |

## 二、提示词主模板

```
我是做{领域}大宗商品产业研究的分析师，负责搭建{品种}的产业研究框架。

我要建立一套"从总量到分类"的指标研究体系：先有一个总量锚（比如全球总库存），
再把它拆分成不同子类（按地区/工艺/口径/形态/环节），每个子类都要有对应的重点指标。

请你帮我做以下 4 件事：

【任务1：分类维度选择】
{品种}的"{板块}"板块，总量应该按什么维度拆分成子类？
从以下五种里选适用的（可多选，也可补充）：地区/工艺/口径/形态/产业链环节。
请给出拆分树：总量 → 子类1 → 孙类1.1/1.2，并标注每个分支的优先级（必看/重要/可选）。

【任务2：重点地区/工艺识别】
在{品种}的"{板块}"板块里：
1. 哪些地区/产地是最重要的？判断标准是什么（集中度/产量占比/库存占比）？
   例：铅外盘库存应该看新加坡（集中度高），而不是巴林（库存极少）。
2. 哪些工艺路线是核心？各工艺占比多少？哪个工艺是边际定价的？
   例：碳酸锂供给分盐湖/云母/辉石，云母和辉石是边际工艺。

【任务3：重点指标推荐】
每个子类（重点地区/工艺/口径/形态）各推荐 1-3 个具体指标，
给出：指标名 + 数据源 + 频率 + 为什么重要。

【任务4：优先级排序】
把所有子类的指标按"必看→重要→可选→不看"排序，
说明排序依据（集中度/频率/领先性/边际定价）。

请直接回答，用拆分树+表格，不要空话。每个子类至少给 1 个具体指标名。
```

## 三、批量执行设计（8 品种 × 6 板块）

### 品种清单
| 代码 | 品种 | 备注 |
|---|---|---|
| CU | 铜 | |
| AL | 铝 | |
| ZN | 锌 | 库存重点：新加坡/高雄 |
| PB | 铅 | 库存重点：新加坡（非巴林） |
| NI | 镍 | |
| SN | 锡 | |
| SI | 硅（工业硅） | 工艺：化学级/冶金级 |
| LC | 碳酸锂 | 供给工艺：盐湖/云母/辉石 |

### 板块清单（6 大节点）
1. **价格信号**（2.x）——拆法：内外盘/期限结构/升贴水
2. **供给**（3.x）——拆法：工艺/地区/原料端
3. **库存**（4.x）——拆法：地区/口径/形态（本次重点）
4. **需求**（5.x）——拆法：下游行业/终端应用
5. **进出口**（6.x）——拆法：贸易流/来源地/套利
6. **成本利润**（7.x）——拆法：工艺成本/副产品/利润

### 批量节奏
- 每轮 1 个品种 × 1 个板块（共 48 轮）
- 轮间冷却 ≥45s（限流）；每 5 轮后冷却 ≥120s（深度思考疲劳）
- 输出到 `analysis/iwencai_classify/{品种}_{板块}.md`
- 断点续跑：已完成 SKIP（state 文件）

## 四、验证过的提问示例

### 例 1：铅库存地区选择（已验证正确方向）
```
铅(PB)的"库存"板块，总量应该按什么维度拆分？
外盘 LME 库存应该重点看哪些地区？为什么不是巴林？
国内库存重点看哪些地区？为什么？
```
→ 预期答案：外盘看新加坡（LME 铅库存集中地，注册+注销仓单最活跃）；国内看五地（上海/天津/广东/江苏/浙江）；巴林库存极少无意义。

### 例 2：碳酸锂供给工艺（用户指定）
```
碳酸锂(LC)的"供给"板块，总量按什么工艺拆分？
盐湖/云母/辉石各占多少？哪个是边际定价工艺？
每个工艺推荐 2 个重点指标（产量/成本/利润/开工）？
```
→ 预期答案：盐湖(青海)+云母(江西)+辉石(澳洲/四川)；云母是边际工艺（成本高）；辉石是需求拉动主工艺。
