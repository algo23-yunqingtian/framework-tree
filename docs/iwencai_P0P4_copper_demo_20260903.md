## P0 — 全球显性库存总量（定方向）

**分析动作**：看 LME+SHFE+COMEX 三地合计库存的连续走势。

**铜的现状（9月3日）**：
- COMEX 铜库存 67.5万吨，连续46个交易日增加，创历史新高
- LME 铜库存同步下降
- **但**：三地合计库存连续 3 周下降 = 全球去库（偏多信号）

**分析结论**：
- 不能只看 COMEX（67.5万吨↑）→ 会误判"库存大增看空"
- 不能只看 LME（↓）→ 会误判"极度紧俏看涨"
- 真相是：美国对铜加征关税预期驱动"买 LME 抛 COMEX + 实物转移"，COMEX 囤货 ≠ 全球宽松
- **三地合计连续去库 3 周 = 全球去库趋势确认，偏多**

**判断规则**：三地合计连续 3 周降 = 偏多；连续 3 周升 = 偏空。

## P1 — 注册仓单 vs 注销仓单（定节奏）

**分析动作**：看注销仓单占比是否突破关键阈值 + 与现货升贴水同步验证。

**铜的现状**：
- 注销仓单占比 52.39%（突破 50% 极端紧张信号）
- 注销规模异常放大，亚洲区域注销激增

**分析结论**：
- 50% = 极端紧张阈值（铜的注销占比与铜价走势相关性达 0.78）
- 亚洲区域注销激增 = 跨市搬库+关税预期驱动
- 但必须与现货升贴水同步验证：注销↑ + 升水↑ = 真实短缺；注销↑ + 贴水 = 移仓信号失真

**判断规则**：
- 铜：注销占比突破 30% → 与铜价相关性 0.78；突破 50% = 极端紧张
- 锌：30% 是关键关口；持续 >35% = 去库确认度高
- 铝：注销占比 <5% = 海外交割金属无人提取，即使库存低也非利多

## P2 — 社会库存（验真实）

**分析动作**：用 SMM/Mysteel 调研的国内社会库存交叉验证交易所库存。

**铜的现状（9月3日）**：
- 国内社库 10.43万吨，环比降 1.52万吨
- 上海 7.09万吨↓、广东 0.80万吨↓（创年内新低）、江苏 2.23万吨↑

**分析结论**：
- 上海 + 广东双去库 = 国内去库确认
- 广东创年内新低 = 需求强劲
- 但江苏因冶炼厂到货小幅累库 → 需关注后续到货节奏
- 社库趋势与交易所库存方向一致 = 趋势确认度高

**判断规则**：
- 交易所库存↓ + 社库↓ = 最强多头信号
- 交易所库存↑ + 社库↑ = 最强空头信号
- 背离持续 2-3 周后往往反转

## P3 — LME仓库地理分布（找错配）

**分析动作**：看核心仓库群的新加坡/迪拜/鹿特丹/韩国库存分布。

**铜的现状**：
- COMEX 库存 67.5万吨 连续 46 天增加
- 关税驱动搬库路径：亚洲 → 美国
- 上海注册仓单连续 6 个交易日下降

**分析结论**：
- 全球铜处于"美国囤货、非美抽紧"的结构性错配
- 美国仓库里的铜无法立即解决伦敦和亚洲的交割紧张
- COMEX-LME 价差是否覆盖运输成本 = 判断铜能否回流的关键

---

## P4 — 结构性失真变量（防失真）

**分析动作**：识别"库存数据看起来利好/利空但实际并非如此"的场景。

**铜的现状**：
- COMEX 库存创新高但属于关税驱动的结构性囤货，非全球宽松
- 67.5万吨 COMEX 库存中有大量是关税预期下的预防性囤货

**分析结论**：
- COMEX-LME 价差是否持续覆盖运输+关税成本 → 判断是否可回流
- COMEX 库存/消费比 <0.5 时说明铜极度紧缺
- ⚠️ 失真风险高——不能把 67.5万吨 COMEX 库存简单加总到全球总库存中解读为宽松

## 完整分析结论

**综合 P0-P4**：
- P0 三地合计去库（偏多）+ P1 注销占比 52% 极端紧张（偏多）+ P2 社库去化确认（偏多）+ P3 结构性错配（非美紧）+ P4 COMEX 失真校正

**最终判断**：铜库存分析结论 = **偏多**。但需持续跟踪：
1. COMEX-LME 价差是否回落（判断回流）
2. 注销仓单占比是否持续 >50%（验证短缺）
3. 广东/上海社库是否继续去化（验证需求）

## 这套分析范式的通用模板

```
问 P0：全球总量趋势是什么？→ 定方向（多空）
问 P1：内部结构领先信号是什么？→ 定节奏（拐点）
问 P2：社库/高频数据验证了 P0 吗？→ 验真实（确认/背离）
问 P3：有没有地理/品牌错配？→ 找错配（解释矛盾）
问 P4：数据会不会骗我？→ 防失真（校正假信号）

结论：当 P0-P4 方向一致时信号最强；出现背离时才是深入诊断的拐点窗口。
```
