## 三、核心坑速查（本轮新增）

| 坑 | 症状 | 解法 |
|---|---|---|
| **chart-note 内嵌 ASCII 双引号** |  `是"货已离仓"` 在 Python 双引号字符串内 → SyntaxError | 统一用中文引号「」或转义；写专门扫描（首尾是 `"` 的行 body 内不能有 `"`） |
| **季节按钮之前是假的** | 点"☀ 季节"显示空图（data 硬编码 12 个 null） | `window.__seasonalize(arr)`：按 `date.split('-')[1]` 分组，历年同月均值 |
| **4 个 build 脚本各写各的** | CSS 结构不同（64 无 button，61/63 有 button）；函数签名手工同步 | 抽 chart_kits.py（P1）；至少先建对照表 |
| **6.4 页 487KB curl 超时** | `curl -s` 默认 30s 超时 return 0 字节 | `--max-time 90`；分页 curl |
| **execute_code f-string 含反斜杠报错** | `f"...count('class=\\\"...')"` SyntaxError | f-string 表达式内不能有 `\`；用变量拼接 |
