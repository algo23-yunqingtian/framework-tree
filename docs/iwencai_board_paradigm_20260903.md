# 同花顺问财 · 分板块分析范式（2026-09-03）

> 来源：同花顺问财 AI 对话（登录态用户"田允晴"），2026-09-03 现场提问。
> 问题：库存/供给/进出口三个板块各自的分析逻辑层次与指标筛选优先级。

---

## 一、库存板块分析范式（P0-P4）

**核心结论**：库存分析的第一优先级永远是**全球显性库存总量（LME+SHFE+COMEX三地合计）**，这是定方向的"锚"；第二优先级是**交易所内部结构（注册仓单vs注销仓单占比）**，是领先3-5个交易日的拐点信号；第三优先级是**重点地区社会库存**；第四优先级是**LME仓库地理分布、品牌结构、铝水转化率**等结构性指标。

### P0 — 全球显性库存总量（定方向）
- LME全球总库存 + 上期所库存 + COMEX库存（三地合计）
- 单一交易所库存可能被跨市套利扭曲，必须三地合计看
- 案例：COMEX铜库存67.5万吨连续46天增加，但LME库存下降→结构性囤货非全球宽松

### P1 — 注册仓单vs注销仓单（定节奏）
- 注销仓单占比上升 = 领先3-5个交易日预测去库
- 注销仓单是"已申请提货但仍在仓库"，从注销到实际出库有数天到数周滞后
- 注销仓单占比必须与现货升贴水同步验证：注销↑+升水↑=真实短缺；注销↑+贴水=移仓

### P2 — 社会库存（验真实）
- 上海/无锡/佛山/巩义等SMM或Mysteel调研口径
- 验证真实消费强度的"地面实况"

### P3 — LME仓库地理分布（找错配）
- 只需关注库存变动贡献最大的核心仓库群

### P4 — 结构性失真变量（防失真）
- 铝的"铝水转化率"、铜的"COMEX结构性囤货"、锡的"缅甸佤邦复产进度"、铅的"废电瓶流通紧张度"
- 显性库存回答"有多少"，隐性变量回答"为什么变"和"会不会持续"

### 库存分析三个"不要"
1. **不要只看一个总数**——全球显性库存是方向锚，但低库存不等于看涨（2026年铝：LME库存低位但注销仓单占比仅1.71%+俄铝品牌集中度94.89%+中国铝材出口放量三重缓冲同时存在）
2. **不要把注销仓单当成已出库库存**——注销是"已申请提货但仍在仓库"，2018年铜市场出现过"库存↓+注销占比↑+价格↓"的反常组合
3. **不要忽略隐性库存和结构性变量**

## 二、供给板块分析范式（P0-P4）

**核心结论**：供给分析的第一优先级不是"产量数字"本身，而是**"供给约束在哪里发生"**——铜看TC加工费和矿山品位，铝看4500万吨产能天花板剩余空间，镍看印尼RKAB配额审批，锡看缅甸佤邦复产进度，锌看TC加工费，铅看废电瓶流通紧张度。总量产量数据只是结果变量，真正的定价锚在"边际供给弹性受限的环节"。

### P0 — 总量锚（定方向）
- 中国精炼铜/铝/锌/镍/锡/铅产量（统计局月度）
- 全球产量（USGS/ICSG/IAI/ISTAR/ILZSG/INSG年度）
- 中国产量增速 vs 全球平均增速的对比 = 中国定价权变化

### P1 — 工艺拆解（看弹性）
不同品种的工艺路线：

| 品种 | 工艺路线 | 核心指标 |
|---|---|---|
| 铜 | 矿山→精炼（火法+电解）；废铜再生 | 铜精矿TC加工费 + 原生铜vs再生铜占比 |
| 铝 | 电解铝（火电自备电vs网电vs水电）；再生铝（约15%） | 电解铝运行产能/4500万吨天花板 + 铝水转化率 |
| 锌 | 矿山→火法（ISP）/湿法冶炼；再生锌 | 锌精矿TC加工费 + 中国锌矿开工率 |
| 镍 | 火法NPI（不锈钢）/湿法MHP（新能源）/电解镍 | 印尼RKAB配额 + HPM计价系数 + 硫磺CIF价格 |
| 锡 | 原生锡矿；再生锡（回收率92%） | 缅甸佤邦复产进度 + 印尼天马产量指引 |
| 铅 | 原生铅；再生铅（35-40%） | 废电瓶采购价 + 再生铅开工率 |

### P2 — 海外供给扰动（量化风险）
- 铜：智利品位下降+秘鲁扰动+刚果(金)禁令+印尼Grasberg推迟
- 铝：几内亚铝土矿（占中国进口55%+）+ 海外EGA仅恢复18%
- 镍：印尼RKAB配额削减30%+硫磺价格涨超300%
- 锡：缅甸佤邦复产缓慢+印尼天马增产3万吨
- 锌：澳洲/秘鲁矿山扰动
- 铅：废电瓶跨境转移管制（巴塞尔公约）

### P3 — 地区成本差异（定位成本曲线）
- 铜：智利地下矿低成本 vs 非洲次生矿高成本
- 铝：云南水电铝丰水期低成本峰 vs 网电高成本峰
- 镍：印尼NPI（12000-14000美元）vs 硫化镍矿电解镍（>20000美元）
- 锡：印尼天马露天矿低成本 vs 缅甸深井矿高成本
- 铅：原生铅（14000-15000元）vs 再生铅（16000-17000元）

### P4 — 前置约束变量（领先拐点，领先1-3个季度）
- 铜：TC加工费 + 矿山CAPEX周期 + 品位趋势
- 铝：产能审批节奏 + 云南水电水位 + 氧化铝产能投放
- 镍：RKAB配额审批进度（月度滚动）+ HPM新规执行力度
- 锡：佤邦复产进度（周度）+ 天马产量执行率（季度）
- 锌：TC + 开工率 + 矿山CAPEX周期
- 铅：废电瓶库存周转天数（领先1-2周）+ 再生铅开工率

### 供给分析三个"不要"
1. **不要用单企业产量替代行业总量**——印尼天马增产70%但占全球精炼镍年消费仅1%
2. **不要用产量增速替代供给弹性判断**——增量来自成本曲线哪一段才是关键
3. **不要忽略工艺路线间的替代弹性**——镍NPI/MHP/电解镍、铅原生/再生、锡原生/再生

## 三、进出口板块分析范式（P0-P4）

**核心结论**：进出口分析的第一优先级不是"净进口数字"本身，而是**"贸易流重构方向"**——铜看COMEX结构性囤货是否回流、铝看几内亚铝土矿到港量与氧化铝出口、镍看印尼中间品进口替代精炼镍出口、锡看缅甸矿砂进口恢复节奏、锌看精矿进口与精锭净进口的剪刀差、铅看废电瓶跨境转移管制。

### P0 — 净进口总量（定方向）
- 海关口径月度净进口量
- 净进口持续增加 = 国内供需缺口扩大，看多
- 净进口持续减少 = 缺口收窄或转为过剩，看空
- 净出口 = 需区分"主动出口"和"被动出口"

### P1 — 原料进口 vs 产品出口（看结构，最关键）

| 品种 | 核心剪刀差 |
|---|---|
| 铜 | 铜矿砂及精矿进口（+6.6%）vs 精铜出口 |
| 铝 | 铝土矿进口（+23.6%）vs 铝材出口放量 |
| 镍 | MHP进口替代精炼镍出口（核心逻辑） |
| 锡 | 缅甸矿砂进口恢复节奏 |
| 锌 | 精矿进口 vs 精锭净进口的剪刀差 |
| 铅 | 废电瓶跨境转移管制 |

### P2 — 来源地集中度（量化风险）
- **>80%**：单一来源地中断风险极高（锡：缅甸占中国锡矿砂进口95%；镍：印尼占中国镍矿砂进口90%）
- **50-80%**：可被其他来源地部分对冲（铜：智利+秘鲁+印尼合计约75%）
- **<50%**：分散，影响有限（锌：分散在多国）

### P3 — 顺差/逆差解读（确认趋势）
- 原料进口增+产品出口增 = 国内加工能力过剩，看空
- 原料进口减+产品出口减 = 国内需求转弱，看空
- 铝材出口放量对冲国内累库 ≠ 需求强劲

### P4 — 跨市场套利信号（领先预警，领先1-2周）
- COMEX-LME价差 >500美元/吨 → 美国囤货、非美抽紧
- 沪铝/伦铝比值 >1.05 → 铝材出口有利润空间
- 沪镍/伦镍比值 >1.1 → 精炼镍进口有利润空间
- 沪锡/伦锡比值 >1.15 → 锡锭出口有利润空间
- 沪锌/伦锌比值 >1.05 → 锌锭出口有利润空间

## 四、三块范式共同的方法论升级

同花顺反复强调的核心思想，直接对应我们要做的核验机制：

1. **主图定方向，副图定节奏**——总量口径做主图（P0），高频窄口径做副图（P1-P4）
2. **锚定方向 + 弹性确认 + 扰动共振三者一致时信号最强**，背离时才是深入诊断的拐点窗口
3. **跨市场套利信号是进出口分析的领先指标**，领先贸易流迁移1-2周
4. **工艺路线间的替代弹性是供给曲线斜率的决定因素**，比总量产量数据更能解释价格拐点
