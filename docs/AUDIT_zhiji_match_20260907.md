## 五、给协作 agent 的修正规则（追加到任务卡）

1. **找不到真指标 = 标 C 级，不许填空**：zhiji_id 留空 + verified=false，notes 写「知几无此指标，需外部源」。绝不允许用字面相近的其他指标顶。
2. **概念维度必须对齐**（判定用）：加工费 / 库存 / 进口量 / 产量 / 开工率 / 利润 / 价格 / 订单排产 —— 八个维度，候选与目标维度不一致一律降级为 C。
3. **氧化铝 ≠ 电解铝、粗铜 ≠ 精铜、工业硅 ≠ 硅矿、镍矿 ≠ 镍精矿**：产业链上下游不可互串。
4. **地域必须一致**：目标写「海外/印尼/南非/美国/巴西」，候选是国内（广西/云南/中国）→ C 级。
5. **先搜 CM 系列**：海关口径进口量用 `CM000020xxxx` 前缀，该 agent 只搜了 ID/FU，漏了整条线（铜精矿进口数量就有真指标）。
6. **拉一次 series 验证非空**：`zhiji_api.py series <id>` 返回空 = 死数据，不得复用（ID01445986 就是空序列被复用 29 次）。
7. **单一 ID 复用 >3 次必须逐条人工复核**：这是批量填空的最强信号。
