## 一、库存类型分类与纳入标准（14 类逐一判定）

| 类型 | 判定 | 一句话理由 |
|---|---|---|
| A. LME 全球总库存 | **必须纳入** | 全球显性库存基准口径，跨品种跨周期比较的核心锚 |
| B. LME 注册仓单 | **必须纳入** | 真正可用于期货交割的合格库存，决定交割压力与逼仓风险 |
| C. LME 注销仓单 | **必须纳入** | 已申请提货、即将退出交割体系，是库存流出的前瞻信号；注销占比对短期价格有指示性 |
| D. LME 单分库库存 | **重要纳入**（品种差异化） | 对铜/铝/镍尤为重要——库存地理错配（美国堆铜、伦敦缺现货）是核心主线；对铅/锡意义较弱 |
| E. SHFE 仓单总量 | **必须纳入** | 国内期货交割库官方口径，日度更新，国内交割压力核心 |
| F. SHFE 分地区仓单 | **辅助参考** | 仓单地点分布有解释力，但披露粒度有限，使用频率低于 SMM 社库 |
| G. 社会库存/社库 | **必须纳入** | 隐性库存显性化口径，SMM 社库是判断国内真实供需拐点的第一指标 |
| H. 冶炼厂/再生铅/蓄电池企业成品库存 | **重要纳入**（品种差异化） | 对铅/锌/镍产业链库存传导至关重要；对铜铝意义较弱 |
| I. 保税库存 | **重要纳入** | 连接国内 SHFE 与海外 LME 的蓄水池，保税去化往往同步或领先于 SHFE+社库去库 |
| J. 港口库存/到港量/在途 | **辅助参考** | 对镍矿/铝土矿/铜精矿等原料有前瞻性，对精炼金属价格是间接影响 |
| K. 中间品库存 | **辅助参考** | 口径窄、样本覆盖窄、口径易变动，仅镍品种辅助验证，不作跨品种通用 |
| L. 期货/持仓/价格/升贴水/盈亏类 | **排除** | 是价格、资金、期现关系指标，不是库存本身（但升贴水可作配套验证） |
| M. 样本企业/N 家样本无加权 | **排除** | 无总量加权无法代表全市场，样本口径不透明会导致误判 |
| N. 产值/销售额/金额 | **排除** | 财务规模指标，与物理库存量无直接对应 |

## 二、优先级排序（必看 → 重要 → 可选 → 不看）

| 等级 | 类型 | 排序理由 |
|---|---|---|
| **必看** | A、E、G、C | 三层底库（全球显性+国内交割+国内现货链）+ 前瞻信号。注销仓单回测策略持有 5-60 天胜率 >50% |
| **重要** | B、I、H、D | 注册仓单配合 C 判交割压力；保税是套利闸门；厂库对铅锌镍是关键；分库在当前关税割裂市场下解释"美国堆铜、伦敦缺现货" |
| **可选** | F、J、K | SHFE 分地区数据粒度限制；港口到港对原料品种有前瞻但对成材滞后；中间品口径窄波动大 |
| **不看** | L、M、N | 非物理库存指标 |

**核心原则**：可交割实物优先、前瞻信号优先、总量口径优先。

## 三、主图 vs 副图的选择逻辑

### 主图四特征

| 特征 | 说明 |
|---|---|
| 总量口径清晰 | 可加总的物理量（吨/万吨），非样本均值、金额、比率 |
| 频率足够高 | 日度或周度更新，月度/季度频率不适合 |
| 市场参与者真实行动 | 反映产业客户和金融机构的实际交割/提货行为，非调研估算 |
| 趋势领先或同步于价格 | 能解释价格变动方向，非事后归因 |

### 四候选主图判断

| 候选 | 资格 | 理由 |
|---|---|---|
| LME 全球总库存 | **✅ 首选主图** | 日度、全球统一口径、历史序列最长、覆盖六品种 |
| SHFE 仓单 | **✅ 次选**（国内品种） | 日度官方数据，但易受单周集中交仓/提单扰动 |
| LME 注销仓单 | ⚠️ 副图预警 | 波动极大，适合作事件型预警；核心价值在注销占比而非绝对量 |
| 社会库存 | **✅ 必配副图/双主图** | 国内需求真实拐点最佳指标；周度、口径因品种而异，不可跨品种横向比 |

**结论**：主图选 **LME 全球总库存**，注销仓单占比作次轴，SMM 社库作副图，注销仓单单列事件预警图。

## 四、常见误区（6 个）

| # | 误区 | 正确做法 |
|---|---|---|
| 1 | 把注销仓单当实际出库 | 注销只是"已申请提货"，货仍在仓库；须与现货升水、近月月差交叉验证 |
| 2 | 只看 LME 总库存，忽略库存地理结构 | COMEX 移库可让 LME 数据失真；须做全球库存地理分布 |
| 3 | 把交易所库存当全市场库存 | 交易所库存只是显性部分；须 SHFE/LME/COMEX + SMM 社库 + 保税三层叠加 |
| 4 | 单周库存波动就下趋势判断 | 单周可能因集中交仓/节假日备货扰动（如 2018 年 3 月 LME 锌单日交仓 7.9 万吨，库存暴增 59%）；至少观察 2-4 周方向 |
| 5 | 混淆社库口径——把 SMM 社库当全口径 | SMM 社库仅覆盖中国大陆流通货源，不含海外保税和海外交易所；不同品种覆盖范围不同（铜=电解铜、铝=铝锭+铝棒、锌=七地、铅=五地） |
| 6 | 忽视升贴水与库存的背离信号 | 低库存不一定涨（南华铝案例：LME 铝库存跌至 1998 年以来最低但价格没涨）；库存↓+升水走阔+近月 Back 加深=真实短缺 |

## 五、方法论总结（同花顺原话）

> 库存研究框架的本质是追踪"可交割实物的时空分布变化"。主框架应锁定：
> 1. **交易所显性库存**（A/B/E）
> 2. **社会隐性库存**（G）
> 3. **保税缓冲库存**（I）
>
> 用注销仓单（C）做趋势前瞻信号，用分库结构（D）和产业链厂库（H）解释极端行情，用升贴水与期限结构验证库存信号真伪。排除 L/M/N 三类非物理库存指标。
