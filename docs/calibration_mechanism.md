# 单品种全量数据向同花顺校准机制

> **背景**：同花顺 v19 给的是「研报关注度」视角，**会漏细分数据**（铅库存实测发现：LME 新加坡分仓库系列、仁川、迪拜全部是它漏掉的）。同时它会把一些跨维度指标塞进来（库存页混入价格/利润）。校准机制 = 把我们的定稿 + 知几命中结果反馈给同花顺，让它评审 → 迭代 → 补齐。

## 一、机制概述（四步闭环）

```
① 封装"校准包" → ② 发给同花顺评审 → ③ 人工审核回传 → ④ 更新 v5 定稿 + 重跑命中 + 入库
```

## 二、Step 1: 封装「校准包」

**位置**：`analysis/iwencai/PB/calibration_20260828.md`

**内容结构**：
```markdown
# 铅(PB) 库存 校准包 v4 → v5

## 1. 我们已定稿的指标（15 张图 / 28 个指标）
| 编号 | 图名 | 指标 | 单位 | 频率 | 知几 ID | A/B/C |
|---|---|---|---|---|---|---|
| C01 | LME铅总库存 | i1 LME铅库存 | 吨 | 日 | a10193709 | A |
| C01b | 沪铅期货库存 | i28 SHFE库存周报 | 吨 | 周 | a10026547 | A |
| ... | ... | ... | ... | ... | ... | ... |
| C05b | LME注销占比 | i7/(i6+i7) 计算 | % | 日 | - | A(计算) |

## 2. 已被同花顺漏掉的细分数据（v4 我们自搜补齐）
- LME 铅 新加坡 注册仓单 (FU00023414)
- LME 铅 新加坡 注销仓单 (FU00023622)
- LME 铅 仁川 注册仓单 (a10100437)
- LME 铅 迪拜 非注册仓单 (a12809923)
- 五地社库分项 (广东/江苏/浙江/天津/上海, a10017065-070)
→ 问同花顺：这些是否还有遗漏？有无分仓库/分持有者/其他地区？

## 3. 我们的数据缺口（需要同花顺给替代/补充）
- 社库分持有者（冶炼厂/贸易商）→ 无公开数据
- 社库分品种（原生/再生）→ 无公开数据
- 铅隐性库存推算 → 无量化序列
→ 问同花顺：是否有其他替代口径？或确认确实不可得？

## 4. 复合图组合评审（专业度）
- C02 LME 注册+注销 双柱 → 是否应改为面积图更直观？
- C05 沪伦库存对比 → 是否应加入注销占比作为第三条轴？
- 其他复合图搭配是否有行业惯例？

## 5. 维度边界评审
- 我们把「沪伦比价」「进口盈亏」从库存页移走（属价格/价差维度）
- 我们把「精矿工厂库存」「废料库存」从 4.4 移到 4.6 又并回 4.4
→ 问同花顺：这些归属判断是否合理？还有无其他跨维度指标？

## 6. 我们已有的纠错库（供参考，防止同花顺重复推荐）
（附 indicator_correction.db correction 表 8 条记录摘要）
```

## 三、Step 2: 发给同花顺（Prompt 模板）

**模板**：
```markdown
以下是一份关于铅(PB) 库存维度的完整指标清单，我们已基于研报视角做了初步筛选，并标注了哪些是研报常见、哪些是我们从数据源反推补齐的。

请你以「专业期货研究员 + 数据源专家」的视角评审：

1. 我们的清单里，哪些指标其实还有更细的拆分我们没发现？（比如分地区/分仓库/分持有者）
2. 哪些数据缺口是否确实无替代方案？还是有其他数据源/口径可以替代？
3. 我们的复合图组合方式是否符合行业惯例？有无更专业的可视化建议？
4. 我们的维度边界划分是否合理？（比如把价格类指标从库存页移走）
5. 有没有研报中常用但我们的清单里完全没出现的「隐藏指标」？

请**只给结论和替代建议，不要讲经济学逻辑/相关性分析**。
```

**输出存档**：`analysis/iwencai/PB/calibration_response_20260828_v2.md`

## 四、Step 3: 人工审核回传

**审核清单**：
- [ ] 是否有**真实遗漏**（如其他 LME 分仓库地区、分持有者数据）
- [ ] 同花顺推荐的「替代口径」是否合理（值域是否真对应盈亏/价差而非价格水平）
- [ ] 复合图建议是否采纳（采纳/不采纳 + 理由）
- [ ] 维度边界判断是否一致
- [ ] 有无推荐指标**重复**我们已拒收的（查纠错库）

**产物**：`analysis/iwencai/PB/calibration_review_20260828.md`（带审核结论 + 采纳/不采纳表）

## 五、Step 4: 更新 v5 定稿 + 重跑 + 入库

1. 基于审核结论更新 `pb_prompt/Pb_看板指标定稿_v5.md`
2. 对**新增指标**复制 STEP 3 清单模板，写 `analysis/iwencai/PB/4_calib_v5_verify_list.json`
3. 跑 `zhiji_batch_verify.py --input 4_calib_v5_verify_list.json`
4. 入库：bump `indicators_v1.json` 到 v1.5 + 追加 changelog
5. 跑 `refresh_cache.py`
6. 重跑 build 脚本生成新版 HTML
7. git commit `[REFRESH] 铅库存 v5: 校准后新增N图` + push
8. STATUS.md 加一行

## 六、校准包的复用性

- **其他目录**（价格/供应/需求/进出口/成本/平衡）做校准时，**复用同一模板**，换品种/维度
- **其他品种**（镍/铜/铝/锌/锡/锂/硅）做同品种库存校准时，**复用同一模板**，换品种代码
- 模板存 `pb_prompt/calibration_template.md`
