# 同花顺问财方法论回复（2026-09-03）

> 来源：同花顺问财 AI 对话（登录态用户"田允晴"），2026-09-03 现场提问获取。
> 问题：有色金属产业研究框架中，如何筛选主图指标、避免跑偏、判断口径、识别高认可度指标。

---

## 一、筛选"一个最核心指标"的六条标准

产业研究每个节点选主图指标，本质是在**信息密度、可得性、市场定价相关性**三者之间做权衡。

| 筛选维度 | 约束条件 | 说明 |
|---|---|---|
| **口径宽度** | 必须是行业总量或全球口径，不接受单矿区/单企业/单分库作为主图 | 供给节点不能用"某矿山产量"替代"全球精炼金属产量"；库存节点不能用"LME某分库"替代"LME全球总库存" |
| **数据频率** | 日度 > 周度 > 月度；主图至少周频，核心交易品种应日频 | LME库存日度更新，上期所库存周度更新——日频更适合做主图，周频作校验 |
| **可得性与持续性** | 公开可回溯、发布时间固定、历史序列连续≥5年 | LME库存自2022年镍事件后恢复每日发布，序列完整；第三方调研数据若更新不稳定只能作辅助 |
| **市场定价相关性** | 指标变动方向与价格方向有稳定传导逻辑，被交易员每日/每周跟踪 | LME库存变化是日内定价因子；中国精炼金属月度产量是月度定价锚 |
| **非价格性** | 节点指标不应被价格"污染"——库存节点选库存量而非库存价值 | 避免循环论证：用价格类指标解释价格行为 |
| **全球可比对性** | 同一指标在铜铝锌镍锡铅六品种间口径一致，便于横向比较 | LME总库存对六金属均采用"注册仓单+注销仓单"口径，可直接横向对比去库/累库斜率 |

**实操原则**：优先选**交易所官方日频总量口径**作为主图，第三方调研高频数据（SMM开工率、Mysteel社会库存等）放在副图或注释中使用。

## 二、避免指标跑偏的四层校验规则

### 1. 概念纯度校验
指标是否直接度量该节点的物理量，而非价格或估值映射？
- ✅ 库存节点：LME总库存（吨）——直接度量实物存量
- ❌ 库存节点："库存价值"或"库存对应的期货市值"——已被价格污染
- ✅ 供给节点：统计局"精炼铜产量（月度吨）"——实物产出
- ❌ 供给节点："某铜企矿产铜产量"——单企业数据，不代表行业总量

### 2. 口径宽度校验
指标覆盖范围是否≥该金属的主要贸易流？

| 节点 | 通过标准 | 失败案例 |
|---|---|---|
| 供给 | 全球产量或中国产量（占全球比重的总量口径） | 单个矿山产量、单个冶炼厂开工率 |
| 库存 | LME全球总库存 + SHFE库存（内外双口径交叉验证） | LME单一仓库库存、单一城市社会库存 |
| 需求 | 终端消费量/开工率（如铜线缆开工率、铝下游加工龙头开工率） | 单一下游企业订单量 |
| 进出口 | 海关口径净进口量（月度吨） | 单口岸通关量、单一贸易商进出口额 |
| 成本利润 | TC/RC加工费（行业均值）、电解铝完全成本指数 | 单一冶炼厂财务成本 |

### 3. 交叉验证校验
该节点指标变动方向能否被相邻节点指标解释？
- 供给端产量↑ → 库存端应累库（若去库则说明需求超预期或出口增加）
- 成本端TC↓（加工费走低）→ 冶炼利润压缩 → 供给端应出现减产或开工率下降

### 4. 领先性校验
指标是否具备前瞻信号而非纯滞后确认？
- LME注销仓单占比是库存变化的领先信号
- SHFE铜的周度开工率是铜下游消费的前瞻高频指标
- 电解铝的产能利用率是供给弹性的先行约束指标

## 三、口径选择：镍库存三选一

| 候选指标 | 口径属性 | 是否适合作主图 | 理由 |
|---|---|---|---|
| LME镍库存·迪拜分库 | 单分库口径，地域窄 | ❌ 不适合 | 仅反映迪拜仓库的交割与移仓行为，不代表全球供需 |
| LME镍库存·全球总计 | 全球交易所口径，日频 | ✅ 首选主图 | 注册仓单+注销仓单合计，覆盖全球LME认可仓库，是机构研报、交易终端默认口径 |
| 上期所镍仓单总量 | 国内期货口径 | ⚠️ 辅助副图 | 反映国内交割压力与内外价差套利，与LME库存结合可判断内外盘库存迁移方向 |

**判断口径过窄的统一标准：**

| 过窄信号 | 具体阈值/规则 |
|---|---|
| 覆盖单一地理节点 | 单仓库、单港口、单矿区 → 一律降级为辅助指标 |
| 覆盖单一企业/样本 | 样本企业<20家且未做加权汇总 → 仅能作高频情绪指标，不能作趋势主图 |
| 数据中断频率高 | 月度更新不稳定、历史序列断层>3个月 → 不适合做时序主图 |
| 口径频繁变更 | 统计范围调整且未做回溯修正 → 趋势线断裂，不可比 |
| 存在替代的全球口径 | 有LME/SHFE/WBMS等总量口径 → 优先总量口径，子口径仅作结构拆解 |

**镍库存完整框架**：主图用 LME镍库存全球总计（日频），副图叠加上期所镍仓单 + LME注销仓单占比（领先信号），构成"全球显性库存+国内交割库存+出库前瞻信号"三维验证。

## 四、高认可度指标的五项特征

| 特征 | 说明 | 实例 |
|---|---|---|
| 官方源头可追溯 | 来自交易所、统计局、行业协会等权威发布机构 | LME库存、中国精炼铜产量（国家统计局） |
| 频率与时效平衡 | 日频用于交易型品种，月频用于产能/产量类慢变量 | LME库存每日16:00更新；月度产量次月发布 |
| 历史序列长且口径稳定 | ≥5年连续序列，中间无重大口径调整 | LME镍库存自2022年事件后恢复完整日度序列 |
| 被定价主体日常使用 | 交易员、基金经理每日/每周例行查看 | LME六大金属库存是期货公司周报固定模块 |
| 能触发价格反应 | 指标发布当日或次日，成交量和波动率可观测放大 | LME库存超预期去库→铜铝镍短线冲高 |

## 六、方法论总结：三个"不要"

1. **不要用价格代理指标替代节点指标**——库存节点选库存量而非库存价值，供给节点选产量而非产值。价格是所有节点的"结果变量"，不应反向充当"原因变量"的度量。

2. **不要用高频但窄口径的数据替代总量口径**——SMM单周开工率、单一矿山产量、单一港口库存可以作为高频先行信号放在副图，但主图必须用总量口径（统计局月度产量、LME全球库存），否则趋势判断会因样本偏差失真。

3. **不要忽略内外口径的映射关系**——铜铝锌镍锡铅均为全球定价品种，中国是最大消费国但非唯一定价中心。主图框架建议采用"LME全球口径为主图 + SHFE国内口径为副图"的双层结构，当内外库存背离时往往正是趋势拐点的前兆。

**核心思想**：主图指标要回答"方向"，副图指标要回答"节奏"。主图用总量口径定方向（全球库存去/累、产量增/减），副图用高频窄口径定节奏（开工率拐点、注销仓单变化、社会库存周变动），两者交叉验证后再下判断。
