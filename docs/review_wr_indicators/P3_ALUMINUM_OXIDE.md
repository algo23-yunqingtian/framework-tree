# P3: 氧化铝品种归属建议

## 背景

当前 `tree_config.json` 中没有氧化铝品种节点（只有 CU/AL/ZN/NI/SN/SI/LI/PB）。
22条氧化铝指标入库后处于"有数据无归属"状态。

## 各选项分析

### 选项 A: 新增 ALX 品种节点
- **优点**: 氧化铝作为独立品种逻辑清晰，在周报中氧化铝和电解铝通常是独立分析的板块
- **缺点**: 需改 tree_config.json + 建 6 个板块页面（产量/价格/库存/矿端/利润/开工率）
- **适用场景**: 如果项目后续持续维护，氧化铝有独立数据源

### 选项 B: 并入铝板块（AL）作为子类别
- **优点**: 铝产业链逻辑自洽（铝土矿→氧化铝→电解铝），代码改动最小
- **缺点**: 氧化铝和电解铝的周报分析维度不同，混在一起可能降低可读性
- **适用场景**: 如果主要是做产业链全景分析

### 选项 C: 暂不建页，只留数据
- **优点**: 零改动成本
- **缺点**: 数据无法在页面查看，后续维护困难
- **适用场景**: 如果短期不会用到氧化铝页面

## 建议: 选项 B（并入铝板块）

**理由**:
1. **产业链逻辑**: 铝土矿 → 氧化铝 → 电解铝 是标准铝产业链，合并到 AL 下符合行业惯例
2. **代码成本最低**: 不需要改 tree_config.json，只需在铝板块下增加一个"氧化铝"模块
3. **数据关联**: 氧化铝和电解铝有大量交叉指标（如电解铝厂氧化铝库存、氧化铝利润模型等），放在一起便于分析
4. **周报实践**: 实际周报中氧化铝和电解铝经常在同一条产业链报告里分析

**实现方式**: 在 tree_config.json 的 AL 节点下新增一个子节点 `aluminum_oxide`，将64条氧化铝指标的 module 字段映射到该子节点下。

## 64条氧化铝指标分布

| 模块 | 数量 | 说明 |
|------|------|------|
| 产量 | 4 | 阿拉丁/SMM 产量数据 |
| 价格 | 4 | 现货/长协/FOB |
| 库存 | 9 | 厂内/站台/站台在途/期货库存 |
| 矿端 | 12 | 铝土矿产量/到港/库存/进口 |
| 矿价 | 1 | 铝土矿CIF |
| 利润 | 1 | 广西利润模型 |
| 开工率 | 1 | 海外开工率 |
| 进出口 | 3 | 出口/进口/净出口 |
| 产能 | 1 | 海外产能预测 |
| 其他 | 8 | 其他交叉指标 |

## 注意事项

1. **地区区分**: 部分氧化铝指标实际指向海外（wr28:海外产能、wr57:海外开工率、wr91:美国进口），并入AL后需标注地区
2. **口径问题**: 氧化铝有"中国口径"和"全球口径"两种，混在一起可能造成混淆
3. **后续扩展**: 如果后续需要独立氧化铝页面，可从AL下拆分出来
