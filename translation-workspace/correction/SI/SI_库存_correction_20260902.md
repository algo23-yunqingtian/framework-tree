## 缺项汇总

1. **社会库存全国总量**：知几仅 SMM 分地区（昆明 a10020032/天津港 a10020033），无全国总量 → 组合或外部源
2. **工厂/市场库存子项**：知几无独立子项，用 a12811428 下游原料库存近似（口径不同需标注）
3. **注销仓单占比/库存天数**：衍生指标，知几无独立
4. **分产区厂库**：SMM 周报定性，非标准化

**移出 11 个**：LME系列4 + 隐性/在途5 + 库存与价格联动2；**保留/修正 7 个**：仓单总量/增减/注销占比(衍生) + 社会库存/工厂库存/市场库存/分产区厂库。
