## 缺项汇总

1. **海外工业硅冶炼产量**（巴西/挪威/美国/法国/俄罗斯）：知几无此口径 → 外部源(硅业分会/USGS/亚洲金属)
2. **巴西自身金属硅出口量**：知几仅有"中国→巴西"出口，非巴西自身出口 → 外部源(亚洲金属)
3. **工业硅社会库存全国总量**：知几仅 SMM 分地区(a10020032昆明/a10020033天津港)，无全国总量 → 需组合或外部源(SMM 49.3万吨口径)
4. **工业硅月进口总量**：知几仅分国别 → 需组合或外部源(海关)
5. **冶炼厂检修量**：定性指标，知几无标准化量值
6. **美国工业硅产量**：知几有 USGS ID01552216（硅铁及金属硅合计）可近似使用

**已移出指标（7 个）**：海外硅矿产量/开工率/产能利用率/检修量/进口量 + TC加工费×2。
**已替换指标（6 个）**：海外系列→工业硅冶炼产量、美巴→USGS/亚洲金属、矿产量→工业硅产量、矿开工率→工业硅开工率、矿产能利用率→工业硅产能利用率、矿进口→产品进口。
