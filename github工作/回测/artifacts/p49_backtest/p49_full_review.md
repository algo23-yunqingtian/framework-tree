## ② 数据源缺陷

### 2.1 VOL成交量时序错位

**缺陷等级**: 🔴 CRITICAL — VOL完全不可用

| 指标 | CLOSE | OI | SETTLE | VOL |
|------|-------|----|----|-----|
| **CSV行数** | 2400 | 2400 | 2400 | **162** |
| **独立日期数** | 400 | 400 | 400 | **162** |
| **与CLOSE日期重叠** | — | — | — | **0 (0%)** |
| **对齐后有效行** | 2400 | 2400 | 2400 | **0** |

**根因分析**:

1. DSHC-F01采集时，VOL指标通过WSD函数拉取的日期区间与CLOSE/OI/SETTLE不同步
2. 162行VOL数据分布在6个品种上 (每品种约27行)，日期与CLOSE的400个交易日完全不重叠
3. 这是WDF采集脚本在分指标采集时的时间窗口偏移导致的系统性缺陷

**影响评估**:

| 影响项 | 程度 |
|--------|------|
| 成交量因子不可用 | 严重 — 无法使用VOL构建任何因子 |
| 对齐后交易日减少 | 427→400 (27天仅有VOL数据被丢弃) |
| 因子数量减少 | 7因子中无VOL因子 |
| 策略信号维度 | 从4维降至3维 (momentum + spread + OI) |

**处理措施**:
- P1.2对齐阶段检测到VOL日期与CLOSE零重叠后，标记为ffill_forward
- VOL列全部为NULL，不参与因子生成
- 回测未使用任何VOL相关因子
- 本缺陷已记录为DSHC-F01数据质量问题，需在上游采集流程修复

## ④ 后续优化选项

### 4.1 方向一：新增因子

| 因子 | 数据需求 | 预期效果 | 实现复杂度 | 优先级 |
|------|----------|----------|------------|--------|
| **成交量加权动量** | VOL数据修复后 | 过滤低流动性日期的虚假动量信号 | 中 | 🔴 P0 (依赖VOL修复) |
| **波动率因子** | CLOSE历史 | 低波动期增加仓位, 高波动期减少 | 低 | 🟡 P1 |
| **跨品种相对强弱** | 6品种CLOSE | 做多强品种, 做空弱品种, 中性对冲 | 中 | 🟡 P1 |
| **持仓量变化加速** | OI 2阶差分 | 捕捉资金流入/流出加速趋势 | 低 | 🟡 P1 |
| **价差率动量** | spread_pct | 捕捉结算价偏离收敛趋势 | 低 | 🟢 P2 |
| **跨期价差因子** | 需多合约数据 | 近远月价差方向性 | 高 | 🟢 P2 (数据不足) |
| **情绪/持仓结构** | 需期货持仓报表 | 多空比例方向性 | 高 | 🟢 P2 (数据不足) |

### 4.2 方向二：调仓频率

| 方案 | 描述 | 交易次数估算 | 成本估算 | 预期效果 |
|------|------|-------------|----------|----------|
| **周度调仓** | 每周评估信号, 减少频繁切换 | 52-56次/年 | ~2.6% | 降低噪声, 成本减半 |
| **双周调仓** | 每两周评估 | 26-30次/年 | ~1.3% | 进一步降噪 |
| **信号阈值过滤** | 仅当\|signal\|>0.5时交易 | 减少30-50% | 成本降低 | 过滤弱信号 |
| **波动率自适应** | 高波动期停止交易 | 动态 | 成本可控 | 避免极端行情 |
| **组合再平衡** | 每周等权再平衡6品种 | 52次 | ~0% | 控制单品种风险 |

**推荐**: 周度调仓 + 信号阈值过滤(0.3) 作为第一版优化，预计可减少40-60%交易次数。

### 4.3 方向三：仓位管理

| 策略 | 描述 | 预期效果 | 实现复杂度 |
|------|------|----------|------------|
| **波动率目标仓位** | 目标年化波动15%, 按品种波动率分配仓位 | 等风险预算, 降低尾部风险 | 中 |
| **Kelly公式** | 基于历史胜率/盈亏比计算最优仓位 | 理论最优增长, 但需可靠估计 | 中 |
| **回撤控制** | 回撤超10%减半, 超20%清仓 | 硬性止损, 保护本金 | 低 |
| **品种权重上限** | 单品种最大30%, 总敞口最大80% | 分散化, 降低集中度风险 | 低 |
| **风险平价** | 各品种风险贡献等权 | 最优分散, 需协方差矩阵 | 高 |

**推荐**: 波动率目标仓位(15%目标) + 回撤控制(20%清仓) 作为第一版优化。

### 4.4 优化路线图

```
Phase 1 (数据修复):        修复VOL采集时序错位 → 补采VOL数据 → 验证对齐
Phase 2 (因子增强):        新增波动率因子 + 持仓量加速因子 + 相对强弱因子
Phase 3 (频率优化):        周度调仓 + 信号阈值0.3过滤
Phase 4 (仓位管理):        波动率目标仓位 + 回撤控制
Phase 5 (组合优化):        风险平价权重 + 跨品种对冲
```
