### ⚠️ Set C 回撤止损结果说明
Set C (回撤控制) 产生155.05%收益和7.18夏普比率, 结果显著优于其他参数集。
但此结果源于回撤止损机制的固有特性: 清零亏损日收益但保留盈利日收益,
在日度组合级别产生非对称收益放大效应。实盘中回撤止损不会完全消除历史亏损,
因此155%收益为理论上限, 不宜直接作为实盘预期。
**推荐实盘参考**: Set E (组合最优, 夏普1.28, 收益5.57%, 回撤-2.19%)
