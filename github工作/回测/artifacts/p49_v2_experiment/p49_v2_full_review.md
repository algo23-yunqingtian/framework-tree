#### 3.2.2 信号计算公式

```python
# 1. Z-score归一化 (全局, 非滚动)
for each factor f:
    z_score[f] = (factor[f] - mean(factor[f])) / std(factor[f])

# 2. 等权复合
signal = (1/14) × Σ(z_score[f_i] for f_i in all_factors)

# 3. 方向性仓位
if signal > 0.3:      position = +1.0  (做多)
elif signal < -0.3:   position = -1.0  (做空)
else:                 position =  0.0  (空仓)
```

**信号特性**:
- 100%命中率因子: spread_cs, spread_pct, momentum_20d, cross_sectional_momentum_20d (4个)
- 负相关因子: realized_vol_20d (IC=-0.017), oi_slope_14d (IC≈0)
- 实际有效因子数: ~8-10个 (IR > 1)

### 3.3 仓位规则

#### 波动率目标仓位

```python
target_vol = 0.15  # 年化目标波动率15%
max_weight = 0.50  # 单品种最大权重50%

# 动态仓位权重
realized_vol = 20日已实现波动率 (基于CLOSE收益率, 非VOL列)
vol_weight = clip(target_vol / realized_vol, 0, max_weight)

# 应用

```

**波动率目标机制**:
- 当 `realized_vol = 15%` → `vol_weight = 1.0` → 乘以 `max_weight=0.5` → 50%仓位
- 当 `realized_vol = 30%` → `vol_weight = 0.5` → 乘以 `max_weight=0.5` → 25%仓位
- 当 `realized_vol = 10%` → `vol_weight = 1.5` → clip到`1.0` → 50%仓位
- 实际最大仓位: 50% (受 `max_weight` 约束)

```python
drawdown_stop = {
```

**顺序模拟逻辑**:
```python
for each day:
    equity = equity × (1 + strategy_return)
    drawdown = (equity - running_max) / running_max
```

## ④ Set C 风险提示

### 4.1 <font color="red">⚠️ 重大风险提示: Set C 回撤止损结果不可用于实盘</font>

> <font color="red">**Set C 结果: 总收益 +155.05%, 夏普 7.1769 — 这是回撤清零机制带来的理论极值, 明确标注不适合实盘使用。**</font>
>
> <font color="red">**🔴 警告：该结果不可复制至实盘环境。回测中的回撤止损在日度组合级别完美执行，消除了已发生的亏损但保留了盈利，产生非对称收益放大。实盘中止损不可能消除已发生的亏损，只会减少未来暴露。**</font>
>
> <font color="red">**🔴 结论：Set C 仅作为回测算法上界参考，禁止实盘使用。实盘推荐方案为 Set E（组合最优）。**</font>

### 4.2 问题机制

Set C 使用 `drawdown_stop` 策略, 核心逻辑:

```python
for each day:
    dd = (equity - running_max) / running_max
    
    if dd < -0.20:
        adjusted_return = 0.0       # 回撤超20%: 收益归零
    elif dd < -0.10:
        adjusted_return = return × 0.5  # 回撤超10%: 收益减半
    else:
        adjusted_return = return     # 正常
    
    equity = equity × (1 + adjusted_return)
    running_max = max(running_max, equity)
```

### 4.3 非对称收益放大效应

| 特征 | 说明 |
|------|------|
| **盈利日** | 收益正常计入, 净值正常增长 |
| **亏损日** | 回撤超10%时收益减半, 超20%时收益归零 |
| **核心问题** | 亏损被消除, 但盈利被保留 → 收益非对称放大 |
| **实盘差异** | 实盘止损不会消除已发生的亏损, 只会减少未来暴露 |
| **回测偏差** | 回测在日度组合级别, 止损前已发生的亏损被"清零" |

### 4.4 理论 vs 实盘差异

| 维度 | 回测 (Set C) | 实盘预期 |
|------|-------------|---------|
| 收益 | +155.05% | 远低于此 |
| 夏普 | 7.18 | 远低于此 |
| 最大回撤 | -3.42% | 取决于实际止损执行 |
| 止损有效性 | 完美执行 | 存在滑点/延迟 |
| 交易成本 | 5.77% | 更高 (更频繁止损触发) |

### 4.5 结论

<font color="red">**Set C 结果应视为回撤止损机制的理论上限, 而非可实现的实盘预期。任何基于Set C参数的实盘决策都是错误的。**</font>

推荐实盘参考: **Set E (组合最优)** — 收益+5.57%, 夏普1.28, 回撤-2.19%。Set E 虽然也包含回撤止损逻辑, 但由于周度调仓+波动率目标+阈值过滤的综合效果, 实际回撤远低于10%触发线, 回撤止损机制几乎未被触发, 结果更具实盘参考性。

<font color="red">**本警告已永久冻结于 `strategy_set_e.lock.json` 的 `frozen_risk_disclosures` 字段，以及本复盘文档的不可变版本控制中。**</font>

### 6.6 因子相关性矩阵扩展分析

#### 6.6.1 相关性强弱分档

| 相关等级 | 对数 | 最高|r| | 影响 |
|---------|------|--------|------|
| 🔴 强相关 (|r|>0.7) | 3对 | -0.93 | 信息冗余, 等权复合时贡献重复 |
| 🟡 中等相关 (0.4<|r|≤0.7) | 4对 | 0.52 | 适度冗余, 可提供互补信息 |
| 🟢 弱相关 (|r|≤0.4) | 14对 | 0.42 | 独立信息源, 应保留 |

#### 6.6.2 3对高相关因子的详细分析

**对1: realized_vol_20d ↔ vol_target_weight (r = -0.93)**
- **原因**: vol_target_weight = clip(target_vol / realized_vol_20d, 0, 0.5), 是realized_vol的数学倒数变换
- **影响**: 在14因子等权复合中, 这两个因子贡献了约28.6%的信号权重, 但实际仅传递1个独立信息
- **建议**: 剔除vol_target_weight, 或将其从因子池中移出(它是仓位参数而非信号因子)

**对2: spread_cs ↔ spread_pct (r = +0.83)**
- **原因**: spread_cs = CLOSE - SETTLE (绝对价差), spread_pct = spread_cs / CLOSE × 100 (相对价差), 两者本质相同
- **影响**: 这两个因子贡献了28.6%的信号权重, 但实际仅传递1个独立信息(价差信号)
- **建议**: 保留spread_cs (IC更高), 剔除spread_pct, 或仅保留一个

**对3: oi_change_rate_7d ↔ oi_change_accel_7d (r = +0.82)**
- **原因**: oi_change_accel_7d = oi_change_rate_7d的差分(加速度), 是变化率的导数
- **影响**: 这两个因子贡献了28.6%的信号权重, 但实际仅传递1个独立信息(OI趋势信号)
- **建议**: 保留oi_change_rate_7d (变化率), 剔除oi_change_accel_7d (加速度)

#### 6.6.3 4对中等相关因子的详细分析
