## 4. 监控与联动动作

1. DSHD 需对条件回测链路进行连续日志监控。
2. 对任何 HOLD 因子访问、读取、计算或触发，立即告警。
3. 对任何越界写入、异常泄漏命中、权限异常，立即升级处置。
4. 触发撤销条件时，条件通道立即关闭，临时许可立即失效。

## 5. 撤销规则

出现以下任一情况，立即撤销临时许可并关闭条件通道：

1. 任一 HOLD 因子被触发。
2. 3 个条件因子发生越界计算或数据读取。
3. 灰度日志显示异常泄漏命中。
4. 审计链路发现未授权访问。
