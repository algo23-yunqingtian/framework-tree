## 3. 约束条件

1. 仅允许访问上表中的 7 张 Wind 数据表。
2. 仅允许 2023-01-01 至 2024-12-31 时间区间内的数据。
3. 仅允许 `FACTOR-004 / FACTOR-006 / FACTOR-007` 三个因子对应的只读查询。
4. 严禁任何 HOLD 因子访问、计算、读取或回测触发。
5. 严禁跨表联查、跨时间窗口查询、批量全量拉取或聚合导出。
6. 严禁将该凭证用于生产放行、全局 Gate 打开或 Release Permit 签发。

## 4. 撤销触发条件

出现以下任一情况，立即吊销本临时凭证并关闭条件通道：

1. 任一 HOLD 因子被触发或读取。
2. 发生跨表、跨时间范围或超出授权表的查询。
3. 出现异常数据拉取、越权访问或未授权日志事件。
4. DSHD 审计发现数据拉取异常或链路边界违规。
5. 任何新的泄漏证据或代码层越界命中。
6. DSHA 连通性测试结果异常并要求暂停。

## 5. 审计与联动要求

1. DSHA 必须仅使用该凭证进行 Wind 连通性验证。
2. DSHD 必须持续监控 Wind 调用日志、访问范围和异常告警。
3. 所有访问日志必须可追溯到因子 ID、数据表、时间区间和调用时间戳。
4. 任何违规立即升级至 DSHC，执行吊销凭证与撤销条件放行。
