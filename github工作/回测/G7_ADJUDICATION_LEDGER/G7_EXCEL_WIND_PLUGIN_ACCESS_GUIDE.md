# G7 Excel + Wind 插件接入操作指引（条件灰度）

> **文档ID**: DSHC-P66-G7-EXCEL-WIND-PLUGIN-GUIDE-001  
> **生成时间**: 2026-10-16 GMT+8  
> **适用范围**: 仅限受限灰度条件放行链路  
> **来源标记**: `source_path=excel_wind_terminal` / `EXCEL_WIND_FALLBACK`  
> **允许因子**: FACTOR-004 / FACTOR-006 / FACTOR-007  
> **禁止因子**: FACTOR-001 / FACTOR-002 / FACTOR-003 / FACTOR-005  
> **时间区间**: 2023-01-01 至 2024-12-31  
> **访问模式**: 只读 / 本地导出 / 非API直连  
> **全局 GATE**: CLOSED/HOLD  
> **Release Permit**: NOT_ISSUED  

---

## 1. 方案说明

当前本地未持有可用 Wind API 账号 / 密钥，因此本次条件灰度数据获取方式改为：

1. 依托本地 Wind 桌面客户端保持登录状态。
2. 在 Excel 中通过 Wind 插件公式发起查询（`WSD` / `WTD` 或等价插件公式）。
3. 将查询结果落表并保存为 `.xlsx` 文件。
4. DSHA 仅读取本地 Excel 文件获取原始数据，不再依赖 WindPy / wpy 直连 API。

> 本方案为条件灰度备用链路，不等同于正式生产接入，不签发正式 Release Permit，不改变全局 GATE。

---

## 2. 边界规则

### 2.1 允许范围

| 项目 | 值 |
|---|---|
| 允许因子 | FACTOR-004 / FACTOR-006 / FACTOR-007 |
| 允许表 | 仅限 7 张 Wind 数据表 |
| 时间范围 | 2023-01-01 至 2024-12-31 |
| 访问模式 | 只读导出 |
| 数据来源标记 | `excel_wind_terminal` |

### 2.2 禁止范围

1. 禁止访问 4 个 HOLD 因子：`FACTOR-001 / FACTOR-002 / FACTOR-003 / FACTOR-005`。
2. 禁止跨表查询、跨时间窗口查询、全量导出。
3. 禁止把 Excel 结果伪装为 WindPy 自动快照。
4. 禁止将未复现的公式、缺失审计字段的数据结果直接入库。
5. 禁止用本方案打开全局 Gate 或签发正式 Release Permit。

### 2.3 审计要求

1. 每次查询都必须在单元格公式层面保留可追溯字段：
   - 因子 ID
   - 数据表名
   - 开始日期 / 结束日期
   - 查询时间戳
   - 操作者标记（DSHA）
2. 每次导出的 `.xlsx` 文件必须附带：
   - 文件 SHA256
   - 文件大小
   - 导出时间
   - 导出机器 / 客户端版本
   - 导出操作者
3. 文件命名建议使用：`factor_id__table__start__end__YYYYMMDD.xlsx`。

## 4. 操作规范

### 4.1 查询写入

1. 仅在 Excel 单元格内写入 Wind 插件公式。
2. 每条公式只能覆盖一个因子、一个表、一个时间区间。
3. 单次查询不得跨表、跨时间窗口。
4. 查询完成后立即保存 `.xlsx`，并记录导出时间戳。

### 4.2 公式约定

- 只允许使用 Wind 插件公式完成查询。
- 查询参数必须在单元格中显式展开，不写隐藏参数。
- 不允许用公式做跨表联查或跨窗口聚合。
- 如需拆批，每批单独保存文件，不合并成不可追溯的大文件。

### 4.3 导出与归档

1. 导出目录按因子 / 数据表 / 日期分层。
2. 每个导出文件必须单独生成 SHA256。
3. 导出记录必须同步写入审计摘要与 manifest。
4. 任一文件不可复现时，必须标记为 `MANUAL_AUXILIARY_DATA`，不得直接替代正式主数据。

---

## 5. 熔断规则

出现以下任一情况，立即熔断并停止 Excel 查询：

1. Wind 桌面客户端掉线，公式返回空值或报错。
2. 查询范围超过 2023-01-01 ~ 2024-12-31。
3. 查询表超出 7 张授权表范围。
4. 任一 HOLD 因子被误写入查询。
5. 任一导出文件无法生成 SHA256 或无法追溯来源。
6. DSHD 审计发现越界访问或异常链路。

熔断后：
- 暂停后续查询；
- 回滚未完成导出；
- 记录异常事件；
- 等待 DSHC 复核。

---

## 6. 与 WindPy / wpy 的关系

- 本指引仅定义 Excel 插件备用链路。
- 不恢复 WindPy / wpy 直连 API 调用。
- 不替代 WindPy 主路径的审计字段要求。
- 若未来重新启用 API 凭证，必须重新生成单独的凭证记录与访问边界，不与本 Excel 链路混用。

---

本指引用于条件灰度下通过 Excel + Wind 插件获取 3 个条件放行因子的原始数据。它只允许受限的本地导出、只读查询和可追溯归档，不改变全局 GATE，不触发生产放行，不签发正式 Release Permit。
