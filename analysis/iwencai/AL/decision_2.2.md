# AL·2.2 现货与升贴水 Step2 取舍决策

来源：`divergence_2.2.md`（同花顺发散，2026-08-30）
节点边界：铝**现货价 与 期货价之间的价差体系**——现货升贴水、基差、现货升水；回答「现货供需紧张程度如何，是否领先期货 1-2 个交易日」。

## 候选指标（按优先排序）

1. **铝现货升贴水**（现货价 - 沪铝主力收盘价）—【正主】本节点核心，直接量化现货相对期货的紧张度；SMM/Mysteel 日度可得，是全节点第一指标。
2. **铝基差**（现货价 - 主力收盘价）—【辅助】与升贴水数值口径高度重合（发散数据同为 +150 元/吨），保留作交叉验证，不做第二张主图。
3. **铝现货价** —【辅助】价差的分母端，用来定位「价差扩大是价涨还是贴水收窄」；日度可得性高。
4. **铝现货升水**（现货价 - 近月合约价）—【辅助】比基差更贴近交割口径，是现货紧张度的补充刻度。
5. **LME铝现货升贴水** —【辅助】海外现货紧张度的对照尺，与 2.3 海外价格共享数据源，本节点用于内外盘对照。
6. **沪铝现货月-主力月差**（LME 现金-3M 类比）—【辅助 · 待验证】原发散记作「铝期货近月合约升贴水」，实为期限结构，仅保留与现货升贴水同图的校验位。

## 排除项

| 排除指标 | 原因 | 归属 |
|---|---|---|
| 铝仓单注册量 | 属仓单/库存类；AI 仅以「升贴水先行信号」纳入，不落在价差边界内 | 4.2 仓单 |
| LME铝注销仓单占比 | 库存结构指标，AI 自注归属隐性/在途库存 | 4.5 隐性/在途库存 |
| LME铝总库存、LME铝注销仓单 | 库存类，原发散图3/图6使用，仅可作右侧细线 | 4.5 / 4.2 |
| 铝期货近月合约升贴水 | 定义是近月-远月，属期限结构；与「铝现货升贴水」混用会污染口径 | 2.4 价差体系 |
| 沪铝主力合约收盘价 | 价格水平而非价差，本节点只需作差值口径 | 2.1 盘面结构 |
| 铝进口盈亏 | 套利测算，非现货价差 | 6.2 精炼金属进出口 |
| 沪伦比 | 内外盘比价，非现货升贴水 | 2.4 价差体系 |

## 落库建议

- 口径必须分清三个：升贴水（对主力）、基差（行业惯用）、现货升水（对近月）。三者数值接近但定义不同，注册元数据时要写清口径，避免与 2.4 月差混用。
- 优先验证：`铝现货价`、`沪铝主力合约收盘价`（可由观行情算出基差）；升贴水/现货升水需 SMM 或 Mysteel 外部源，标「待外部源」。
- LME 现货升贴水可先查知几（LME cash-3M 系列通常有）。
