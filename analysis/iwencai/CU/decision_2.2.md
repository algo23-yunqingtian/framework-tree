# CU·2.2 现货与升贴水 Step2 取舍决策

> 边界定义：本子节点只回答「现货相对期货的升贴水/基差水平与结构」。仓单本体、社会库存、库存天数一律不外溢。

## 候选指标（按优先排序）

1. **【正主】SMM 1#电解铜现货均价（元/吨）** —— 现货定价中枢，升贴水计算的分子端；日度可得。
2. **【正主·复合】平水铜升贴水（元/吨）** —— 最主流的现货对主力合约贴水口径，信息量最大，与现货均价构成基差；日度可得。
3. **【辅助】升水铜升贴水（元/吨）** —— 反映优质/品牌铜溢价，区分「普涨」与「结构性紧张」。
4. **【辅助】湿法铜升贴水（元/吨）** —— 冶炼工艺结构分位，验证紧张是否跨工艺。
5. **【辅助】非注册铜升贴水（元/吨）** —— 品牌折价维度，反映交割品替代弹性。
6. **【辅助】LME 0-3 升贴水（美元/吨）** —— 海外现货对远期升水，与沪铜升贴水互为对照，验证内外盘现货强度是否同步。
7. **【辅助】沪铜主力合约收盘价（元/吨）** —— 升贴水分母锚，须与现货均价同图连续化。
8. **【待验证】EQ-A 铜升贴水（元/吨）** —— 新兴非注册铜基准，2026-09-01 起发布，历史序列极短，知几可得性待验证。

## 排除项

| 指标 | 原因 | 归属 |
|---|---|---|
| SHFE铜交割仓单数量 | 仓单本体，非升贴水 | 4.2 仓单 |
| 上期所铜交割库容与地区升贴水规则 | 制度/静态参数，非时序指标 | 4.2 仓单 |
| 现货基差「周度环比/分位数」派生形态 | 同一指标的呈现方式，去重 | 合并入「平水铜升贴水」 |
| 库存天数（SHFE/LME 折算） | 库存派生，属库存边界 | 4.1 交易所库存 |
| 铜价同比/分位 | 估值口径，属价格信号其他子类 | 2.3 海外价格 / 7.1 成本曲线与分位 |
| 精废价差 | 再生替代逻辑，非现货升贴水 | 3.2.3 再生/二次供应 |

## 推荐图组合

1. **图1 现货均价-主力价-升贴水三角图（复合·正主）**：1#电解铜现货均价（线）+ 沪铜主力收盘（线）+ 平水铜升贴水（柱，元/吨，0轴）。用途：判断现货相对期货的紧张度，升贴水收窄即压力释放。
2. **图2 四大口径升贴水对比图（复合）**：平水 / 升水 / 湿法 / 非注册铜升贴水四线叠加，标注主力合约换月点。用途：识别紧张是「全面」还是「结构性」。

4. **图4 EQ-A 铜升贴水 vs 平水铜升贴水图（单·待验证）**：两条升贴水线并列。用途：跟踪非注册铜替代弹性（序列建成后启用）。
