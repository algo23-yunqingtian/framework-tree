# CU·2.1 跨市场价差与贸易流信号 Step2 取舍决策

> 边界定义：本子节点只回答「跨市场价差（沪伦比/COMEX-LME）与贸易流是否支撑进口/套利」。矿端TC、废铜替代、汇率关税、交易所库存本体一律不外溢。

## 候选指标（按优先排序）

1. **【正主】进口盈亏（元/吨）** —— 直接量化内外盘套利窗口开合，是本节点唯一把价差、汇率、物流、关税合成一个数值的指标；日度可得性最高。
2. **【辅助】沪伦比（元/吨 ÷ 美元/吨）** —— 内外盘比价中枢，与进口盈亏互为验证；日度行情可得。
3. **【辅助】洋山铜溢价（美元/吨）** —— 保税现货对LME升水，贸易流温度计；周度可得。
4. **【辅助】铜精矿进口量（万吨）** —— 贸易流实物确认，但更贴近 3.1.4；此处仅作进口链交叉验证，标「待验证」知几序列。
5. **【辅助】LME注册仓单、LME注销仓单、COMEX注册仓单** —— 作为跨市场价差形成的库存基础，但本体归属 4.1/4.2，此处仅取结构线用于复合图，不作主指标。
6. **【待验证】人民币兑美元中间价** —— 进口盈亏的成本项，属宏观汇率，知几序列待查。

## 排除项

| 指标 | 原因 | 归属 |
|---|---|---|
| 铜精矿现货TC / RC | 矿端加工费，不是跨市场价差；重复占用 3.1.5 | 3.1.5 TC加工费 |
| 1#废铜报价、光亮铜报价、精废价差 | 再生替代逻辑，非贸易流价差 | 3.2.3 再生/二次供应 |
| 上海保税区铜库存 | 库存本体，且为隐性库存核心 | 4.5 隐性/在途库存 |
| 上海有色金属网口径「国内精炼铜进口亏损」文本指标 | 与进口盈亏同一指标派生口径，去重 | 合并入「进口盈亏」 |
| 各交易所库存绝对水平（LME/SHFE/COMEX 总库存） | 库存子类本体 | 4.1 交易所库存 |

## 推荐图组合

1. **图1 沪铜-伦铜-进口盈亏三角图（复合·正主）**：进口盈亏（柱，元/吨，0轴）+ 沪伦比（折线，右轴）+ 沪铜主力/LME 3M 价格（背景区带）。用途：一眼判断套利窗口是「价差阻断」还是「汇率/关税阻断」。
2. **图2 洋山溢价 + 保税区库存复合图**：洋山铜溢价（折线）+ 上海保税区库存（柱）。用途：验证高价差是否有保税实物支撑。
3. **图3 跨市仓单结构对比图（复合）**：LME注册/注销仓单 + COMEX注册仓单 + SHFE仓单（堆叠柱）。用途：解释价差背后的可交割资源分布（引用 4.1/4.2 数据源，不重复建图）。
4. **图4 进口铜精矿到港量 + 进口盈亏联动图（复合·待验证）**：铜精矿进口量（柱）+ 进口盈亏（折线，右轴）。用途：判断贸易流是否被盈亏窗口压制。
