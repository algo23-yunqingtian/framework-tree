## 0. 里程碑概览

V88-RC1 划分为 4 个 Phase，遵循 V87 验证成熟的门禁流程（Phase → Gate → 长稳 → Release）。

```
Phase01 (P0爬虫补数) → Phase02 (P1元数据改造) → Phase03 (P2算子+周报) → Phase04 (技术债修复+终期Gate)
```

## 2. 依赖关系

```
Phase01 (爬虫补数)  ──┐
                      ├──→ Phase02 (元数据改造需 Phase01 指标齐备)
                      │
Phase03 (算子+周报)  ──┤──→ Phase04 (技术债+终期Gate，需前三 Phase 完成)
                      │
                      └──→ 
```

- **Phase01 是前置**：Phase02 元数据改造需 Phase01 补数后的完整指标集
- **Phase03 可并行**：算子/周报迭代与 Phase01/02 部分并行
- **Phase04 收尾**：技术债修复 + 终期 Gate，需前三 Phase 完成

## 3. 风险与缓解

| 风险 | 缓解 |
|---|---|
| TD-001 破坏 MD5 校验链 | 修复时同步更新所有引用元数据，独立工单验证 |

| 元数据 yaml 与现有 metrics.json 冲突 | 以 metrics.json v87.2.0 为基线增量演进 |
| 阈值修改风险 | **2.0% 熔断阈值全程不修改**（生产既定） |
