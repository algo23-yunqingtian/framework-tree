### 2.3 案例 B: 时间戳跳跃 (MEDIUM)

#### B-01: Dry-run R5 时间窗口跳跃

| 属性 | 值 |
|------|-----|
| 发现时间 | 2026-10-16 (Dry-run R5) |
| 日期范围 | 2026-06-01 ~ 2026-06-30 |
| 问题描述 | Dry-run R5 的日期范围为2026年6月，与当前日期 (2026-10月) 存在4个月跳跃。若直接用于回填，会导致时间序列中间出现122天空缺。 |
| 根因 | Dry-run测试使用了较早的日期范围，与实时采集数据不连续 |
| 影响 | 若合并到主数据序列，会导致 DQA-04 (Continuity) 和 DQA-07 (DateContinuity) 失败 |
| 状态 | ⏳ **待处理** — Dry-run数据未合并，仅用于测试 |
| 修复建议 | Phase04集成时按时间顺序合并，确保连续性 |

#### B-02: 采集间隔不均匀

| 属性 | 值 |
|------|-----|
| 发现时间 | 持续监控 |
| 问题描述 | SPOT_IS 为日度数据，但周末/节假日无数据。若爬虫未正确识别交易日，可能产生时间戳跳跃。 |
| 根因 | 100PPI 数据仅在交易日发布，周末和法定节假日无更新 |
| 影响 | DQA-07 (DateContinuity) 可能在节假日后标记为WARN |
| 状态 | ⚠️ **已知** — 通过 DQA-15 (Calendar Exemption) 处理 |
| 修复建议 | 集成交易日历，排除周末和法定节假日 |

#### B-03: 跨月/跨年边界跳跃

| 属性 | 值 |
|------|-----|
| 发现时间 | Smoke测试 |
| 问题描述 | 1511行数据跨越2021-2026年，存在多年月/年边界。部分月份可能缺少月末/月初数据点。 |
| 根因 | 100PPI 历史数据在某些月份可能不完整 (如1月有元旦假期) |
| 影响 | 长周期分析时可能出现微小缺口 |
| 状态 | ⚠️ **已知** — DQA-07 DateContinuity 会标记 |
| 修复建议 | Phase04集成时做缺口填充 (forward fill 或插值) |
