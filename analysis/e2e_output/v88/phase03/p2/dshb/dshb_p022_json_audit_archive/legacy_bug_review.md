### 2.1 Summary

`global POLL_INTERVAL_SECONDS, MAX_POLLS` declared AFTER first usage in `argparse.add_argument()` within the `main()` function. Python requires `global` declarations to precede any use of the variable within the function scope.

```
Line 552:     parser.add_argument('--max-polls', type=int, default=MAX_POLLS,
Line 553:                         help=f'Maximum polls before exit (default: {MAX_POLLS}, 0=unlimited)')

Line 562:     global POLL_INTERVAL_SECONDS, MAX_POLLS
                    ↑↑↑ Global declared AFTER usage (too late)
```

### 2.3 Root Cause (Unchanged)

The `global` statement at line 562 is a no-op when the variable has already been referenced in the function scope. Python raises a `SyntaxError` at runtime when the CLI `main()` path is entered.
