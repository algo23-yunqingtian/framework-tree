### 2.2 CUSUM漂移检测
参数: μ₀=-0.456311, δ=0.1, k=0.05, h=4.0(初始5.0)
每日计算: S_t+ = max(0, S_t + (X_t - μ₀) - k), 告警: S_t+>h OR S_t->h
阈值矩阵: 初始宽松(0-14d) h=5.0→稳定期(14-30d) h=4.0→严格期(>30d) h=3.0

### 2.3 EWMA趋势检测
参数: λ=0.1(初始0.05), L=3.0, μ₀=-0.456311, σ₀=0.364233
UCL=-0.222, LCL=-0.691
每日计算: Z_t = λ×X_t + (1-λ)×Z_t-1, 告警: Z_t>UCL OR Z_t<LCL
阈值矩阵: 初始宽松(0-14d) λ=0.05/L=3.5→稳定期 λ=0.10/L=3.0→严格期 λ=0.20/L=2.5

### 2.4 双层检测协同逻辑
| 条件 | 判定 |
|------|------|
| CUSUM正常 + EWMA正常 | GREEN(无漂移) |
| CUSUM告警 + EWMA正常 | YELLOW(疑似趋势漂移) |
| CUSUM正常 + EWMA告警 | YELLOW(疑似水平漂移) |
| CUSUM告警 + EWMA告警 | RED(确认漂移) |
| 连续3天YELLOW | BLUE(升级告警) |

### 2.5 漂移告警分级
| 等级 | 颜色 | 条件 | 响应 | 升级 |
|:----:|:----:|------|------|:----:|

| YELLOW | 🟡 | CUSUM≥4.0 OR EWMA≥3.0 | 记录+观察 | 24h |
