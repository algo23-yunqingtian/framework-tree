### 4.4 代理估算偏差验证 (Wind vs Proxy)

在Wind数据导入前, 评估代理模型与真实数据的偏差:

| 时间段 | 代理模型行数 | Wind行数 | 可对比行数 | 预期偏差 |
|--------|:-----------:|:--------:|:----------:|:--------:|
| 2015-06 ~ 2015-12 | ~130 | ~130 | 130 | ±20-40% |
| 2016-01 ~ 2016-12 | ~244 | ~244 | 244 | ±20-40% |
| 2017-01 ~ 2017-12 | ~242 | ~242 | 242 | ±20-40% |
| 2018-01 ~ 2018-12 | ~242 | ~242 | 242 | ±20-40% |
| 2019-01 ~ 2019-12 | ~244 | ~244 | 244 | ±20-40% |
| **合计** | **1,102** | **1,102** | **1,102** | **±20-40%** |

**代理偏差计算公式**:

```
proxy_deviation = (proxy_value - wind_value) / wind_value × 100%
```

**预期结果**:
- 均值偏差: 15-25% (代理模型R²=0.823的理论预期)

### 5.4 DQA-09实施代码逻辑

```python
def dqa_wind_cross_validation(rows, wind_ref_data):
    """DQA-09: Wind数据交叉验证.
    
    对比Wind导入数据与SHFE官方参考数据的完全一致率和数值偏差.
    """
    if not wind_ref_data:
        return {"pass": True, "detail": "No reference data for validation",
                "skipped": True}
    
    # 匹配日期
    matched = [r for r in rows if r.get("date") in wind_ref_data]
    if not matched:
        return {"pass": False, "detail": "No matching dates"}
    
    # 完全一致率
    exact = sum(1 for r in matched 
                if r["top20_long"] == wind_ref_data[r["date"]]["top20_long"]
                and r["top20_short"] == wind_ref_data[r["date"]]["top20_short"])
    exact_ratio = exact / len(matched)
    
    # 数值偏差(均值)
    deviations = []
    for r in matched:
        ref = wind_ref_data[r["date"]]
        for field in ["top20_long", "top20_short"]:
            if ref[field] != 0:
                deviations.append(abs(float(r[field]) - ref[field]) / abs(ref[field]))
    
    mean_dev = sum(deviations) / len(deviations) if deviations else 0
    max_dev = max(deviations) if deviations else 0
    
    # 判定
    if exact_ratio >= 0.95 and mean_dev <= 0.001:
        verdict = "PASS"
        passed = True
    elif exact_ratio >= 0.90 and mean_dev <= 0.005:
        verdict = "WARN"
        passed = False
    else:
        verdict = "FAIL"
        passed = False
    
    return {
        "pass": passed,
        "detail": f"Exact={exact}/{len(matched)} ({exact_ratio:.2%}), "
                  f"MeanDev={mean_dev:.4%}, MaxDev={max_dev:.4%}",
        "exact_match_ratio": round(exact_ratio, 4),
        "mean_deviation": round(mean_dev, 6),
        "max_deviation": round(max_dev, 6),
        "verdict": verdict,
        "reference_source": "SHFE_OFFICIAL",
        "validation_range": f"{matched[0]['date']}~{matched[-1]['date']}"
    }
```
