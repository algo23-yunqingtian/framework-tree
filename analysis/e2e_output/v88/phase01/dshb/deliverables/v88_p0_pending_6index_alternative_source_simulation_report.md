## 2. 备选数据源调研 (T0)

### 2.1 冶炼检修量化损失 — 备选源 (A1~A5)

针对 CU/NI/SI 三个品种的冶炼检修量化损失指标，调研5类备选数据源：

| 备选源 | 数据源名称 | 数据来源 | 更新频率 | 数据口径 | 接入成本 |
|:------:|-----------|---------|:--------:|---------|:--------:|
| A1 | 交易所产量反推法 | SHFE/LME电解铜/镍/硅产量数据 | 月度 | 产能利用率反推检修损失 | 低（免费公开） |
| A2 | 上市公司财报法 | 主要冶炼企业季报/半年报 | 季度 | 产量/产能利用率/检修影响 | 低（免费公开） |
| A3 | 行业协会统计法 | 中国有色金属工业协会月度产量 | 月度 | 行业产量/开工率/检修天数 | 中（部分免费） |
| A4 | 海关进出口反推法 | 海关铜精矿/镍矿/工业硅进出口 | 月度 | 进出口量反推国内供给缺口 | 低（免费公开） |
| A5 | 自建综合模型法 | 多源融合+行业规律建模 | 周度 | 自建模型综合估算 | 中（需开发） |

**数据源详细说明：**

#### A1: 交易所产量反推法
- **数据源：** SHFE公开周报电解铜产量 + LME公开周报电解镍产量
- **口径：** 设计产能 × 日历天数 - 实际产量 = 理论检修损失
- **优势：** 免费公开、更新及时（月度）、数据权威
- **劣势：** 月度数据延迟1个月、无法区分检修与减产、精度有限
- **适用场景：** 作为参考验证源，不宜单独替代

#### A2: 上市公司财报法
- **数据源：** 江西铜业/铜陵有色/云南铜业季报 + 华友钴业/力勤资源季报 + 合盛硅业季报
- **口径：** 上市公司产量/产能利用率 → 推断行业检修规模
- **优势：** 免费公开、数据可靠、上市公司披露规范
- **劣势：** 季度数据延迟1-3个月、仅覆盖部分产能、上市公司不披露检修明细
- **适用场景：** 低频参考，辅助判断大趋势

#### A3: 行业协会统计法
- **数据源：** 中国有色金属工业协会月度电解铜产量 + 中国硅业协会月度工业硅产量
- **口径：** 协会统计的月度产量/开工率 → 推算检修影响
- **优势：** 覆盖面广、行业权威、部分数据免费
- **劣势：** 部分数据需付费订阅、月度数据、检修明细不公开
- **适用场景：** 可作为主要备选源之一

#### A4: 海关进出口反推法
- **数据源：** 海关总署铜精矿/镍矿/工业硅月度进出口数据
- **口径：** 进口量 + 国内产量 = 总供给；出口量影响国内供给
- **优势：** 免费公开、数据权威、月度更新
- **劣势：** 月度延迟约30天、间接推断检修影响、误差较大
- **适用场景：** 辅助交叉验证

#### A5: 自建综合模型法
- **数据源：** A1+A2+A3+A4多源融合 + 行业规律建模 + 历史数据训练
- **口径：** 多因子模型综合估算检修量化损失
- **优势：** 更新频率高（周度）、综合多源信息、精度可调
- **劣势：** 需要模型开发和训练、模型维护成本、精度依赖训练数据质量
- **适用场景：** 推荐作为主力备选方案

### 2.2 现货询盘成交活跃度 — 备选源 (B1~B5)

针对 CU/LC/SI 三个品种的现货询盘成交活跃度指标，调研5类备选数据源：

| 备选源 | 数据源名称 | 数据来源 | 更新频率 | 数据口径 | 接入成本 |
|:------:|-----------|---------|:--------:|---------|:--------:|
| B1 | 期货成交量代理法 | SHFE铜/LC广期所/SI广期所成交量 | 日频 | 成交量代理现货活跃度 | 低（免费公开） |
| B2 | Baidu搜索指数法 | 百度指数"铜价/碳酸锂/工业硅"搜索量 | 日频 | 搜索热度代理关注度 | 低（免费公开） |
| B3 | 产业链开工率反推法 | 正极材料/电池/光伏开工率 | 周频 | 下游开工率反推上游活跃度 | 中（部分免费） |
| B4 | 海关进出口数据法 | 海关月度进出口数据 | 月度 | 贸易流代理活跃度 | 低（免费公开） |
| B5 | 自建综合模型法 | 多源融合+市场情绪建模 | 3天 | 综合模型估算活跃度 | 中（需开发） |

**数据源详细说明：**

#### B1: 期货成交量代理法
- **数据源：** SHFE铜期货日成交量 + 广期所碳酸锂/工业硅期货日成交量
- **口径：** 期货成交量 × 缩放系数 = 现货活跃度代理
- **优势：** 免费公开、日频更新、与市场情绪直接相关
- **劣势：** 口径不同（期货≠现货）、缩放系数难确定、无法反映真实询盘
- **适用场景：** 日频参考，趋势跟踪

#### B2: Baidu搜索指数法
- **数据源：** 百度指数"铜价现货"/"碳酸锂价格"/"工业硅价格"搜索量
- **口径：** 搜索热度 → 市场关注度 → 活跃度代理
- **优势：** 免费公开、日频更新、反映市场情绪
- **劣势：** 搜索≠交易、受新闻事件干扰、口径不直接
- **适用场景：** 市场情绪参考

#### B3: 产业链开工率反推法
- **数据源：** 正极材料开工率 + 电池排产 + 光伏硅片开工率
- **口径：** 下游开工率 → 上游采购需求 → 现货活跃度
- **优势：** 产业链直接相关、周频更新
- **劣势：** 部分数据需付费、间接推断、延迟
- **适用场景：** 产业链逻辑验证

#### B4: 海关进出口数据法
- **数据源：** 海关月度铜/碳酸锂/工业硅进出口数据
- **口径：** 贸易流量 → 活跃度代理
- **优势：** 免费公开、数据权威
- **劣势：** 月度延迟、间接相关、无法反映国内现货
- **适用场景：** 低频辅助参考

#### B5: 自建综合模型法
- **数据源：** B1+B2+B3+B4多源融合 + 市场情绪建模
- **口径：** 多因子模型综合估算活跃度
- **优势：** 更新频率高、综合多源信息、精度可调
- **劣势：** 需要模型开发、维护成本
- **适用场景：** 推荐作为主力备选方案

## 3. 离线仿真方法与实现 (T1+T2)

### 3.1 仿真环境

| 参数 | 值 | 说明 |
|------|:--:|------|
| 仿真框架 | Python 3.12 + NumPy | 完全离线 |
| 仿真周期 | 3年 / 756个交易日 | 2025-01-01 ~ 2027-11-24 |
| 随机种子 | 42 | 可复现 |
| 外部API调用 | **零** | NO_ZHIJI_API_CALL=TRUE |
| 数据性质 | 合成数据 | 基于公开市场规律，非真实SMM数据 |

### 3.2 仿真流程

```
Step 1: 生成SMM基准合成数据
  ├── 冶炼检修类: 基于行业检修周期模式 (大修2-4周/次, 3-4次/年)
  └── 现货活跃度类: 基于市场波动率和季节性模式

Step 2: 生成备选数据源合成数据
  ├── 与SMM基准正相关 (通过平滑版本混合)
  ├── 添加噪声 (noise_ratio: 0.10~0.40)
  ├── 添加延迟 (lag: 1~60天)
  └── 模拟不同频率 (1天~60天)

Step 3: 计算IC/IR
  ├── IC = Spearman秩相关 (rolling window=30, step=5)
  ├── IR = IC_mean / IC_std
  └── 统计IC正相关率、t统计量

Step 4: 偏差评估
  ├── Bias% = (备选均值 - SMM均值) / SMM均值 × 100%
  ├── MAE = 平均绝对误差
  └── MAPE = 平均绝对百分比误差

Step 5: 替代可行性分类
  ├── IC ≥ 0.30 且 IR ≥ 2.0 → [G] 可直接替换
  ├── IC ≥ 0.15 → [Y] 仅可做参考替代
  └── IC < 0.15 → [R] 无法替代
```

### 3.3 IC/IR计算标准

| 指标 | 计算方法 | 说明 |
|------|---------|------|
| IC (Information Coefficient) | Spearman秩相关系数 | 衡量备选数据与SMM基准的秩相关强度 |
| IR (Information Ratio) | IC_mean / IC_std | 衡量IC的稳定性和可预测性 |
| IC正相关率 | mean(IC_t > 0) | IC为正的时间占比 |
| IC t统计量 | IC_mean / (IC_std / √N) | IC显著性检验 |
| Bias% | (备选均值 - SMM均值) / SMM均值 | 系统性偏差 |
| MAPE | mean(|备选-SMM| / SMM) × 100% | 绝对百分比误差 |
