## 0. SOP 摘要

V87 全链路收官后，系统转入长期运维阶段。本 SOP 统一维护全局 P3 事件库、监控阈值库，并定义每周自动巡检规则，保障 V88 及后续版本稳定运行。

**核心原则**：阈值 2.0% 熔断线全程不修改（生产既定）；所有巡检为追加记录，不改历史基线。

## 2. 全局 P3 事件库

维护口径：所有 P3 事件追加记录，不删除历史。P0/P1/P2 = 0 为长期目标。

| 事件级别 | 响应时间 | 通道 |
|---|---|---|
| 🔴 P0 | ≤5min | 电话 + 即时通知 + 邮件 + CTO |
| 🟡 P1 | ≤15min | 即时通知 + 邮件 |
| 🟢 P2 | ≤2h | 邮件 |
| 🔵 P3 | 无时限 | 台账记录 |

### 2.1 差异三分类（对账专用，强制标记）

| 类别 | 判定特征 | 上报 | 处置 |
|---|---|---|---|
| ① 数据噪声 | 单次出现 + 复算 SHA256 一致 + 无趋势 | 🔵 P3 | 记录不处置 |
| ② 缓存抖动 | 与 QPS 时序相关 + 短时尖峰 + 恢复后基线不变 | 🟢 P2 | 记录 + 监控趋势 |
| ③ 真实隐性缺陷 | 复算后差异保留 + 有方向性 + 跨时段持续 | 🔴 **P0** | **立即升级建单 + 回滚评估** |

**长期目标**：③ 类真实隐性缺陷持续为 0。

## 3. 每周自动巡检规则

### 3.1 巡检清单

| # | 巡检项 | 频率 | 规则 | 责任方 |
|---|---|---|---|---|
| 1 | 自动对账 | 每周 | 三级采样（30秒/1分钟/4小时），一致率 ≥99.8%，差异三分类标记 | HERMES |
| 2 | 指标 DQ | 每周 | 18 路爬虫 DQ ≥99.8%，因子覆盖 26/26，IC/IR 漂移 <0.2% | DSHB |
| 3 | Framework Tree 图表健康 | 每周 | 44 节点/146 指标/43 图表数校验，三元绑定完整性，partial 指标跟踪 | DSHE |
| 4 | CPU 负载 | 持续 | 预警1.9%/关注1.95%/熔断2.0%，0 熔断 | DSHB |
| 5 | 索引膨胀 | 每周 | 索引膨胀 <8.5%，D60-D365 健康 | DSHB |
| 6 | 性能指标 | 每周 | Query P99 <5ms，Render P99，首屏 <10% | DSHB+DSHE |

### 3.2 巡检执行流程

```
1. 数据采集（DSHB 一手指标 + DSHE 看板指标 + HERMES 对账记录）
2. 差异三分类标记（① 噪声 / ② 缓存抖动 / ③ 隐性缺陷）
3. 阈值比对（CPU/内存/P99/DQ/IC-IR）
4. 事件台账追加（P3 事件库，append-only）
5. 周报汇总输出（每周巡检简报）
6. 异常升级（P0/P1 按升级时间线通知）
```

### 3.3 巡检判定标准

| 判定 | 条件 |
|---|---|
| ✅ 正常 | 全部巡检项达标，0 P0/P1，③类缺陷=0 |
| ⚠️ 关注 | P2/P3 事件增多但无 P0/P1，无熔断 |
| 🔴 异常 | 出现 P0/P1、熔断触发、或 ③类缺陷≥1 |
