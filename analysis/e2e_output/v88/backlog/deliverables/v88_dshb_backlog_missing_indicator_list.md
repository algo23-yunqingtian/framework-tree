## 1. 口径说明

### 1.1 两套统计口径差异

| 口径 | 统计单位 | 总数 | 已匹配 | 部分匹配 | 缺失 | 来源 |
|------|:--------:|:----:|:------:|:--------:|:----:|------|
| **后端指标口径** | 指标 | 147 (123+24) | 123 | 24 | 0 | DSHB Phase33冻结报告 |
| **前端图表口径** | 图表 | 88 (63+25) | 63 | 0 | 25 | DSHE周报渲染测试 |

**差异根因：**

| 差异维度 | 图表口径 | 指标口径 |
|----------|----------|----------|
| 统计粒度 | 1张图表 | 1条数据序列 |
| 映射关系 | 1图表可绑定1~N个指标 | 1指标可出现在1~N张图表中 |
| 状态定义 | matchable = 图表所有指标数据可用 | matched = 指标数据完整入库 |
| 数量差异 | 88张 | 147项 |

**差异分解：**

```
图表口径:   63 可匹配 + 25 待补 = 88 张图表
                    ↓ 展开
指标口径:  123 matched + 24 partial + 0 missing = 147 项指标

差异来源:
  ① 1图表:多指标 展开倍数: 63张图表 ≈ 90+ 项指标引用
  ② 指标跨图表复用: 部分指标被多张图表引用
  ③ partial→图表降级: 24项partial中部分对应图表仍可渲染
  ④ YAML定义vs实际绑定: 102 YAML图表 vs 147 实际指标绑定
```

> **HERMES收官报告记录引用**: 上述差异已在 V87 收官报告 (`v87_rc1_g1_full_project_closure_report.md`) §6.2 正式记录，口径规格化文档 (`v88_dshe_chart_indicator_stat_caliber_spec.md`) 已定义禁止混用规则 R1-R4。

### 1.2 禁止混用规则

| 规则 | 说明 |
|------|------|
| R1 | 周报中禁止出现"指标"口径数据（如147项/123matched） |
| R2 | 指标入库报告中禁止使用"图表"口径数据（如88张/63可渲染） |
| R3 | 跨Agent对齐会议中如需同时引用，必须明确标注口径来源 |
| R4 | 百分比计算必须基于同一口径内的分子分母 |
