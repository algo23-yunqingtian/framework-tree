## 1. 背景与问题

在V87-RC1-G1项目生命周期中，DSHE前端与DSHB/HERMES后端各自维护了一套统计口径。在V87归档收官报告（`v87_rc1_g1_full_project_closure_report.md`）中明确记录了两套口径之间的差异：

> 工单口径「63 匹配 / 25 待补」与 DSHB 冻结口径「123 matched / 24 partial / 0 missing」存在差异，差异源于统计口径（工单按图表维度，冻结报告按指标维度）。

为避免V88迭代中因口径歧义导致重复建设或遗漏，本文档正式定义两套口径的适用场景与数据边界。

## 3. 口径差异根因分析

### 3.1 结构性差异

| 差异维度 | 图表口径 | 指标口径 |
|----------|----------|----------|
| 统计粒度 | 1张图表 = 1个视觉展示项 | 1个指标 = 1条数据序列 |
| 映射关系 | 1图表可绑定1~N个指标 | 1指标可出现在1~N张图表中 |
| 状态定义 | matchable = 图表所有指标数据可用 | matched = 指标数据完整入库 |
| 数量差异 | 88张 | 146项 |

### 3.2 具体差异场景

#### 场景A：1图表绑定多指标（图表口径低估）

```
示例: cu_i1_ts_01
  ├── SHFE库存 (indicator_id: FU00014935)  ← matched
  └── LME库存 (indicator_id: FU00014813)    ← matched

图表口径: 1张图表 (matchable)
指标口径: 2项指标 (2 × matched)
```

#### 场景B：1指标出现在多图表（指标口径低估）

```
示例: 主连 (CU_FU00014941)
  ├── 出现在 cu_p1_ts_01 (铜 主连结算价)
  ├── 出现在 cu_p1_ts_02 (铜 持仓量)  ← 同一节点多图表
  └── ... 其他复用

图表口径: 1图表中只计1次
指标口径: 1指标全库只计1次
```

#### 场景C：指标半匹配但图表仍可渲染（口径不一致）

```
示例: partial指标(24项)
  ├── 指标层: partial (口径差异/字段缺失, DQA巡检标记)
  └── 图表层: matchable (如果图表绑定该指标但降级渲染)
       注: 当前24项partial指标对应的图表仍按matchable计
```

### 3.3 数量差异分解

```
图表口径:   63 可匹配 + 25 待补 = 88 张图表
                    ↓ 展开
指标口径:  123 matched + 24 partial = 146 项指标

差异分解:
  1图表:多指标 展开倍数:  63张图表 ≈ 90+ 项指标引用
  指标跨图表复用:         部分指标被多张图表引用
  partial→图表降级:      24项partial中部分对应图表仍可渲染
  YAML定义vs实际绑定:     102 YAML图表 vs 146 实际指标绑定
```

## 5. 周报统计标准（正式定义）

### 5.1 周报统计规则

```
周报图表统计规则 (R-REPORT-CALIBER-V1):

1. 统计范围: 仅统计weekly_render=true的图表(当前88张)
2. 状态分类:
   - "可渲染": data_status=matchable 且 所有绑定指标数据连续
   - "待补数据": data_status=pending_data 或 绑定指标中存在缺失
   - "已废弃": data_status=deprecated (不计入)
3. 计数单位: 1张图表 = 1个计数
4. 百分比计算: 可渲染数 / (可渲染数 + 待补数)
5. 周报模板: "本周X张图表, Y张可渲染, Z张待补"
```

### 5.2 周报统计输出格式

```markdown
## 本周周报渲染统计

| 指标 | 值 |
|------|:--:|
| 总图表数 | 88 |
| 可渲染 | 63 (71.6%) |
| 待补数据 | 25 (28.4%) |
| 新增可渲染 | +0 |
| 解决待补 | +0 |
```

### 5.3 禁止混用规则

| 规则 | 说明 |
|------|------|
| R1 | 周报中禁止出现"指标"口径数据（如146项/123matched） |
| R2 | 指标入库报告中禁止使用"图表"口径数据（如88张/63可渲染） |
| R3 | 跨Agent对齐会议中如需同时引用，必须明确标注口径来源 |
| R4 | 百分比计算必须基于同一口径内的分子分母 |
