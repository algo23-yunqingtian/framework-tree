## 8. 最优参数组合筛选

### 8.1 推荐参数

| 参数 | 当前值 | 推荐值 | 变化 | 理由 |
|------|:------:|:------:|:----:|------|
| TTL | 5min | **7min** | +2min | 减少集中失效, 提升极端场景命中率 |
| Shard Capacity | 512 | **1024** | +512 | 减少驱逐, 提升命中率 |
| Warm-up Threshold | 80% | **85%** | +5% | 更早触发预热, 减少冷启动 |
| Max Memory | 3.0MB | **3.0MB** | 不变 | 已在上限内, 无需增加 |

### 8.2 参数选择理由

- **TTL=7min**: 延长TTL减少集中过期, 极端场景命中率提升最显著(+9.3pp), 且内存增长仅+0.1MB
- **Shard=1024**: 增加分片容量减少驱逐, 穿透率从12.5%降至6.2%(-50.4%)
- **Warm-up=85%**: 提前预热减少冷启动延迟, 恢复时间从4.0min降至2.0min
- **Max Mem=3.0MB**: 已满足需求, 无需增加, 保持内存可控
