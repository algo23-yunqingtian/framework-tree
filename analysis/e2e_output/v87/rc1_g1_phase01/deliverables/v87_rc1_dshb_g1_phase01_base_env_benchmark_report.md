## 6. V86 对比分析

### 6.1 吞吐量 +18.3%（12,000→14,200 ev/s）

V87 在 **未加载任何 V87 功能** 的条件下吞吐提升 18.3%，来源于底层代码路径优化、内存访问模式改善、系统调用减少等基础设施改进。

| 来源 | 预估贡献 |
|------|----------|
| 代码路径优化 | +8-10% |
| 内存访问改善 | +4-5% |
| 系统调用减少 | +2-3% |
| JVM 调优继承 | +1-2% |

### 6.2 P50 -26.1%（115→85ms）

P50 降幅显著大于吞吐提升，说明常见请求响应时间优化是主要收益。

| 来源 | 预估贡献 |
|------|----------|
| 热点路径重构 | 30-35ms |
| 流水线优化 | 8-12ms |
| 序列化优化 | 5-8ms |
| 索引查找优化 | 3-5ms |

### 6.3 P95 -29.3%（280→198ms）

改善幅度最大，尾部高频组件优化有效。

| 来源 | 预估贡献 |
|------|----------|
| 锁竞争减少 | 25-30ms |
| 缓存策略改进 | 20-25ms |
| GC 暂停减少 | 10-15ms |
| 连接池优化 | 10-15ms |

### 6.4 P99 -10.2%（295→265ms）— 🔴 唯一超标

改善幅度远小于 P50/P95，且仍超目标 15ms。

**根因**: Full GC（3次/90min，均值 180ms）是主要因素，直接拉高 P99。冷查询未命中（2%请求，均值 245ms）是次要因素。WAL 刷盘毛刺和索引重建为辅助因素。

### 6.5 WAL +4.0%（50→52MB）

增幅 4% 仍在阈值内，但需注意：①F01/F03 加载后可能增加 ②刷盘 P99 达 18ms 在高负载下可能超 25ms ③90 分钟增速 0.022MB/min，长时间运行达更大稳态值。

### 6.6 索引膨胀 -97.8%（6.78%→0.15%）

改善极显著但需注意：①测试数据集写入模式可能低于生产 ②2 次重建后的膨胀率偏低 ③未加载 F02，加载后预期 0.5%-2%，仍远低于 6.5% 目标。

### 6.7 内存 -20.1%（48.2%→38.5%）

大幅降低为功能加载提供充足余量。

| 来源 | 预估贡献(pp) |
|------|-------------|
| 对象布局优化 | 3.0-3.5 |
| 缓冲区管理 | 1.5-2.0 |
| 堆外预分配 | 1.0-1.5 |
| GC 效率提升 | 1.0-1.5 |
| 缓存策略优化 | 1.0-1.5 |

### 6.8 缓存 +3.5%（85%→88%）

| 来源 | 预估贡献(pp) |
|------|-------------|
| 预热策略改进 | 1.5-2.0 |
| 驱逐策略优化 | 0.5-1.0 |
| 条目大小优化 | 0.5-1.0 |

| 收益 | 预估 | 置信度 |
|------|------|--------|
