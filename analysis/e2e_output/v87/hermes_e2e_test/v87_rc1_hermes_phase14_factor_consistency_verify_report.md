## 1. 校验目标

1. 校验原始外部指标全字段 SHA256 完整性（5字段联合校验 + SHA256）
2. 校验 26 项派生因子 22 字段全字段 SHA256 完整性
3. 校验因子计算逻辑一致性与 DQ 通过率（重点：100%全量下）
4. 校验因子 IC/IR/衰减/VIF 等衍生字段准确性
5. 校验因子数据在全量流量下的跨版本一致性（V87.1 vs V87 RC1 监控通道）
6. 校验因子在 DSHE 因子看板渲染的一致性
7. 校验 CPU 硬熔断期间因子数据一致性（Phase14 新增）
