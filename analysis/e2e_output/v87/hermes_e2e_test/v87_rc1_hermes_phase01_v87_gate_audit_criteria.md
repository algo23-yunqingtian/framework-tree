## 2. Gate 判定规则

### 2.1 GO 判定（全部满足）

| # | 条件 | 阈值 |
|---|------|------|
| 1 | SHA256三方对账全通过 | 100%窗口 |
| 2 | 链断裂 = 0 | 0 |
| 3 | 去重 = 100% | 100% |
| 4 | 丢包率 | ≤0.01% |
| 5 | WAL P99 | <2000ms |
| 6 | 索引P99 | <10ms |
| 7 | V87字段校验 | 全部PASS |
| 8 | 模型偏差 | ≤5%（灰度后） |
| 9 | 无退化趋势 | 全部stable |
| 10 | P0/P1缺陷 | 0/0 |

### 2.2 CONDITIONAL-GO 判定

| # | 条件 | 说明 |
|---|------|------|
| 1 | 9/10条件满足 | 1项可接受偏差 |
| 2 | P2风险 | ≤1个 |
| 3 | 无P0/P1 | 必须 |
| 4 | 附约束条件 | 明确缓释方案 |

### 2.3 RED 判定（任一满足）

| # | 条件 | 说明 |
|---|------|------|
| 1 | P0缺陷 | 数据丢失/断裂 |
| 2 | P1缺陷 | 核心指标超阈值 |
| 3 | SHA256不一致 | 数据完整性破坏 |
| 4 | 链断裂>0 | 链完整性破坏 |
| 5 | 去重<100% | 去重失败 |
| 6 | 模型偏差>20% | 模型失效 |
