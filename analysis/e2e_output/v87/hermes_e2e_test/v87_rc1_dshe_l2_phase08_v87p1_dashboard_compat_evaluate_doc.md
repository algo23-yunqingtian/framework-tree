## 1. 执行摘要

本文档针对 DSHB V87.1 优化方案（R-NEW-001）在 DSHE V87 RC1 L2 展示层的兼容性进行系统性评估，覆盖指标面板、告警规则、HERMES 字段联动、性能指标、集成测试五个维度。

**核心结论：GO for V87.1 adaptation.**

DSHE V87 RC1 当前 L2 大盘状态（8 面板 / 12 规则 / 5 字段）与 V87.1 优化方向高度契合。V87.1 引入的 DSHB P99 优化（266.6ms → 249.8ms，-5.26%）预计将联动改善 DSHE 端渲染 P99（149ms → 146ms）与查询 P99（280ms → 270ms），缓存命中率由 96.5% 提升至 97.0%。

**关键数字**：总工作量 **10–16 人天**；集成测试周期 **2–3 周**（3 阶段）；测试用例 **22 例**；风险 **高 2 / 中 4 / 低 6**；阻断项 **0**。

**风险边界**：V85 分支不可修改（NO_MODIFY_V85=TRUE），评估严格限定于 V87 RC1 → V87.1 演进路径；知几 API 通道关闭（NO_ZHIJI_API_CALL=TRUE）；既有产物不可覆盖（NO_OVERWRITE=TRUE）。
