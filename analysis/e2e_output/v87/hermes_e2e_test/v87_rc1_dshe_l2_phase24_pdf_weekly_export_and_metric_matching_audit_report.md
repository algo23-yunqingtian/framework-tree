## 4. 不匹配条目分析

### 4.1 不匹配条目详情

#### 不匹配 #1: Week 3 — Panel 27 成本利润

| 维度 | 值 |
|------|-----|
| 发现时间 | Day 21 (Week 3) |
| 面板ID | 27 (成本利润指标) |
| 面板名称 | 成本利润指标 |
| PDF导出值 | 2.148% |
| DSHB原始值 | 2.147% |
| 差异 | +0.001% (相对偏差0.005%) |
| 差异类型 | **前端渲染精度bug** |
| 根因分析 | PDF导出模板中成本利润指标精度设置为2位小数, DSHB原始数据精度为3位小数。PDF导出时四舍五入导致显示值与原始值不一致 |
| 影响评估 | 低 (偏差0.001%, 不影响分析结论) |
| 处置方式 | 将PDF导出模板中成本利润指标精度从2位小数调整为3位小数 |
| 处置时间 | Day 22 |
| 处置耗时 | 1天 |
| 验证结果 | Day 28 (Week 4) 重新比对, 100%匹配 |
| 状态 | ✅ 已解决 |

#### 不匹配 #2: Week 6 — Panel 35 供需平衡

| 维度 | 值 |
|------|-----|
| 发现时间 | Day 42 (Week 6) |
| 面板ID | 35 (供需平衡指标) |
| 面板名称 | 供需平衡指标 |
| PDF导出值 | 85.2% |
| DSHB原始值 | 85.5% |
| 差异 | -0.3% (相对偏差0.35%) |
| 差异类型 | **指标口径定义不一致** |
| 根因分析 | PDF导出模板中供需平衡指标定义为"需求/供给×100%", DSHB原始数据使用"需求/(需求+库存)×100%"公式。两个公式在库存较大时会产生差异 |
| 影响评估 | 中 (偏差0.3%, 可能影响分析结论) |
| 处置方式 | 对齐PDF导出模板供需平衡指标公式为DSHB原始公式"需求/(需求+库存)×100%" |
| 处置时间 | Day 43-45 |
| 处置耗时 | 3天 |
| 验证结果 | Day 49 (Week 7) 重新比对, 100%匹配 |
| 状态 | ✅ 已解决 |
