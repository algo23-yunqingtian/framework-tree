## 2. 三方对账架构

### 2.1 三方对账体系

```
DSHB (L1 数据层)
  │
  ├── 原始数据 → DSHB数据仓库
  │
  ├── 数据质量规则 (DQ Rules)
  │
  └── 数据接口 → DSHE (L2 展示层)
                    │
                    ├── 看板面板 → 用户展示
                    │
                    ├── 指标时序导出 → 共享文件系统
                    │
                    └── 对账数据 ← HERMES (L3 对账层)
                                  │
                                  ├── 爬虫数据 (5交易所15指标)
                                  │
                                  ├── 三方对账流水线 (Phase16)
                                  │
                                  ├── 差异检测 → DSHE定位
                                  │
                                  └── 根因分析 → DSHB修复
```

### 2.2 三方角色定义

| 角色 | 系统 | 职责 | 状态 |
|------|------|------|------|
| 数据源 | DSHB (L1) | 原始数据存储/数据质量规则/数据接口 | ✅ |
| 展示方 | DSHE (L2) | 看板展示/指标时序导出/差异定位 | ✅ |
| 对账方 | HERMES (L3) | 爬虫数据/三方对账/差异检测 | ✅ |

### 2.3 三方对账数据流

```
数据流:
1. DSHB原始数据 → DSHB数据仓库
2. DSHB数据接口 → DSHE看板面板
3. DSHE指标时序 → 共享文件系统
4. HERMES爬虫数据 → HERMES对账流水线
5. HERMES对账 → DSHE差异定位
6. DSHE差异修复 → DSHB数据修正
7. DSHB修正后 → HERMES重新对账
8. 对账通过 → 记录归档
```

## 5. 三方对账流程

### 5.1 对账流程

```
三方对账流程:
1. HERMES爬虫数据采集 (5交易所15指标)
2. HERMES数据清洗 + DQ规则校验
3. HERMES读取DSHE导出指标时序
4. HERMES三方比对:
   a. DSHB原始数据 vs DSHE展示数据
   b. DSHE展示数据 vs HERMES爬虫数据
   c. DSHB原始数据 vs HERMES爬虫数据
5. 差异检测:
   a. 数值偏差 > 阈值
   b. 时间戳偏差 > 阈值
   c. 口径不一致
   d. 数据缺失
   e. 数据延迟
6. 差异定位:
   a. HERMES侧差异 → HERMES定位
   b. DSHE侧差异 → DSHE定位
   c. DSHB侧差异 → DSHB定位
7. 差异修复:
   a. 自动修复 (可修复)
   b. 人工修复 (需人工)
8. 重新对账 → 确认修复
9. 对账记录归档
```
