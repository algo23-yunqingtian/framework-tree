### 4.2 新增降噪规则

#### L5: 延迟抑制 (Delay Suppression)

```
触发条件:
  1. 数据源更新延迟 > 预期更新频率 × 2
  2. 延迟持续 < 24h
  3. 数据源状态: 活跃 (非断流)

动作:
  - 抑制告警推送
  - 记录延迟事件日志
  - 延迟恢复后不补发告警

效果:
  - 过滤 NP-02 类噪声 (数据源延迟恢复)
  - 抑制率: ~1%
  - 误判率: 0% (延迟恢复后数据正常)
```

#### L6: 值域校验 (Range Validation)

```
触发条件:
  1. 数据值超出历史P1-P99范围
  2. 超出幅度 > 20%
  3. 持续时间 < 2个采集周期

动作:
  - 抑制告警推送
  - 记录异常值事件日志
  - 标记为"待确认"而非"告警"

效果:
  - 过滤 NP-05 类噪声 (数据源值域异常)
  - 抑制率: ~1%
  - 误判率: 0% (历史P1-P99范围覆盖真实变化)
```
