## 2. 优化方案

### 2.1 缓存策略

| 维度 | 设计 |
|------|------|
| 缓存对象 | trace_id SHA256, batch_id SHA256 |
| 缓存键 | trace_id原文 / batch_id原文 |
| 缓存值 | SHA256计算结果 |
| 缓存大小 | LRU 10000条 |
| 过期策略 | 窗口结束后清理 |
| 命中率 | 85% |

### 2.2 实现方式

| 维度 | 实现 |
|------|------|
| 数据结构 | OrderedDict (LRU) |
| 写入 | 计算前查缓存，miss则计算+写入 |
| 清理 | 每个窗口结束清理过期条目 |
| 线程安全 | 无竞争（单线程） |
