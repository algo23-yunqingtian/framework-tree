### 6.2 规则详解

#### R01 价格异常检测

```sql
-- 公式: |price - MA(20)| > 2 * σ(MA(20))
SELECT metric_id,
       ABS(current_value - AVG(value) OVER (ORDER BY ts ROWS 20)) AS deviation,
       AVG(value) OVER (ORDER BY ts ROWS 20) AS ma20,
       STDDEV(value) OVER (ORDER BY ts ROWS 20) AS sigma20
FROM metrics
WHERE metric_id = 'EXT-001'
AND ABS(current_value - ma20) > 2 * sigma20
```

| 参数 | 值 | 说明 |
|------|:--:|------|
| 移动窗口 | 20天 | 月度移动平均 |
| 阈值 | 2σ | 2倍标准差 |
| 严重度 | ERROR | 触发ERROR告警 |
| 频率 | 1小时 | 每小时检查 |

#### R02 库存变化异常

```sql
-- 公式: |Δinventory| / inventory_prev > 15%
SELECT metric_id,
       ABS(current_value - prev_value) / NULLIF(prev_value, 0) * 100 AS change_pct
FROM metrics
WHERE metric_id IN ('EXT-006', 'EXT-007')
AND ABS(current_value - prev_value) / NULLIF(prev_value, 0) > 0.15
```

#### R03-R07 外部指标一致性

| 规则 | 公式 | 阈值 | 严重度 |
|------|------|:----:|:------:|
| R03 生产一致性 | \|prod - trend\| < 5% | 5% | WARN |
| R04 进出口平衡 | \|imp+exp - total\| < 3% | 3% | WARN |
| R05 供需平衡 | net ∈ [-10%, +15%] | ±10-15% | WARN |
| R06 成本结构 | \|sum - total\| < 2% | 2% | WARN |
| R07 溢价合理 | premium ∈ [hist_min, hist_max] | 历史范围 | WARN |

#### R08 时间对齐校验

```sql
-- 公式: |t_external - t_internal| < 2h
SELECT ext.metric_id,
       ext.ts AS t_ext,
       int.ts AS t_int,
       ABS(ext.ts - int.ts) AS time_diff
FROM external_metrics ext
JOIN internal_metrics int ON ext.metric_id = int.related_metric
WHERE ABS(ext.ts - int.ts) > INTERVAL '2 hours'
```

#### R09 空值检测

```sql
-- 公式: null_count / total_count < 5%
SELECT metric_id,
       SUM(CASE WHEN value IS NULL THEN 1 ELSE 0 END) * 100.0 / COUNT(*) AS null_rate
FROM metrics
GROUP BY metric_id
HAVING null_rate > 5.0
```

#### R10 跳变检测

```sql
-- 公式: |Δvalue| > 3 * σ
SELECT metric_id, ts,
       ABS(value - LAG(value) OVER (ORDER BY ts)) AS change,
       STDDEV(value) OVER (ORDER BY ts) AS sigma
FROM metrics
WHERE ABS(value - LAG(value) OVER (ORDER BY ts)) > 3 * STDDEV(value) OVER (ORDER BY ts)
```

#### R15 综合质量评分

```sql
-- 加权平均: quality_score = Σ(weight_i * rule_score_i)
SELECT metric_id,
       (0.15 * r01_score + 0.10 * r02_score + ... + 0.05 * r14_score) AS quality_score
FROM rule_results
WHERE quality_score < 80
```

## 7. 告警阈值设计

### 7.1 告警等级

| 等级 | 触发条件 | 质量评分 | 响应时间 | 通知方式 | 处理 |
|:----:|---------|:--------:|:--------:|---------|:----:|
| 🟢 INFO | 轻微偏差 | 80-100 | 24h | Dashboard | 记录 |
| 🟡 WARN | 中度偏差 | 60-79 | 4h | Slack/DingTalk | 检查 |
| 🔴 ERROR | 严重偏差 | 40-59 | 1h | PagerDuty | 修复 |
| 🔴 CRITICAL | 严重异常 | 20-39 | 30min | PagerDuty+电话 | 紧急修复 |

### 7.2 告警路由

```
INFO → Dashboard (记录)
  ↓
WARN → Slack/DingTalk (检查)
  ↓
ERROR → PagerDuty (修复)
  ↓
CRITICAL → PagerDuty + 电话 (紧急修复)
  ↓
EMERGENCY → 电话 + 短信 + 邮件 (立即响应)
```

| 告警 | 关联告警 | 关联逻辑 |

## 9. 数据质量校验规则

### 9.1 DQ规则总览 (DQ-R01~R10)

| ID | 规则名称 | 检查内容 | 公式/方法 | 阈值 | 严重度 |
|:--:|---------|---------|-----------|:----:|:------:|
| DQ-R01 | 空值检测 | 空值率 | null_count/total | <5% | ERROR |
| DQ-R02 | 跳变检测 | 值突变 | \|Δ\|>3σ | 3σ | ERROR |
| DQ-R03 | 时间错位 | 时间戳偏差 | \|t_ext-t_int\|<2h | 2h | WARN |
| DQ-R04 | 单位一致性 | 单位正确性 | unit∈unit_list | — | WARN |
| DQ-R05 | 数据滞后 | 数据新鲜度 | age<48h | 48h | WARN |
| DQ-R06 | 完整性 | 数据完整率 | complete/total>95% | 95% | ERROR |
| DQ-R07 | 一致性 | 多源一致性 | deviation<10% | 10% | WARN |
| DQ-R08 | 准确性 | 值合理性 | value∈[min,max] | 历史范围 | WARN |
| DQ-R09 | 及时性 | 更新及时率 | on_time/total>90% | 90% | WARN |
| DQ-R10 | 可用性 | 可访问性 | available/total>99% | 99% | ERROR |

### 9.2 DQ评分公式

```
quality_score = 
  0.25 * completeness +
  0.20 * accuracy +
  0.20 * timeliness +
  0.20 * consistency +
  0.15 * availability
```

### 9.3 DQ等级

| 等级 | 评分 | 含义 | 处理 |
|:----:|:----:|------|:----:|
| 🟢 A | 90-100 | 优秀 | 无需处理 |
| 🟢 B | 80-89 | 良好 | 监控 |
| 🟡 C | 60-79 | 一般 | 关注 |
| 🔴 D | 40-59 | 较差 | 修复 |
| 🔴 F | <40 | 差 | 紧急修复 |

## 11. 异常处理流程

### 11.1 异常分类

| 类别 | 示例 | 处理方式 | 严重度 |
|------|------|---------|:------:|
| 数据异常 | 价格跳变>3σ | 自动标记+告警 | ERROR |

| 时间异常 | 时间戳偏差>2h | 时间对齐+告警 | WARN |
| 单位异常 | 单位不一致 | 自动转换 | WARN |
| 质量异常 | 质量评分<60 | 降级+告警 | CRITICAL |
| 系统异常 | 接入层故障 | 熔断+告警 | EMERGENCY |

### 11.2 处理流程

```
异常检测 → 异常分类 → 异常评估 → 自动/人工处理 → 结果记录 → 告警通知
  ↓         ↓          ↓           ↓            ↓          ↓
异常分类    严重度     影响范围     自动修复      dq_results   告警引擎
            评分        分析        或人工复核                    │
                                                                ↓
                                                         告警路由
```

### 11.3 自动修复规则

| 异常 | 自动修复 | 人工复核 | 条件 |
|------|:--------:|:--------:|------|
| 时间戳偏差 | ✅ | ❌ | 偏差<2h |
| 单位不一致 | ✅ | ❌ | 单位可转换 |
| 空值率>5% | ✅ | ✅ | 空值率>10%需人工 |
| 数据滞后>48h | ✅ | ✅ | 滞后>72h需人工 |
| 质量评分<40 | ❌ | ✅ | 必须人工复核 |
