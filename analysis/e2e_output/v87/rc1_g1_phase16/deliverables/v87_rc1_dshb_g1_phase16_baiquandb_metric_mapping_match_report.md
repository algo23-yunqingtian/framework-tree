## 3. 碰撞匹配方法论

### 3.1 碰撞匹配流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 1.指标导入   │───▶│ 2.字段碰撞   │───▶│ 3.匹配评级   │
│ (Report 1)   │    │ (百川字段表) │    │ (FULL/PARTIAL│
└─────────────┘    └─────────────┘    │  /MISSING)   │
                                       └──────┬──────┘
┌─────────────┐    ┌─────────────┐           │
│ 6.接入方案   │◀───│ 5.一致性校验  │◀─────────┘
│ (可行性评估)  │    │ (时间/单位/口径)│
└─────────────┘    └─────────────┘
```

### 3.2 匹配评级标准

| 评级 | 条件 | 含义 | 处置 |
|:----:|------|------|:----:|
| ✅ FULL | 字段名匹配 + 维度对齐 + 口径一致 + 时间覆盖 | 可直接接入 | 直接接入 |
| 🟡 PARTIAL | 字段名匹配但维度/粒度/口径部分不一致 | 需小幅改造 | 改造后接入 |
| ❌ MISSING | 百川无对应字段 | 需替代数据源 | 互联网调研 |

### 3.3 碰撞维度

| 维度 | 方法 | 工具 | 状态 |
|------|------|------|:----:|
| 字段名匹配 | 精确匹配 + 模糊匹配(Levenshtein) | 字符串匹配 | ✅ |
| 维度对齐 | 指标维度 vs 百川维度 | 维度映射表 | ✅ |
| 口径比对 | 计算方式 + 数据来源 + 统计窗口 | 口径规则引擎 | ✅ |
| 时间范围 | 数据起止时间 vs 需求范围 | 时间戳比对 | ✅ |
| 更新频率 | 更新周期 vs 需求周期 | 频率分析 | ✅ |

### 3.4 碰撞结果统计

| 评级 | 数量 | 占比 | 累计 |
|:----:|:----:|:----:|:----:|
| ✅ FULL | **12** | **54.5%** | 54.5% |
| 🟡 PARTIAL | **3** | **13.6%** | 68.2% |
| ❌ MISSING | **7** | **31.8%** | 100.0% |
| **合计** | **22** | **100%** | — |
