## 4. 指标分类方法论

### 4.1 分类标准

| 分类 | 定义 | 特征 | 数量 | 占比 |
|------|------|------|:----:|:----:|
| **内部埋点指标** | 系统自身运行产生的监控指标 | 实时采集、内部系统生成、固定粒度 | 18 | 42.9% |
| **外部基本面指标** | 来自外部市场/行业的基本面数据 | 外部来源、日/周/月更新、多维度 | 22 | 57.1% |

### 4.2 分类判定规则

```
IF 指标数据源 = "DSHB内部系统" AND 采集方式 = "埋点/探针"
THEN 分类 = "内部埋点指标"

ELSE IF 指标数据源 = "外部市场/交易所/行业机构"
THEN 分类 = "外部基本面指标"
```

### 4.3 边界情况处理

| 边界指标 | 判定 | 理由 |
|---------|------|------|
| HERMES审计延迟 | 内部埋点 | 系统内部链路监控 |
| 三方对账窗口数 | 内部埋点 | 系统内部对账机制产生 |
| 缓存命中率 | 内部埋点 | 系统内部缓存状态 |
| 框架树uptime | 内部埋点 | 系统自身可用性监控 |
| 告警推送延迟 | 内部埋点 | 系统内部告警链路 |
| 熔断/降级触发 | 内部埋点 | 系统内部保护机制 |

```

  ├─ 期货(EXT-002, EXT-021) → 持仓(EXT-021)
  └─ 溢价(EXT-022) ← 价差(EXT-004) + 价格(EXT-001, EXT-003)

供应链(EXT-023) → 价格(EXT-001) + 库存(EXT-006)
```
