## 3. 统一时序架构

### 3.1 单一时序库

```
┌─────────────────────────────────────────────────────────────────┐
│              DSHB 统一时序库 (metrics表)                          │
│                                                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  内部指标 (18项)                                        │   │
│  │  INT-001 P99延迟 → INT-018 日志增量                      │   │
│  │  source_type = 'internal'                                │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  外部指标 (22项)                                        │   │
│  │  EXT-001 现货价格 → EXT-024 替代能源影响                  │   │
│  │  source_type = 'baiquan'/'internet'/'manual'/'paid'/     │   │
│  │               'computed'                                 │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  关联索引 (metric_association_index)                     │   │
│  │  internal_metric_id ↔ external_metric_id ↔ rule_id       │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 Schema设计

```sql
-- 统一时序表
CREATE TABLE metrics (
    metric_id     VARCHAR(50),
    metric_name   VARCHAR(200),
    ts            TIMESTAMP,
    value         NUMERIC,
    unit          VARCHAR(50),
    source_type   VARCHAR(20),    -- internal/baiquan/internet/manual/paid/computed
    source_id     VARCHAR(100),
    quality_score SMALLINT DEFAULT 100,
    ingestion_time TIMESTAMP,
    lineage_id    UUID,
    PRIMARY KEY (metric_id, ts)
);

-- 指标关联索引
CREATE TABLE metric_association_index (
    id                  SERIAL PRIMARY KEY,
    internal_metric_id  VARCHAR(50),
    external_metric_id  VARCHAR(50),
    rule_id             VARCHAR(10),
    association_type    VARCHAR(20),  -- load/data_source/alert/performance/data_volume
    join_key            VARCHAR(100),
    description         TEXT
);
```

### 6.2 规则实施详情

#### R01 价格异常检测

```sql
-- 公式: |price - MA(20)| > 2 * σ(MA(20))
SELECT metric_id, ts,
       ABS(current_value - ma20) AS deviation,
       ma20, sigma20,
       CASE WHEN ABS(current_value - ma20) > 2 * sigma20
            THEN 'FAIL' ELSE 'PASS' END AS result
FROM (
    SELECT metric_id, ts, value AS current_value,
           AVG(value) OVER (ORDER BY ts ROWS 20) AS ma20,
           STDDEV(value) OVER (ORDER BY ts ROWS 20) AS sigma20
    FROM metrics
    WHERE metric_id IN ('EXT-001', 'EXT-002', 'EXT-003', 'EXT-004')
);
```

| 参数 | 值 | 说明 |
|------|:--:|------|
| 移动窗口 | 20天 | 月度移动平均 |
| 阈值 | 2σ | 2倍标准差 |
| 严重度 | ERROR | 触发ERROR告警 |
| 频率 | 1小时 | 每小时检查 |
| 覆盖指标 | EXT-001~004 | 价格类指标 |

#### R02 库存变化异常

```sql
-- 公式: |Δinventory| / inventory_prev > 15%
SELECT metric_id, ts,
       ABS(current_value - prev_value) / NULLIF(prev_value, 0) * 100 AS change_pct,
       CASE WHEN ABS(current_value - prev_value) / NULLIF(prev_value, 0) > 0.15
            THEN 'FAIL' ELSE 'PASS' END AS result
FROM (
    SELECT metric_id, ts, value AS current_value,
           LAG(value) OVER (ORDER BY ts) AS prev_value
    FROM metrics
    WHERE metric_id IN ('EXT-006', 'EXT-007', 'EXT-008')
);
```

#### R08 时间对齐校验

```sql
-- 公式: |t_external - t_internal| < 2h
SELECT ext.metric_id, ext.ts AS t_ext, int.ts AS t_int,
       ABS(ext.ts - int.ts) AS time_diff,
       CASE WHEN ABS(ext.ts - int.ts) > INTERVAL '2 hours'
            THEN 'FAIL' ELSE 'PASS' END AS result
FROM metric_association_index idx
JOIN metrics ext ON idx.external_metric_id = ext.metric_id
JOIN metrics int ON idx.internal_metric_id = int.metric_id
WHERE ABS(ext.ts - int.ts) > INTERVAL '2 hours';
```

#### R09 空值检测

```sql
-- 公式: null_count / total_count < 5%
SELECT metric_id,
       SUM(CASE WHEN value IS NULL THEN 1 ELSE 0 END) * 100.0 / COUNT(*) AS null_rate,
       CASE WHEN SUM(CASE WHEN value IS NULL THEN 1 ELSE 0 END) * 100.0 / COUNT(*) > 5.0
            THEN 'FAIL' ELSE 'PASS' END AS result
FROM metrics
GROUP BY metric_id
HAVING null_rate > 5.0;
```

#### R10 跳变检测

```sql
-- 公式: |Δvalue| > 3 * σ
SELECT metric_id, ts,
       ABS(value - LAG(value) OVER (ORDER BY ts)) AS change,
       STDDEV(value) OVER (ORDER BY ts) AS sigma,
       CASE WHEN ABS(value - LAG(value) OVER (ORDER BY ts)) >
                 3 * STDDEV(value) OVER (ORDER BY ts)
            THEN 'FAIL' ELSE 'PASS' END AS result
FROM metrics
WHERE value IS NOT NULL;
```
