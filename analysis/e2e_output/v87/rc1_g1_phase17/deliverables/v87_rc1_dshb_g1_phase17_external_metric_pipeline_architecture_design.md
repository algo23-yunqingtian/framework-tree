## 2. 执行摘要

### 2.1 总体评估

V87.1 RC1 G1 Phase17外部指标数据流水线架构设计**全部完成**。基于Phase16指标映射结论, 设计完整的4层流水线架构(数据源→采集→标准化→存储), 覆盖8个数据源、42项指标。设计统一数据标准化层(时间粒度/单位/字段命名/空值填充), 设计3类熔断策略(采集失败/数据跳变/超时)与指数退避重试策略, 设计低频率增量采集调度与反爬风控策略。架构方案性能影响<2%, 3 Sprint/6周部署计划完成。

## 4. 流水线架构总览

### 4.1 四层架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    DSHB 外部指标数据流水线架构                     │
│                                                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ Layer 4: 存储层 (Storage Layer)                          │   │
│  │ - DSHB时序库 (metrics表)                                  │   │
│  │ - 联合校验结果 (dq_results表)                             │   │
│  │ - 质量评分 (quality_scores表)                             │   │
│  │ - 血缘追踪 (lineage表)                                    │   │
│  └──────────────────────────┬──────────────────────────────┘   │
│                             │                                   │
│  ┌──────────────────────────▼──────────────────────────────┐   │
│  │ Layer 3: 标准化层 (Standardization Layer)                 │   │
│  │ - 时间粒度标准化 (日/周/月→UTC时间戳)                       │   │
│  │ - 单位转换 (元/吨→美元/吨, 万吨→吨)                        │   │
│  │ - 字段命名标准化 ({source}_{category}_{name})              │   │
│  │ - 空值填充 (forward fill / null / interpolate)            │   │
│  └──────────────────────────┬──────────────────────────────┘   │
│                             │                                   │
│  ┌──────────────────────────▼──────────────────────────────┐   │
│  │ Layer 2: 采集层 (Ingestion Layer)                         │   │
│  │ - 百川API增量拉取 (15项指标, REST API)                     │   │
│  │ - 互联网网页抓取 (3个脚本, LME/SHFE/IEA)                   │   │
│  │ - 人工录入接口 (2项指标, 版本记录)                          │   │
│  │ - 付费API接入 (2项指标, 占位)                               │   │
│  │ - 系统计算 (1项指标, EXT-015)                              │   │
│  └──────────────────────────┬──────────────────────────────┘   │
│                             │                                   │
│  ┌──────────────────────────▼──────────────────────────────┐   │
│  │ Layer 1: 数据源层 (Data Source Layer)                     │   │
│  │ - 内部埋点 (18项指标, DSHB探针+JMX+OS)                     │   │
│  │ - 百川DB (15项指标, REST API)                             │   │
│  │ - 互联网 (3项指标, LME+SHFE+IEA)                           │   │
│  │ - 人工搜索 (2项指标, CRU+SMM+WoodMac)                      │   │
│  │ - 付费API (2项指标, Wind+Bloomberg)                        │   │
│  │ - 系统计算 (1项指标, EXT-015)                              │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 组件职责

| 层 | 组件 | 职责 | 关键能力 | 依赖 |
|:--:|------|------|---------|------|
| L4 | 存储层 | 数据持久化 | 时序库+关系型混合存储 | L3 |
| L3 | 标准化层 | 数据规范化 | 时间/单位/字段/空值转换 | L2 |
| L2 | 采集层 | 数据采集 | API拉取+网页抓取+人工录入 | L1 |
| L1 | 数据源层 | 原始数据 | 8个数据源接入 | 外部 |

### 4.3 数据流向

```
数据源 → 采集层 → 标准化层 → 存储层 → 联合校验 → DQ评估 → 告警 → Dashboard/审计
   ↓        ↓         ↓         ↓          ↓          ↓       ↓
   └────────┴─────────┴─────────┴──────────┴──────────┴───────┘
                                    ↓
                          血缘追踪 (全链路)
```
