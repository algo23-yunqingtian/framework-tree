## 4. 压缩+归档方案设计

### 4.1 压缩策略

| 维度 | 配置 |
|------|------|
| **压缩算法** | Zstandard (ZSTD) |
| **压缩级别** | Level 3 (平衡压缩率与性能) |
| **压缩比** | ~70% (3:1) |
| **索引压缩** | Bloom Filter + 列式压缩 |
| **热数据保留** | 7天热数据 (在线查询) |
| **冷数据归档** | 7天以上数据压缩归档至冷存储 |
| **归档存储** | S3兼容对象存储 (冷层) |
| **归档延迟** | 查询延迟+2.8% (冷数据查询) |

### 4.2 归档策略

| 维度 | 配置 |
|------|------|
| **归档触发** | 数据年龄>7天 |
| **归档频率** | 每日凌晨02:00 (低峰期) |
| **归档粒度** | 按天归档 (1个归档文件/天) |
| **归档大小** | ~1.5 GB/天 (压缩后) |
| **归档保留** | 90天 (Phase08归档目标) |
| **归档校验** | SHA256 + 行数校验 |
| **归档回滚** | 归档前保留原始数据72h |
| **归档回滚时间** | <30s |
