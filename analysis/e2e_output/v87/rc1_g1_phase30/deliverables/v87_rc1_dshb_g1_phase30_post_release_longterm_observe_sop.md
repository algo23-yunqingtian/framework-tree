## 6. 升级路径

### 6.1 升级矩阵

| 级别 | 角色 | 响应时间 | 权限 | 触发条件 |
|:----:|------|:--------:|------|----------|
| L1 | 值班工程师 | 0-15min | 执行回滚/重启 | P0/P1告警 |
| L2 | 技术负责人 | 15-30min | 决策回滚/降级 | P1告警未解决 |
| L3 | 架构团队 | 30min-2h | 架构决策/应急方案 | P1持续>30min |
| L4 | 项目总监 | 2h+ | 资源协调/上线决策 | P0持续>2h |

### 6.2 升级流程

```
P0告警 → 自动回滚 → 通知L1 → L1未解决(15min) → 通知L2 → L2未解决(30min) → 通知L3 → L3未解决(2h) → 通知L4
P1告警 → 通知L1 → L1未解决(30min) → 通知L2 → L2未解决(1h) → 通知L3
P2告警 → 记录 → 周会评审 → 计划修复
P3告警 → 记录 → 月度评审 → 优化建议
```
