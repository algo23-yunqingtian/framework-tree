| 字段 | 值 |
|------|------|
| **偏差描述** | NI_SHFE因子IC计算值与审计脚本计算值差异2.3% |

| **结论** | **豁免** — 窗口参数配置差异, 非代码缺陷 |

## 11. 修复代码变更清单

### 11.1 DEV-B-005: 动量因子Kahan求和

```python
# 文件: dshb/factors/factor_momentum.py
# 变更: 朴素累加 → Kahan求和算法

# 修复前:
cumulative_return = 0.0
for r in returns:
    cumulative_return += r  # 朴素累加, 浮点精度丢失

# 修复后:
cumulative_return = 0.0
compensation = 0.0  # Kahan补偿项
for r in returns:
    y = r - compensation
    t = cumulative_return + y
    compensation = (t - cumulative_return) - y
    cumulative_return = t
```

**变更行**: 12行 | **影响范围**: 仅CU_SHFE动量因子 | **性能影响**: <1%

### 11.2 DEV-B-006: Beta因子极端行情归一化

```python
# 文件: dshb/factors/factor_beta.py
# 变更: 添加极端行情归一化步骤

# 修复后新增:
def normalize_extreme_beta(cov_matrix, returns, threshold=0.05):
    """极端行情下Beta归一化"""
    max_return = max(returns)
    min_return = min(returns)
    if max_return > threshold or min_return < -threshold:
        # 极端行情检测: 对协方差矩阵进行归一化
        norm_matrix = cov_matrix / (max_return**2 + 1e-10)
        return norm_matrix
    return cov_matrix
```

**变更行**: 25行 | **影响范围**: 仅AL_SHFE Beta因子 | **性能影响**: <2%
