### 5.2 在途因子保护机制

```
熔断触发
  → 暂停新因子计算
  → 在途因子自动回滚(已计算部分丢弃, 回滚到上一稳定窗口)
  → 切回基线版本
  → 基线版本从上一稳定窗口继续计算
  → 确保因子时序连续性, 0丢失, 0损坏
```
