## 4. 差异分类规则（强制三分类标记）

所有差异点**必须**归类为以下三类之一，不允许"未分类"状态：

| 类别 | 定义 | 判定特征 | 上报级别 | 处置 |
|---|---|---|---|---|
| **① 数据噪声** | 随机测量抖动，复算后消失 | 单次出现 + 复算 SHA256 一致 + 无趋势 | P3（记录） | 记录，不处置 |
| **② 缓存抖动** | 冷热存储/索引加载引起的性能抖动 | 与 QPS 时序相关 + 短时尖峰 + 恢复后基线不变 | P2（通知） | 记录 + 监控趋势 |
| **③ 真实隐性缺陷** | 复算后仍存在、有系统性 | 复算后差异保留 + 有方向性 + 跨时段持续 | **P0（立即升级）** | **升级建单 + 回滚评估** |

### 4.1 分类判定流程

```
差异点出现
   │
   ├─ 复算 SHA256 是否一致？
   │    ├─ 一致 → ① 数据噪声（记录，不处置）
   │    └─ 不一致 → 继续
   │
   ├─ 差异是否与 QPS/缓存时序相关 + 短时自愈？
   │    ├─ 是 → ② 缓存抖动（P2 通知 + 监控趋势）
   │    └─ 否 → 继续
   │
   └─ ③ 真实隐性缺陷（P0 立即升级 + 建单 + 回滚评估）
```

### 4.2 分类基线（Phase18 已验证）

| 来源 | 比对点 | 差异点 | 分类结果 |
|---|---|---|---|
| Phase30 真实金丝雀 72h | 18,720 | 2 | ① 数据噪声 ×2 |
| Phase34 30 天长稳 720h | 20,160+ | 0 | — |

| Phase17 生产三方对账 | 729,600 | 0 | — |
| **合计** | **830,718+** | **2** | **① ×2 / ② ×0 / ③ ×0** |
