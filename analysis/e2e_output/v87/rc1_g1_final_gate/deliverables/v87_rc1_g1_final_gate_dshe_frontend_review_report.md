## 3. Phase36三项关注项评估与首7天监控预案(T1)

### 3.1 关注项清单与评估

Phase36 预检识别出3项关注项，本节逐项评估风险等级、监控策略与首7天观测计划。

#### 3.1.1 关注项#1: Query P99偏高18.6%

| 维度 | 值 |
|------|:--:|
| **关注项** | Query P99偏高 |
| **Phase35基线** | 42ms |
| **Phase36实测** | 49.8ms |
| **偏差** | +18.6% |
| **阈值** | <+20% (<50.4ms) |
| **余量** | 0.6pp (3.0%) |
| **峰值时段** | 02:00-03:00 (51ms) |
| **风险等级** | 🟡 中低 (接近阈值) |
| **真实风险判定** | ❌ 非真实风险 (阈值内可控) |

**原因分析**:
- Phase36 500并发用户回放下 Query P99 达49.8ms，较基线42ms偏高18.6%
- 02:00-03:00时段峰值51ms，缓存命中率降至91.8%(基线95%+)
- 原因: 并发峰值523人(超基线4.6%) + 缓存命中率下降 + 冷缓存回源
- 属于负载敏感区间，非架构问题

**监控策略**:
