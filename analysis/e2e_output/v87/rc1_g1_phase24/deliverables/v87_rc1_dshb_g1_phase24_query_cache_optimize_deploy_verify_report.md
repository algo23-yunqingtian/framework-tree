## 2. 查询缓存优化方案设计

### 2.1 优化目标

| 目标 | 值 | 来源 |
|------|:--:|------|
| 削减开盘峰值延迟 | ≥10% | Phase23运维分析 |
| 提升缓存命中率 | ≥96% | Phase23观测(93.8%) |
| 查询一致性 | 100% | 质量要求 |
| 内存增加 | <5MB | 性能约束 |
| 0数据丢失 | 0 | 数据完整性要求 |

### 2.2 缓存增强方案

| 方案项 | 设计 | 说明 |
|--------|------|------|
| 缓存结构 | LRU+TTL双策略 | LRU淘汰+TTL过期, 双重保障 |
| 缓存键设计 | 因子ID+时间窗口+参数哈希 | 精确匹配查询计划 |
| 缓存预热 | 开盘前15min预加载 | 避免开盘缓存冷启动 |
| 缓存失效策略 | 指数退避重试 | 避免缓存雪崩 |
| 一致性校验 | 哈希对账(HERMES) | 定期校验缓存结果一致性 |
| 内存保护 | 缓存内存上限2.5MB | 防止内存溢出 |
| 降级策略 | 缓存失效回退至全量计算 | 自动降级 |

### 2.3 缓存键空间设计

| 缓存键格式 | 示例 | 说明 |
|-----------|------|------|
| `{factor_id}:{window}:{param_hash}` | `F001:20280105:{sha256_16}` | 精确匹配查询计划 |
| 参数哈希 | 输入参数SHA256前16位 | 参数变更自动失效 |
| 时间窗口 | 15分钟窗口 | 与计算窗口对齐 |
