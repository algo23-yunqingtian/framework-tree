## 3. 桶预热优化背景

### 3.1 问题描述

Phase03 StageB 50%灰度在线观测期间，发现以下问题:

| 问题 | 描述 | 影响 |
|------|------|------|
| **P99延迟抖动** | 流量切换时路由桶预热时间不足(5s)，新增桶冷启动导致P99延迟抖动1.2ms | 影响P99稳定性 |
| **流量波动** | 桶预热期间流量分布不均，波动超过±0.2% | S2档抖动12s |
| **R-NEW-001** | V87 P99延迟270.8ms，接近目标阈值250ms | 75%灰度可能恶化 |

### 3.2 根因分析

```
流量切换时:
  路由桶重新分配 → 新增桶需要预热 → 预热不足5s → 冷启动P99抖动
  ↓
  5s预热 → 桶命中率89.5% → 部分请求走冷路径 → P99 +1.2ms
  ↓
  流量波动 → 69.2%~70.8% → 12s恢复
```

### 3.3 优化目标

| 目标 | 指标 | 目标值 | 当前值 |
|------|------|:------:|:------:|
| 延长预热时间 | 预热时长 | 10s | 5s |
| 改善预热策略 | 预热方式 | 渐进式(5→8→10s) | 一次性 |
| 降低P99抖动 | P99抖动 | <0.5ms | 1.2ms |
| 缩短流量波动 | 波动恢复时间 | <5s | 12s |
| 增加回退机制 | 预热失败回退 | 自动回退 | 无 |
| 增加监控 | 预热监控指标 | 3项 | 0项 |

## 4. 优化方案设计

### 4.1 参数变更

| 参数 | 优化前 | 优化后 | 变更类型 |
|------|:------:|:------:|:--------:|
| 预热时长 | 5s | 10s | 参数调整 |
| 预热策略 | 一次性预热 | 渐进式预热 | 策略变更 |
| 预热阶段 | 1阶段(5s) | 3阶段(5s→8s→10s) | 策略变更 |
| 预热失败回退 | 无 | 自动回退至5s | 新增机制 |
| 预热监控指标 | 无 | 3项 | 新增监控 |

### 4.2 渐进式预热策略

| 阶段 | 时间 | 预热进度 | 桶命中率 | 说明 |
|:----:|:----:|:--------:|:--------:|------|
| 阶段1 | 0~5s | 50% | 85.0% | 基础预热 |
| 阶段2 | 5~8s | 75% | 88.5% | 增强预热 |
| 阶段3 | 8~10s | 100% | 89.5% | 完全预热 |

### 4.3 预热失败回退机制

| 条件 | 动作 | 回退参数 |
|------|------|---------|
| 预热超时(>15s) | 自动回退至5s | 恢复旧参数 |
| 桶命中率<80% | 自动回退至5s | 恢复旧参数 |
| P99抖动>2.0ms | 暂停爬坡，等待预热完成 | — |
| 回退后恢复 | 重试渐进式预热(1次) | 渐进式10s |

### 4.4 预热监控指标

| 指标 | 含义 | 采集频率 | 告警阈值 |
|------|------|:--------:|:--------:|
| bucket_warmup_duration | 预热耗时 | 1s | >15s |
| bucket_warmup_p99_jitter | P99抖动(ms) | 1s | >2.0ms |
| bucket_warmup_fail_rate | 预热失败率 | 1min | >1% |
