## 2. Phase02 环境加固目标

### 2.1 核心目标

Phase02 的核心使命是将 Phase01 的裸基线测试环境**加固为可复现、可隔离、资源锁定**的基准测试平台，确保 V87 RC1 G1 多轮基准测试在相同条件下可比。

| 目标编号 | 目标名称 | 目标描述 | 优先级 | 验收条件 |
|---------|---------|---------|--------|---------|
| G-01 | **可复现性** | 三轮（Round 1/2/3）基准测试的环境状态完全一致 | 🔴 P0 | 环境快照 SHA256 一致 |
| G-02 | **资源隔离** | 基准进程独占 CPU/内存/磁盘 I/O，不受外部进程干扰 | 🔴 P0 | 资源偏差 ≤ 5% |
| G-03 | **网络隔离** | 基准进程不访问外网，不依赖外部 API | 🔴 P0 | 所有外部调用返回隔离错误 |
| G-04 | **数据隔离** | 基准使用独立数据库与 schema，不与生产/其他测试冲突 | 🔴 P0 | 数据隔离验证通过 |
| G-05 | **配置锁定** | 所有配置参数（JVM、环境变量、阈值）冻结不变 | 🟡 P1 | 配置校验和一致 |
| G-06 | **脏数据清理** | 清除 Phase01 遗留数据、重建索引、重置 WAL 与缓存 | 🔴 P0 | 清理前后指标对比符合预期 |
| G-07 | **功能开关状态** | 所有 V87 功能在基准测试中保持 ON 状态 | 🔴 P0 | 功能标志验证通过 |
| G-08 | **监控数据隔离** | 监控数据不干扰基准测试，基准不污染监控数据 | 🟡 P1 | 监控数据隔离验证通过 |
| G-09 | **SOP 合规** | 遵循 V86 遗留 SOP 中的相关操作规范 | 🟡 P1 | 25 SOP 中相关项全部合规 |
| G-10 | **健康检查** | 环境加固后通过 3 轮健康检查 | 🔴 P0 | 健康检查 3 轮全部通过 |
