## 7. Phase18新增缺陷详情

### 7.1 D-NEW-024: DQ噪声回退风险

| 字段 | 内容 |
|------|------|
| **ID** | D-NEW-024 |
| **名称** | DQ噪声回退风险(金丝雀部署期间) |
| **等级** | P3 |
| **发现阶段** | Phase18 DQ优化 |
| **描述** | DQ规则优化后, 7项规则阈值放宽。金丝雀部署期间(10%→50%→100%), 新阈值可能导致真实异常被漏报 |
| **根因** | 阈值从5σ改为4σ(金属), 从5%改为8%(web null), 从30min改为45-60min(delay) |
| **影响** | 低 — 金丝雀部署+7天双运行+自动回滚预案 |
| **缓解措施** | 1) 金丝雀部署(10%→50%→100%) 2) 7天双运行对比 3) 自动回滚(<4h) 4) 每日监控假阴性率 |
| **状态** | 🟡 观察中 |
| **关联风险** | G-024 |

### 7.2 D-NEW-025: 影子回测模型验证不足

| 字段 | 内容 |
|------|------|
| **ID** | D-NEW-025 |
| **名称** | 影子回测模型验证不足 |
| **等级** | P3 |
| **发现阶段** | Phase18回测数据 |
| **描述** | 30天数据集(1,260点)较短, 可能无法充分验证回测模型。8个相关性对中, 部分可能为虚假相关 |
| **根因** | 数据集时间窗口短(30天), 外部数据稀疏(IEA月度), 多重检验未校正 |
| **影响** | 低 — 需要90天扩展观测和样本外验证 |
| **缓解措施** | 1) Bonferroni校正 2) 交叉验证 3) 90天扩展观测 4) 样本外测试 |
| **状态** | 🟡 观察中 |
| **关联风险** | G-025 |

| 字段 | 内容 |

| **名称** | PARTIAL校正因子重新验证 |
