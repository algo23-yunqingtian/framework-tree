## 9. 缺陷根因分析

### 9.1 DEF-P99-001根因分析

| 分析项 | 内容 |
|--------|------|
| **根因类型** | 配置调优副作用 |
| **根因描述** | G1GC MaxGCPauseMillis从默认~30ms降至20ms, 降低暂停目标必然增加GC频率 |
| **影响链** | 参数调整 → GC频率增加12% → CPU使用率+1.6% → 仍在安全范围内 |
| **缓解措施** | 监控GC频率趋势, 必要时微调MaxGCPauseMillis至25ms |
| **预防措施** | 后续版本引入自适应GC暂停时间策略 |

### 9.2 DEF-P99-002根因分析

| 分析项 | 内容 |
|--------|------|
| **根因类型** | 数据量估算偏差 |
| **根因描述** | 热数据条目数量约800个, 高于设计预估下限500个 |
| **影响链** | 数据量增加 → 预热时间2.1min(仍在3min阈值内) → 不影响稳态性能 |
| **缓解措施** | 优化预热算法, 按访问频率排序减少低效条目加载 |
| **预防措施** | 引入预热时间自适应机制, 根据数据量动态调整 |
