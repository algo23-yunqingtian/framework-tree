### 8.2 P3 观察项 1：GC 频率增加

| 属性 | 值 |
|------|-----|
| **缺陷编号** | DEF-P99-001 |
| **标题** | GC 频率增加 12%，CPU 使用略增 |
| **严重程度** | P3 (观察项) |
| **描述** | GC 调优后 GC 频率从 18 次/分钟增加到 20 次/分钟（+11.1%），CPU 使用率增加 1.6%。这是因为调优后 GC 每次暂停时间大幅缩短（P99 -33.7%），触发更频繁的 GC 周期。整体 GC 开销（暂停时间 × 频率）反而降低。 |
| **影响评估** | 轻微影响。GC P99 暂停从 28.2ms 降至 18.7ms，Max 从 41.8ms 降至 32.4ms。CPU 使用率从 35.2% 升至 36.8%，距警戒线 60% 余量充足（23.2%）。 |
| **根因分析** | ZGC Generational 调优后，年轻代回收更频繁但更快，导致 GC 周期增加但每次耗时减少。这是预期行为，非异常。 |
| **处理策略** | 无需修复。持续监控 GC 频率和 CPU 使用率趋势。 |
| **监控计划** | 通过 Prometheus GC 指标持续监控，告警阈值设为 GC P99 > 25ms 或 CPU > 50%。 |
| **状态** | 🟡 观察中 (非阻塞) |

### 8.3 P3 观察项 2：缓存预热时间

| 属性 | 值 |
|------|-----|
| **缺陷编号** | DEF-P99-002 |
| **标题** | 缓存预热时间 2.1 分钟，略长于估算值 |
| **严重程度** | P3 (观察项) |
| **描述** | 缓存预热时间为 2.1 分钟，设计文档估算为 2-3 分钟，实测在估算范围内但接近下限。预热期间缓存命中率从 72% 逐步上升至 94.5%，性能在预热完成后稳定。 |
