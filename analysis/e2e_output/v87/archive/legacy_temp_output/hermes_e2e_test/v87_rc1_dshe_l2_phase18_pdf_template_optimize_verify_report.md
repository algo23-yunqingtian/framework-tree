### 3.2 优化方案

#### 图表间距优化

```
优化前 (V1.0):
┌─────────────────────┐
│ 图表1 (180px高)      │
└─────────────────────┘
│ 10px间距              │
┌─────────────────────┐
│ 图表2 (180px高)      │
└─────────────────────┘

优化后 (V1.1):
┌─────────────────────┐
│ 图表1 (165px高)      │
└─────────────────────┘
│ 15px间距              │
┌─────────────────────┐
│ 图表2 (165px高)      │
└─────────────────────┘

结果: 总高度不变, 图表高度-15px, 间距+5px
```

#### 图例位置优化

```
优化前 (V1.0): 图例在图表下方
┌─────────────────────┐
│ 图表 (180px高)       │
└─────────────────────┘
├ 图例 (40px高)        │
│ LC主力 | 7日均线 | 30日均线 │

优化后 (V1.1): 图例在图表右侧
┌─────────────┬──────────┐
│             │ 图例      │
│ 图表         │ LC主力    │
│ (180px高)   │ 7日均线   │
│             │ 30日均线  │
└─────────────┴──────────┘
图表宽180px, 图例宽60px
```

#### 图表分辨率优化

```
优化前: 72dpi, 文件较小但清晰度不足

影响: 文件大小从1.8MB→1.7MB (通过压缩其他元素抵消)
```

### 5.2 数值一致性校验方法

```
校验流程:
  1. 从Dashboard页面获取22项指标最新值
  2. 导出PDF周报
  3. 从PDF中提取22项指标值
  4. 逐一对比页面值与PDF值
  5. 记录差异项 (若有)
  6. 计算一致率

校验标准:
  - 数值精度: 小数点后2位 (价格类) / 整数 (数量类)
  - 时间戳: 精确到分钟
  - 单位: 完全一致
  - 差异阈值: 0 (必须完全一致)
```
