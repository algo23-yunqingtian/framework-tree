### 4.2 外部指标时间基准

| 类别 | 更新频率 | 发布时间 | 延迟 | 对齐策略 |
|---|---|---|---|---|
| 期货价格 | 日 | 收盘后2h | <4h | 最近交易日对齐 |

| 金融数据 | 月 | 次月5日 | <20d | 最近完整月份对齐 |
| 汇率 | 日 | 次日9:15 | <12h | 最近交易日对齐 |
| 大宗商品 | 日 | 实时 | <1h | 最近交易日对齐 |

### 4.3 时间对齐算法

```
┌──────────────────────────────────────────────────────────────┐
│                    时间对齐决策树                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  输入: 内部指标时间戳 + 外部指标时间戳                          │
│                                                              │
│  Step 1: 判断外部指标类型                                      │
│  ├── 日频指标 → 最近交易日对齐                                 │
│  ├── 月频指标 → 最近完整月份对齐                               │
│  └── 实时指标 → 最近交易日对齐                                 │
│                                                              │
│  Step 2: 计算时间偏差                                         │
│  ├── 偏差<24h → 直接对齐                                     │
│  ├── 24h≤偏差<72h → 最近交易日对齐                             │
│  └── 偏差≥72h → 最近完整周期对齐                              │
│                                                              │
│  Step 3: 生成对齐时间戳                                       │
│  ├── 保留原始时间戳(用于审计)                                  │
│  ├── 生成对齐时间戳(用于展示)                                  │
│  └── 记录对齐偏差(用于一致性分析)                              │
│                                                              │
│  输出: 对齐后时间戳 + 原始时间戳 + 对齐偏差                     │
└──────────────────────────────────────────────────────────────┘
```

### 4.4 时间对齐精度要求

| 指标类别 | 对齐精度要求 | 可接受偏差 | 状态 |
|---|---|---|---|
| 日频价格 | 交易日对齐 | ≤24h | ✅ |
| 日频库存 | 交易日对齐 | ≤24h | ✅ |
| 月频宏观 | 月份对齐 | ≤31d | ✅ |
| 月频金融 | 月份对齐 | ≤31d | ✅ |
| 实时汇率 | 交易日对齐 | ≤24h | ✅ |
| 实时大宗商品 | 交易日对齐 | ≤24h | ✅ |
| **平均对齐偏差** | **—** | **≤12h** | **✅** |

## 5. 数据一致性协议 (T0)

### 5.1 协议定义

```
┌──────────────────────────────────────────────────────────────┐
│              外部指标数据一致性协议 V1.0                         │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  协议版本: V1.0                                              │
│  生效日期: 2027-10-05                                        │
│  参与方: DSHE + DSHB + HERMES                                │
│                                                              │
│  一致性维度:                                                  │
│  ├── 时间一致性: 时间戳对齐, 偏差≤24h                          │
│  ├── 单位一致性: 统一单位标准, 无歧义                           │
│  ├── 精度一致性: 保留原始精度, 不做无意义截断                     │
│  ├── 口径一致性: 数据口径文档化, 三方确认                        │
│  └── 版本一致性: 数据版本标记, 可追溯                           │
│                                                              │
│  数据链路:                                                    │
│  ┌─────┐    ┌─────┐    ┌─────┐    ┌─────┐                   │
│  │百川库│ → │DSHB │ → │DSHE │ → │HERMES│                    │
│  │数据源│    │解析 │    │展示 │    │审计 │                    │
│  └─────┘    └─────┘    └─────┘    └─────┘                   │
│                                                              │
│  验证机制:                                                    │
│  ├── DSHB→DSHE: 数据完整性校验(字段数+空值率+范围检查)          │
│  ├── DSHE→HERMES: 审计日志写入(时间戳+指标值+数据源)            │
│  └── HERMES→DSHB: 对账反馈(偏差报告+异常标记)                  │
│                                                              │
│  异常处理:                                                    │
│  ├── 数据缺失: 标记"数据暂缺", 前值填充, 告警触发               │
│  ├── 数据跳变: 标记"异常跳变", 人工审核, 暂缓展示               │
│  ├── 数据延迟: 标记"数据延迟", 显示延迟时长, 超阈值告警           │
│  └── 单位错误: 自动修正+标记, 记录修正日志                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 数据质量校验规则

| 校验项 | 规则 | 阈值 | 处理 |
|---|---|---|---|
| 字段完整性 | 所有必填字段非空 | 100% | 缺失→标记+告警 |
| 数值范围 | 在历史P1-P99范围内 | ±3σ | 越界→标记+告警 |
| 空值率 | 每字段空值率 | ≤0.1% | 超阈值→告警 |
| 数据时效 | 在预期发布时间+24h内 | ≤24h | 超时→标记延迟 |
| 单位一致性 | 与数据源标注单位一致 | 100% | 不一致→修正+记录 |
| 跳变检测 | 与前一数据点偏差 | ≤50% | 超阈值→标记+审核 |
