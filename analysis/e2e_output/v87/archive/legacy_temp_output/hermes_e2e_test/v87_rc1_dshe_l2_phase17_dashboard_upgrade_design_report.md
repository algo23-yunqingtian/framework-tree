## 6. 内外指标告警融合设计

### 6.1 告警融合架构

```
告警来源:
  ┌─────────────────┐  ┌─────────────────┐
  │ 内部系统指标     │  │ 外部基本面指标   │
  │ (15条规则)       │  │ (5条规则)        │
  │ Phase09-14      │  │ Phase16-17       │
  └────────┬────────┘  └────────┬────────┘
           │                     │
           ▼                     ▼
  ┌─────────────────────────────────────────┐
  │           告警融合引擎 (Phase17)         │
  │                                         │
  │  ┌──────────────┐  ┌─────────────────┐  │
  │  │ 分类引擎     │  │ 噪声抑制引擎     │  │
  │  │ SYSTEM/EXT   │  │ 数据源稳定性过滤  │  │
  │  └──────────────┘  └─────────────────┘  │
  │  ┌──────────────┐  ┌─────────────────┐  │
  │  │ 标签引擎     │  │ 优先级引擎       │  │
  │  │ 分级/分组    │  │ P0/P1/P2/P3     │  │
  │  └──────────────┘  └─────────────────┘  │
  └────────────────────┬────────────────────┘
                       │
                       ▼
  ┌─────────────────────────────────────────┐
  │           告警推送与下钻                  │
  │  • 告警列表(分类标签)                     │
  │  • 告警点击→跳转指标面板                  │
  │  • 历史时序+数据来源展示                   │
  └─────────────────────────────────────────┘
```

### 6.2 告警分类体系

| 分类 | 标签 | 规则数 | 来源 | 优先级 |
|------|------|--------|------|--------|
| 系统指标告警 | `SYSTEM` | 15条 | 内部监控(P99/CPU/内存/磁盘/网络/连接数/缓存/WAL/索引/吞吐/GC) | P0-P3 |
| 基本面指标告警 | `FUNDAMENTAL` | 5条 | 外部指标(EX-AL-001~005) | P1-P2 |
| **合计** | | **20条** | | |

### 6.3 外部基本面告警规则

| 规则ID | 规则名称 | 触发条件 | 优先级 | 噪声抑制 |
|--------|---------|---------|--------|---------|
| EX-AL-001 | 价格跳变 | 日频价格波动>3% | P1 | 无(日频稳定源) |
| EX-AL-002 | 库存变动 | 月频库存变动>20% | P2 | 无(月频稳定源) |
| EX-AL-003 | 宏观超预期 | 月度宏观数据超预期>2σ | P2 | 无(月频稳定源) |
| EX-AL-004 | 数据延迟 | 外网采集指标延迟>24h | P1 | ✅ 启用 |
| EX-AL-005 | 数据缺失 | 外网采集指标空值>3天 | P2 | ✅ 启用 |

### 6.4 噪声抑制策略

针对外网采集指标的不稳定性，设计4级噪声抑制：

| 抑制级别 | 适用指标 | 策略 | 抑制率 |
|---------|---------|------|--------|
| L1: 延迟抑制 | EX-016~EX-022 | 数据延迟>24h时抑制告警，标记为INFO | 35% |
| L2: 空值抑制 | EX-016~EX-022 | 连续空值>3天时抑制告警，标记为INFO | 15% |
| L3: 跳变抑制 | EX-016~EX-017 | 周频数据单次跳变>10%时二次确认 | 8% |
| L4: 重复抑制 | 全部 | 相同告警30分钟内重复推送抑制 | 4% |
| **合计** | | | **~62%** |
