## 2. DSHB因子输出Schema接收与指标清单梳理

### 2.1 DSHB因子输出Schema

DSHB Phase19因子生产流水线输出以下7项核心因子指标:

| 编号 | 指标名称 | 英文标识 | 数据类型 | 频率 | 计算口径 |
|------|---------|---------|---------|------|---------|
| F-001 | 信息系数 | IC | float32 | 日频 | Rank IC, 20日滚动 |
| F-002 | 信息比率 | IR | float32 | 日频 | IC均值/IC标准差, 20日滚动 |
| F-003 | 方差膨胀因子 | VIF | float32 | 日频 | 因子回归R²/(1-R²) |
| F-004 | 因子衰减 | DECAY | float32 | 日频 | IC(t)/IC(t-k), k=1~20 |
| F-005 | 因子净值 | NAV | float64 | 日频 | 累计收益率+1 |
| F-006 | 波动率 | VOL | float32 | 日频 | 因子收益率年化标准差 |
| F-007 | 最大回撤 | MDD | float32 | 日频 | (max-min)/max |

### 2.2 衍生指标清单

基于核心指标衍生以下3项辅助指标:

| 编号 | 指标名称 | 计算方式 | 用途 |
|------|---------|---------|------|
| F-D01 | 因子有效性评分 | IC×0.4+IR×0.3+VIF逆×0.3 | 面板排序/风险提示 |
| F-D02 | 因子健康度指数 | 1-|MDD|/VOL×0.5-(1-IR)×0.5 | 健康度看板 |
| F-D03 | 因子共线性标记 | VIF>5=HIGH, VIF>3=MEDIUM | 告警/下钻定位 |

### 2.3 指标数据模型

```
FactorMetric {
  factor_id: string          // 因子唯一标识, 如 "F-MOM-001"
  factor_name: string        // 因子中文名
  commodity: string          // 品种: LC/CU/ZN/NI/SN/PB/AL/SI
  date: string               // 日期, ISO 8601
  ic: float32                // 信息系数
  ir: float32                // 信息比率
  vif: float32               // 方差膨胀因子
  decay: float32             // 因子衰减系数
  nav: float64               // 因子净值
  volatility: float32        // 波动率
  max_drawdown: float32      // 最大回撤
  effectiveness_score: float32  // 因子有效性评分 (衍生)
  health_score: float32      // 因子健康度指数 (衍生)
  collinearity_flag: string  // 共线性标记 (衍生)
  calc_timestamp: int64      // 计算时间戳(ms)
  pipeline_version: string   // DSHB流水线版本
  schema_version: string     // Schema版本
}
```

## 5. 因子指标计算口径与数据模型

### 5.1 指标计算口径

| 指标 | 计算公式 | 参数 | 说明 |
|------|---------|------|------|
| IC | rank_corr(factor_value, return) | 20日滚动窗口 | Spearman秩相关系数 |
| IR | mean(IC) / std(IC) | 20日滚动窗口 | IC均值与标准差之比 |
| VIF | R² / (1 - R²) | 多因子回归 | 因子间多重共线性 |
| 因子衰减 | IC(t) / IC(t-k) | k=1~20滞后阶数 | IC随时间衰减系数 |
| 因子净值 | cumprod(1 + factor_return) | 日频复利 | 因子策略净值曲线 |
| 波动率 | std(factor_return) × √252 | 日频年化 | 年化波动率 |
| 最大回撤 | (max - min) / max | 净值极值 | 峰值到谷值回撤 |

### 5.2 数据聚合策略

| 聚合方式 | 适用场景 | 聚合粒度 | 说明 |
|---------|---------|---------|------|
| 实时查询 | 当日数据 | 1min | 日内因子值更新 |
| 日频聚合 | 时序面板 | 1d | 默认查询粒度 |
| 周频聚合 | 趋势分析 | 7d | 周报展示 |
| 月频聚合 | 绩效回顾 | 30d | 月度绩效分析 |

| AL-F02 | IR跌破阈值 | IR < 0.5 持续3日 | WARN | 面板+推送 |
| AL-F03 | VIF过高 | VIF > 5.0 | CRITICAL | 面板+推送+短信 |
| AL-F04 | 因子值突变 | |Δvalue| > 3σ 单日 | WARN | 面板 |
| AL-F05 | 因子计算中断 | calc_timestamp > 30min | CRITICAL | 面板+推送+短信 |

### 7.2 告警分层体系

| 层级 | 告警类型 | 区分方式 | 响应策略 |
|------|---------|---------|---------|
| L1 原始指标异常 | 外部数据源延迟/缺失 | 标记为SOURCE异常 | 通知DSHB数据团队 |
| L2 因子计算异常 | 因子计算超时/中断 | 标记为CALC异常 | 自动重试+告警 |
| L3 因子健康度异常 | IC/IR/VIF异常 | 标记为HEALTH异常 | 标记+告警+下钻 |
| L4 因子失效预警 | 综合评分D级 | 标记为INVALID | 告警+建议停用 |

### 7.3 告警降噪策略 (复用Phase18)

| 降噪级别 | 说明 | 复用 |
|---------|------|------|
| L1 基础阈值 | 固定阈值告警 | ✅ 复用 |
| L2 持续次数 | 连续N次触发才告警 | ✅ 复用 |
| L3 变化率限制 | 变化率<5%不告警 | ✅ 复用 |
| L4 时间窗口去重 | 同因子同类型10min内去重 | ✅ 复用 |
| L5 延迟抑制 | 数据延迟不触发因子告警 | ✅ 复用 |
| L6 值域校验 | 值域外数据不触发因子告警 | ✅ 复用 |
