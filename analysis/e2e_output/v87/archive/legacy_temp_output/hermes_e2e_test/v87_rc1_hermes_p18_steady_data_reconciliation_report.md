## §1 任务目标

本报告面向 V87-RC1-G1 发布门禁的 **Phase18 稳态三方自动对账** 任务，对 **DSHB 因子输出 ↔ DSHE 看板指标 ↔ HERMES 网关** 三方链路在定时批量采样模式下的数据一致性进行综合分析与达标判定。

### 1.1 对账三方定义

| 方 | 角色 | 数据供给 | 采样方式 |
|---|---|---|---|
| **DSHB** | 底层因子真值引擎 | 26 因子时序数据，每小时整点快照 | 因子-小时级采样 |
| **DSHE** | 看板渲染指标层 | 渲染数据快照 8 次/天 → HERMES | 渲染级采样 |
| **HERMES** | 独立审计网关 | 全窗口哈希校验 + 三方对账引擎 | 自动批量采样 |

### 1.2 对账链路

```
DSHB 因子时序 ──(每小时整点快照)──→ HERMES 网关 ←──(渲染快照8次/天)── DSHE 看板
         │                                                            │
         └────────────── 三方自动对账引擎 ──────────────────────────────┘
                         (哈希校验 + 双版本比对 + 差异自动分类)
```

### 1.3 验收标准

- 三方一致率 ≥ 99.8%（V87-RC1-G1 门禁定义）
- 0 项系统性差异（哈希级）
- 熔断 0 次触发，回滚 SLA ≤ 3.2 min

| 维度 | 容差 | 判定 |

| DQ 子维度 | Δ ≤ 0.1 pp = PASS；0.1 < Δ ≤ 0.3 pp = WARN；Δ > 0.3 pp = FAIL | 分级判定 |
| KS 分布检验 | α = 0.01 | 捕获分布偏移 |
