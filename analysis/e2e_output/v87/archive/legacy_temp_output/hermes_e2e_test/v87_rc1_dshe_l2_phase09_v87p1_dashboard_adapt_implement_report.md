## 5. 查询语句优化改造

### 5.1 索引提示优化（P2 面板）

**改造前**：
```sql
SELECT ts, supply, demand, balance
FROM archive_90d_supply_demand
WHERE ts >= @start AND ts < @end
ORDER BY ts;
```

**改造后**：
```sql
SELECT /*+ INDEX(archive_90d_supply_demand idx_v87_90d_archive) */
  ts, supply, demand, balance
FROM archive_90d_supply_demand
WHERE ts >= @start AND ts < @end
ORDER BY ts;
```

**效果**：查询耗时 -3.2ms（预期 -3.5ms，达标率 91.4%）

### 5.2 聚合查询下推（P7 面板）

**改造前**：客户端 5min 粒度聚合 → 数据量 288 点/天

**改造后**：服务端 1min 粒度下推聚合 → 数据量 1,440 点/天，但聚合计算在 DSHB 侧完成

**效果**：DSHE 侧聚合计算耗时 -2.6ms（预期 -2.8ms，达标率 92.9%）

### 5.3 查询窗口自适应（P5 面板）

**改造前**：固定 24h 查询窗口

**改造后**：基于访问频次自适应调整查询窗口（1h–24h），高频访问自动缩小窗口

**效果**：缓存命中率提升 +0.3pp
