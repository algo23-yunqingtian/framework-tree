| schema 必需字段 | THS 对应字段 | 转换规则 | 状态 |

## 6. 渲染前必做适配清单

基于本次校验结果, 后续 THS 模板渲染前必须完成以下适配:

### 6.1 适配层(参照 t22_render_online.py::adapt_template)
1. `template_id` → `chart_id`
2. `chart_title` → 解析出 `title`(去除品种/节点/等N项/类型前后缀)
3. `variety`/`plot_type` → `meta.variety`/`meta.chart_type`
4. `indicator_name_list[]` → 展开为 `series[].name`(每项一个series)
5. 从 `单位` 字段推导 `y_axis.left.unit`
6. 新增缺失字段: `series[].zhiji_id`(需zhiji匹配)、`series[].status`(需校验)

### 6.2 风险预判
1. **节点对齐风险**: 3个模板(THS-AL-3.1/3.2/3.3)用高层节点, tree_config用细分节点(3.1.1-3.1.5), 需确定映射规则
2. **品种体系风险**: LI/LC/CU/ZN 在 THS 有但 PDF 无, 品种中文名映射表需补齐
3. **指标数风险**: 部分模板指标数>15(最多44), 单图指标过多需拆图或聚合
4. **频率缺失风险**: 153/155模板无频率信息, 渲染时无法确定时间轴粒度
5. **单位缺失风险**: 19个模板无单位, 纵轴单位需从指标名反推
6. **schema不兼容风险**: 全部模板需经适配层, 不可直接渲染(最大风险)
