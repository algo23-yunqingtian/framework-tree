# 人工评审核对清单 (Review Checklist)

> 工单: `HERMES_RENDER_SCRIPT_FIX_AND_MANUAL_REVIEW_PACKAGE`
> 适用批次: Batch-A / Batch-B / Batch-C

---

## 使用说明

1. 按批次逐一评审，每评完一条在 CSV 中填写评审结果
2. 本清单为逐条核对参考，每项打 ✓ 或 ✗
3. 全部核对完成后提交评审结果，运行 `review_result_apply.py` 回写

---

## 一、图表组合合理性

- [ ] **1.1** 图表类型与数据特征匹配（时序→折线/柱状、占比→饼图、对比→堆叠）
- [ ] **1.2** Y轴单位一致（同一Y轴的series单位相同）
- [ ] **1.3** 双Y轴配置正确（左轴/右轴单位合理，刻度范围合理）
- [ ] **1.4** 时间粒度一致（日/周/月/季，同一图内不混用）
- [ ] **1.5** 数据量级差异过大时已做标准化/分面处理

## 二、指标名称歧义

- [ ] **2.1** 系列名与 zhiji 实际指标名语义一致
- [ ] **2.2** 系列名无误导性（如"产量"标签配"销量"数据 → 需确认或修正）
- [ ] **2.3** 单位标注正确（万吨/吨/%/亿元等）
- [ ] **2.4** 时间范围标注清晰（如"2024年"、"周度"、"月度"）
- [ ] **2.5** 口径描述完整（如"国产+进口"、"仅国产"、"不含加工"）

## 三、跨品种错配

- [ ] **3.1** 品种代码正确（AL/AO/CU/LC/LI/NI/SI/SN/ZN）
- [ ] **3.2** 系列名中品种与实际品种一致
- [ ] **3.3** zhiji 指标名的品种前缀正确
- [ ] **3.4** 无其他品种的指标混入本品种模板

## 四、复合图例

- [ ] **4.1** 图例名称唯一（无重复图例名）
- [ ] **4.2** 图例名称非空字符串
- [ ] **4.3** 图例颜色与线型可区分
- [ ] **4.4** 图例位置合理（不遮挡图表主体）

## 五、双Y轴检查

- [ ] **5.1** 左轴单位与series匹配
- [ ] **5.2** 右轴单位与series匹配
- [ ] **5.3** 双轴刻度范围合理（不过大/不过小）
- [ ] **5.4** 双轴标签清晰标注

## 六、同花顺模板适配质量 (THS 模板专用)

- [ ] **6.1** THS 模板已匹配 zhiji_id（pending_match 状态解除）
- [ ] **6.2** 适配后指标口径与原始 THS 推荐一致
- [ ] **6.3** 图表类型适配合理（THS 原推荐 vs 适配后）
- [ ] **6.4** 系列名适配后语义正确
- [ ] **6.5** 数据粒度与 THS 原始粒度一致

## 七、风险处理

- [ ] **7.1** P0 冲突已人工确认（产量vs销量、场内vs场外等）
- [ ] **7.2** P1 冲突已人工评估（拟合vs指数、社库vs仓单等）
- [ ] **7.3** 白名单条目已过期检查（expiry_date）
- [ ] **7.4** INVALID/MISSING zhiji_id 已确认处理方式

## 八、最终决策

- [ ] **8.1** 评审结论已填写（通过/驳回/临时白名单放行）
- [ ] **8.2** 备注已填写（评审理由）
- [ ] **8.3** 评审人已签名
- [ ] **8.4** 评审时间已记录
