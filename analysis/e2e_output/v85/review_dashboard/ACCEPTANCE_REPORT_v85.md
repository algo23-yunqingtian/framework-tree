## 4. 人工复核操作指引

### 4.1 如何查看看板

1. 打开 `review_dashboard.html`（纯静态，零后端，浏览器直接双击即可）。
2. 页面顶部导航：**概览 → 告警直达 → 图表速览 → 全量表**。
3. 「概览」区看 12 个统计卡片 + 状态分布，确认大盘。
4. 「图表速览」区看 15 张渲染图，缩略图点击可开大图，卡片颜色对应状态。
5. 「全量表」区看全部 32 行 × 47 字段。表格横向可滚动，表头悬停显示完整字段名。

### 4.2 如何识别告警（颜色约定）

| 颜色 | 含义 | 本版条数 | 处置 |
|------|------|---------|------|
| 白（无底色） | 正常 | 27 | 常规确认 |
| 黄 | 稀疏（数据点过少） | 0 | 回查汇总文件 |
| 橙 | 权限缺失 | 5 | 见 §4.3 |
| 红 | 数据源下线（停更/下线） | 0 | 回查汇总文件 |

导航栏有「稀疏 / 权限缺失 / 下线」三个筛选按钮，点击后表格只显示对应状态行；右上角搜索框可按 idx / 品种 / 指标名 / ID 过滤。

### 4.3 人工确认处置方式

**第一步：确认候选是否可用（放行 16 行）**
- 看「候选指标名」是否与「图表短名」语义一致。
- 看「单位匹配」列：绿色「是」= 一致；红色「否」= 冲突（本版仅 ID02069937 一条，已自动换算，仍需人工确认换算系数正确）。
- 看「数据_status」列：「权限缺失」= 数据可拉但缺元数据权限，5 行均需人工确认是否可接受。
- 看「unified_warning」列：非「无」的 5 行已回填 `unit_match_false(MEDIUM) [回填@a12804329]`，表示该候选共享同一 a12804329 元数据缺口，需一并评估。

**第二步：填写人工结论**
- 在全量表最右列「人工结论(待填)」输入框直接填写（如 `可绑定` / `换候选` / `废弃` / `待路径修复`）。
- 填写内容自动存入浏览器 localStorage，刷新不丢失。
- 填写完毕点击「导出人工结论 (.csv)」下载，交回主脑合并。

**第三步：处置拦截/弃权样本（16 行）**
- **11 条拦截**（最终分=0）：候选指标名与图表语义完全无关（如「中国净进口量变化/锡」匹配到「电力净进口」），直接废弃，无需人工再看。
- **5 条弃权**（路径污染）：ID01464616 / ID01464612 系列动力电池候选指标名正确，但源路径无 `|` 层级。若确认需要，走「修路径」流程而非改匹配规则。

**第四步：处理看板外告警**
- 打开 `../unified_warning_summary.md` §2.2，核对 3 条不在看板的告警（ID00259727 / CM0000053686 / a10166705）。
- ID00259727 停更 1446 天（最后更新 2022-10-13），建议从候选池永久移除并寻找替代序列。
