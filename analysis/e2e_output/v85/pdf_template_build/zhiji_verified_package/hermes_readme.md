```python
import json

with open('pdf_web_chart_template_hermes_ready.json') as f:
    data = json.load(f)
```

## 5. PART_OK 模板限制与使用建议

### 使用建议

1. **渲染时跳过无效 series**：`verify_status == 'MISSING'` 的 series 无有效数据，渲染时跳过
2. **INVALID series 标记警告**：`verify_status == 'INVALID'` 的 series 原 ID 无效，建议人工核查后补新 ID
3. **优先使用 FULL_OK 模板**：FULL_OK 模板所有 series 均已校验通过，可直接用于渲染
4. **PART_OK 模板可部分渲染**：仅渲染 VALID/FILLED 的 series，其余显示占位符
