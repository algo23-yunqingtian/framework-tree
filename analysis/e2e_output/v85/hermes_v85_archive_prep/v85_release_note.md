## 1. 版本概述

V85 是期货图表模板风险管控系统的完整交付版本，覆盖 **488个图表模板**（PDF 333 + THS 155），**9个有色金属品种**（AL/AO/CU/LC/LI/NI/SI/SN/ZN），实现从风险识别→黑名单校验→人工评审→Gate准入门禁的全链路管控。

| 维度 | 数据 |
|------|------|
| 模板总数 | 488 (PDF 333 + THS 155) |
| series总数 | 2721 (回放) |
| 渲染成功率 | 328/333 (98.5%) |
| 渲染就绪率 | 97/488 (19.9%) |
| 黑名单规则 | 31条最终版 + 1候选(BL-009a) |
| 风险库 | 50条独立 (v2版, 50字段) |
| 别名库 | 864条 (7品种) |
| 混淆对 | 13条 (8P0 + 5P1) |
| Gate检查 | 46项HERMES + 6项DSHB v2 |
| 评审完成率 | 0/488 (待人工3-5天) |
| zhiji拉取 | 248/248 (100%, 缓存复用) |
| 品种覆盖 | 9个 (AL/AO/CU/LC/LI/NI/SI/SN/ZN) |
