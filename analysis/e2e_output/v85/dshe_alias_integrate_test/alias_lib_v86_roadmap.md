## 2. 各批次明细

### B1 · 别名库导入 + 冲突裁定 — **P0**

| 项 | 值 |
|---|---|
| 计划写入 aliases | **2253 条**（覆盖 1650 个 canonical 键） |
| 已存在跳过（幂等） | 249 条 |
| 需人工裁定冲突 | **165 条**（`alias_norm` → 多个原子键） |
| 需抽检 | 100 条（V5 门禁与标签等价，无独立筛查力） |
| 预估人工量 | **1.5–2.5 人天** |
| 预期收益 | 别名库从「离线资产」变为「在线匹配信号」。R-07 直查命中当前为 **负向 0 / 正向 14**，导入后预期正向命中显著上升 —— **具体幅度未知，必须导入后实测** |

阻塞原因：不修则别名库对匹配链路零贡献（R-07 命中 0），B2–B5 的注册工作无处落地。

### B2 / B3 / B4 · THS canonical 注册 — **P1 / P1 / P2**

HERMES 2359 个 THS 系列名中 **2304 个未解析（97.67%）**，其中 **2299 个是 `UNREGISTERED_ONLY`**（即缺少 canonical 注册），仅 5 个是真正缺别名映射。

| 批次 | 品种 | 条目 | 优先理由 | 预估人工量 |
|---|---|---|---|---|
| B2 | NI | **746**（741 unreg + 5 target） | 488 模板中 NI 79 个、P0 33 个，量最大 | 3.5–5 人天 |
| B3 | SN 536 + ZN 381 | **917** | SN 是高危混淆对高频品种（402 跨品种对中的核心） | 4–6 人天 |
| B4 | SI 324 + LI 209 + AL 69 + CU 39 | **876** | AL/CU 各仅 69/39，可打包 | 3.5–5 人天 |

**关键前置事实**：这 2299 行**不是别名缺失，而是 canonical 缺失**——即 iv1 中没有对应的指标键。因此这不是「补别名」，而是「先注册指标、再补别名」，工作性质与 B1 完全不同，工作量也应按指标注册口径估算。

**候选质量警告**：这 2304 行中 **442 行（19.2%）的 `best_match` 是跨品种错误候选**（如 `Cancelled warrants`(CU) → `硫化镍矿：产量`(NI)、`综合使用电价`(AL) → `工业硅电价`(SI)）。**直接按 best_match 注册会把 19.2% 的错误固化进 iv1**，必须先经人工或跨品种校验过滤。

### B5 · TARGET_HIT 别名映射 — P2

仅 **5 条**（全部 NI，`best_match` 可解析但 THS 原名缺映射）。预估人工量 **0.25 人天**。规模极小，可并入 B2 一并处理。

### B6 · 高危混淆对处置 — **P1**

| 项 | 值 |
|---|---|
| 总数 | 409（**跨品种 402 / 同族 7**） |
| 级别 | P0 102 / P1 307 |
| category | 算法高风险 372 / 警告 15 / 跨品种 14 / 口径冲突 4 / 互斥 3 / 品种口径 1 |
| evidence | 全部为 `IV1_NEAR`（iv1 内部近邻），即**同名指标被两个品种 key 各建一份** |
| 预估人工量 | P0 102 条 × 2 分钟 ≈ **3.5 人天**；P1 307 条可批量规则处理 ≈ 1.5 人天 |

处置分两支：
- **跨品种 402 条**：多数已由 R-01 品种锚点拦截（T2.1 负向 22/41 命中 `variety_anchor_violation`），无需新增黑名单，仅需**确认锚点覆盖**。
- **同族 7 条**：真正的歧义风险，需要建别名或拆键。

### B7 · 歧义清单二次复核 — P2

本轮已用 V86 判定 + 别名库标注 + 高危混淆对三源交叉重分级 448 行：

| 新等级 | 行数 | 占比 | 主要依据 |
|---|---|---|---|
| W0_错误别名 | **437** | 97.5% | V86 硬拦截 434（`variety_anchor_violation` 250 / `blacklist_precheck` 183） |
| W3_高风险 | 6 | 1.3% | RISK_DB P0 4 + 降级复核 2 |
| W2_待复核 | 3 | 0.7% | dice 边界 |
| W1_可靠同义 | 2 | 0.4% | V86 通过 + synonym_merge |

**与上一轮分级一致性 56.2%**（一致 252 / 不一致 196）。不一致几乎全部是「上一轮 W2/W1 → 本轮 W0」，即上一轮低估了拦截面。

结论：**448 行中有 437 行不需要人工判同义**——它们已被 V86 硬拦截，只需确认「不应合并」。真正需要人工的是 **W3 6 行 + W2 3 行 = 9 行**。预估人工量 **0.5 人天**（比上一轮按 448 行估算的 3 人天低一个量级）。

### B8 · FP 标签噪声清理 — **P1**

正向 200 条中 140 条被拦（FP 140），原因分布：

| 原因 | 条数 | 性质 |
|---|---|---|
| `variety_anchor_violation` | 55 | 旧流水线错配，V86 拦截正确 → **标签噪声** |
| `variety_neutral_target_review` | 43 | 品种中性目标，需人工确认 → **待复核** |
| `below_threshold` | 39 | 相似度不足，需判读 → **待复核** |
| `blacklist_precheck` | 3 | 黑名单命中 → 需确认 |

上一轮已确认「抽样 42 条同族 FP 为旧流水线口径错误，V86 拦截正确」。**Precision 22.65% 偏低是标签噪声造成的低估，不是规则缺陷。** 建议：
1. 对 55 条跨品种 FP 做标签修正 → 修正后 Precision 预期显著回升（**具体值需重算，不在此预估**）。
2. 43 条品种中性目标进入人工复核队列。
预估人工量 **1–1.5 人天**。

## 6. 风险与依赖

1. **19.2% 候选跨品种错误**（442 条）：若按 best_match 直接注册进 iv1，会把错误固化到源头数据，且**回滚成本高**（iv1 是有写权限方独占的真源）。必须在 B2 前增加跨品种校验闸门。
2. **B1 门禁无独立筛查力**：2502 条 100% 通过源于标签与门禁等价，抽检缺失意味着 2253 条写入的真实质量未知。
3. **两处 DSH-B 输入缺失**（`semantic_blacklist_v85_final.json` / `full_488_template_playback_result.csv`）：B6 的「确认锚点覆盖」无法用 DSH-B 回放数据交叉验证，只能依赖本仓库 488 代理数据。
4. **回归套件覆盖不足**：200 条正向为抽样（池 1179），B8 的 140 FP 归因存在抽样误差；建议 B8 完成后对全池 1179 重跑。
5. **所有收益预估均未经实测**：唯一实测锚点为当前基线，任何批次执行后必须重跑 `combine_eval.py` 与回归套件再更新指标。
