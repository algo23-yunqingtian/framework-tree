## 1. 结论A：`matched_name` 不是比对目标

**旧草稿声称**：`confidence = Dice(match_norm(series_name), matched_name)`；真实目标实为 `canon_name(indicator_key)`。

### 1.1 测试设计

对每一行同时计算三个候选目标下的 Dice 得分，与记录值比较（|Δ| ≤ 0.011 判为命中）：

| 候选 | 定义 |
|---|---|
| `canon_name` | `indicators_v1.json[indicator_key].name` |
| `matched_name` | THS CSV 的 `matched_name` 列（展示字段） |
| `indicator_key` | 指标键字面量（控制项） |

### 1.4 判定

> **结论A：VERIFIED（成立）**

1. 全量命中率 1021 vs 558（1.83 倍）；

## 2. 结论B：44.0% 的行两列不一致

**旧草稿声称**：44.0% 的 fuzzy 行 `canon_name` 与 `matched_name` 不一致。

### 2.1 测试设计（两个口径）

| 口径 | 定义 | 用途 |
|---|---|---|
| **口径1（原始字符串）** | `canon_of(r) != r["matched_name"]` 逐字符比对 | 与 `build_alias_library.py` 第 576 行 `NR_TARGET_GAP` 完全同口径 |
| **口径2（语义）** | 仅统计两侧**均为真实名称**的行，排除 `matched_name` 为空串或字面量 `"None"` | 衡量"两列都有值但冲突" |

两口径都跑，不做先验选择。

### 2.2 真实结果

| 口径 | 数值 |
|---|---|
| 口径1：canon ≠ matched（原始字符串） | **499 / 1134 = 44.0%** ← 精确复现草稿数值 |
| 口径2：两侧真实名称且相同 | 635 (56.0%) |
| 口径2：两侧真实名称且**不同** | **201 (17.7%)** |
| 口径2：`matched_name` 缺失 | **298 (26.3%)** —— 全部为字面量 `"None"`，空串 0 |
| canon_name 缺失 | 0 |
| 校验 same+diff+absent | 635+201+298 = 1134 ✓ |

**分层（口径2）**：

| resolution_source | 一致 | 不一致 | 合计 | 不一致率 |
|---|---|---|---|---|
| indicators_v1 | 621 | 0 | 621 | **0.0%** |
| zhiji_note | 14 | 201 | 215 | **93.5%** |

499 = 298（`matched_name` 缺失）+ 201（两列真实冲突）。

### 2.4 判定

> **结论B：VERIFIED_WITH_CAVEAT（数值成立，表述夸大）**

- 44.0% 这一数值本身**可精确复现**（499/1134，与源脚本同口径）；
- 但其中 **298 行（26.3%）属于 `matched_name` 缺失**（字面量 `"None"`），即**根本没有可比对目标**，与"两列冲突"是两种不同现象；
- 真正"两列均有真实名称且不同"的只有 **201 行（17.7%）**，全部落在 zhiji_note 通道（该通道 93.5% 不一致）。

**旧报告推理链需修正之处**：将"无可比对目标"与"两列冲突"混为一谈，导致"不一致率"这一指标被高估 26.3 个百分点。修正后的正确表述是：

> indicators_v1 通道两列 100% 一致；zhiji_note 通道 513 行中仅 14 行两列同名，其余 499 行因 matched_name 缺失或口径层级不同而不同于 canonical 名。

## 4. 方法学限制

1. **容差敏感性未做扫描**。TOL=0.011 取自源脚本。若容差放宽至 0.02，`neither` 类 113 行中的部分可能转为命中，但 canon vs matched 的相对优势在裁决子集 191:0 的格局下不会逆转。
2. **zhiji_note 通道机制未解释**。该通道 `matched_name` 缺失率 58.1%（298/513），而 canon_name 命中率仍达 90.4%。缺失原因（未返回候选 / 候选被拒 / 字段语义不同）本轮未追查，不影响结论A判定。
3. **10.0% 不可复现残留**仍无标签解释，仅能观测到"记录值系统性低于复算值"的单向偏差，推测为额外的衰减因子，本轮未定位。
4. 验证仅在静态文本层面进行，不涉及价格数据、策略或 PnL；不调用 zhiji API。
