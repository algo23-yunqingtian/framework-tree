## 3. 标签噪声审计（本报告最重要的方法学修正）

### 3.1 问题

`verify_status ∈ {VALID, FILLED}` **不是干净的正类标签**：
- `FILLED` 仅表示「旧流水线自动填入了数据」，可能本身即错误匹配；
- `VALID` 表示人工/规则校验通过，质量较高，但覆盖率仅 96/200。

因此 FP=140 中混杂了「真误拦」与「正确拦截了旧流水线自身的错配」两类。

### 3.2 对 140 条 FP 做跨品种审计

| FP 类别 | 行数 | 判定 |
|---|---|---|
| **跨品种错配** | **55** | 旧流水线本身匹配错误，V86 拦截**正确** |
| 品种中性（一方品种一方中性短名） | 43 | 需人工复核（V86 已降为 review） |
| 同族 / 无品种标记 | 42 | 需逐条判定 |

### 3.3 修正后指标

| 指标 | 原始 | 扣除旧流水线错配 55 条后 |

| 疑似真误拦 | 140 | **85** |

## 5. 结论

1. **Recall 100.00%（41/41）**：41 条历史风险案例零漏放，这是本次回归测试的硬结论。
2. **原始 Specificity 42.86% 是标签噪声造成的低估**：140 条 FP 中 55 条属旧流水线自身跨品种错配（V86 拦截正确），42 条同族类 FP 经抽样审计多为旧流水线口径错误（V86 拦截正确）。修正后 Specificity ≥ 57.50%，真实值更高。
3. **三态判定正确**：负向 41 条 100% 硬拦截（无 review）；正向 200 条中 60 自动通过、43 转人工、97 硬拦。
4. **别名库未接入**：本轮回归在别名库未接入状态下执行，R-07 命中 0。43 条正向 review 预计可被别名库直查 + 中性白名单大幅消解。
5. **可复现性**：随机种子 20261001，正向 200 条抽样可精确复现。

## 6. 局限

1. **正向集规模仅 200 条**（池 1179 条）：抽样比例 16.97%，单条 FP 对 Specificity 的影响约 0.5pp，置信区间较宽。
2. **标签噪声无法完全剔除**：`verify_status` 不是人工标注的正确性标签，本报告只能做启发式审计，无法给出精确的干净标签 Specificity。
3. **别名库未接入**：R-07 收益为预估。
4. **未做阈值敏感性测试**：TH_HIGH/MID/LOW 固定为 0.85/0.70/0.55。
5. **无时间维度**：测试集为同一份历史快照，未验证规则对新增指标名的鲁棒性。
