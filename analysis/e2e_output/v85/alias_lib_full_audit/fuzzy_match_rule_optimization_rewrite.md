## 1. 旧模糊匹配算法反推

### 1.1 输入规模

| 项 | 值 |
|---|---|
| THS 匹配统计总行 | 2354 |
| `match_type == fuzzy_name` 且 confidence 非空 | **1134** |
| resolution_source | indicators_v1 **621** / zhiji_note **513** |

### 1.2 反推公式（复现率 90.0%）

```
confidence = Dice( match_norm(series_name), canon_name(indicator_key) )
```

- `match_norm(s)`：全角转半角 + 压空白 + 剥尾部单位括注 `(元/吨)` 类
- `canon_name(k)`：`indicators_v1.json[k].name`
- `Dice(a,b) = 2·|multiset(a)∩multiset(b)| / (|a|+|b|)`，字符多重集 Sørensen-Dice
- 容差 `|Δ| ≤ 0.011`

| 分层 | n | 复现 | 率 | 不可复现 |
|---|---|---|---|---|
| indicators_v1 | 621 | 557 | **89.7%** | 64 |
| zhiji_note | 513 | 464 | **90.4%** | 49 |
| **合计** | **1134** | **1021** | **90.0%** | **113** |

### 1.3 比对目标消融（决定性）

| 候选目标 | 独立命中 | 命中率 |
|---|---|---|
| `canon_name(indicator_key)` | **1021** | **90.0%** |
| `matched_name`（CSV 展示列） | 558 | 49.2% |
| `indicator_key` 字面量（控制项） | 81 | 7.1% |
| canon **or** matched | 1021 | 90.0% |

分层看：indicators_v1 通道 canon/matched 均为 557（两列恒等）；zhiji_note 通道 canon **464** vs matched **1**。**裁决子集**（canon 与 matched 得分差异 > 0.011，记录值只能归属一方）共 200 行，其中 canon_wins **191**、matched_wins **0**。

> **结论：`matched_name` 是展示字段，不是比对目标。** 已在本轮独立复核 VERIFIED（`verification_notes.md` §1）。

### 1.4 残留 113 行（10.0%）不可复现

113 行 = indicators_v1 64 + zhiji_note 49。系统性特征：**记录值一律低于复算值**（无高于复算值的样本），提示存在额外衰减因子（如长度惩罚、词序敏感项），但本轮未定位到具体实现。样例：

| series | 记录 | 复算 canon |
|---|---|---|
| 电解铝企业厂内铝锭库存 | 0.560 | 0.583 |
| 中国未锻轧铝及铝材月度出口量 | 0.588 | 0.788 |
| 中国未锻轧铝及铝材月度进口量 | 0.588 | 0.788 |
| SMM EQ-A铜升贴水 | 0.571 | 0.667 |
| 成交量（手） | 0.667 | 0.750 |
| 进口盈亏（元/吨） | 0.615 | 0.667 |

**限制声明**：残留部分无标签解释，不影响 90.0% 主体的公式判定，但阈值调优（§5 R-06）应以复算值而非记录值为准。

### 1.5 两列不一致率（**本稿修订项**）

| 口径 | 数值 | 说明 |
|---|---|---|
| 原始字符串比对（=源脚本 `NR_TARGET_GAP` 口径） | **499 / 1134 = 44.0%** | 旧稿引用值，数值可复现 |
| 语义比对：两侧均为真实名称且不同 | **201 / 1134 = 17.7%** | 真实冲突 |
| 其中 `matched_name` 缺失（字面量 `"None"`） | 298 / 1134 = 26.3% | 无可比对目标，非冲突 |

分层：indicators_v1 通道 621 行两列 **100% 一致**；zhiji_note 通道 513 行中仅 14 行同名，不一致率 93.5%（其中 298 行系 matched_name 缺失）。

> 旧稿把「无可比对目标」与「两列冲突」合并计入 44.0%。修正口径后，真实同义冲突率 **17.7%**。此修正不改变任何规则的必要性 —— 冲突样本中的跨品种错配（如「LME铝总库存 → 镍：3个月合约：收盘价」）正是 R-01b 品种锚点的目标。

## 4. 规则集（含 R-01b 补充）

规则按顺序短路执行，返回三态 `{accept, review, reason}`：

| 序 | 规则 | 条件 | 返回 | 语义 |
|---|---|---|---|---|
| 1 | **R-01b** 品种锚点硬校验 | 双方品种族均识别且交集为空 | `block` | 跨品种立即拦截 |
| 2 | **R-05** 黑名单前置 | 命中 25 条黑名单规则（已剪枝，见 §5） | `block` | 已知错配模式 |
| 3 | **R-02** 口径互斥硬表 | 命中 `EXCL_HARD`（口径对） | `block` | 产量↔消费量等 |
| 4 | **R-03** 品种中性目标降级 | 一方识别到品种、另一方为中性短名 | `review` | 禁止自动放行，人工复核 |
| 5 | **R-06** 分层阈值 | Dice ≥ TH_HIGH(0.85) 且同族 → `accept`；≥ TH_MID(0.70) → `accept`+soft_flag；< TH_LOW(0.55) → `block` | 三态 | 相似度兜底 |
| 6 | **R-07** 别名库直查 | 命中别名库 canonical 且 relation ∈ 自动通过层 | `accept` | **本轮新增能力位**（见 §6） |

三态语义（`decision_semantics`）：

| 态 | 含义 |
|---|---|
| `accept` | 自动通过 |
| `review` | **降级人工复核（禁止自动放行）**，非硬拦截 |
| `block` | 硬拦截 |

阈值：`TH_HIGH=0.85` / `TH_MID=0.70` / `TH_LOW=0.55`。`NEUTRAL_WHITELIST` 与 `NEUTRAL_WHITELIST_CANON` 初始为空集 —— 这是 R-01b/R-03 高触发的直接原因，也是别名库导入的直接收益点。

## 7. 局限

1. **90.0% 之外 10.0% 无解释**：残留 113 行记录值系统性低于复算值，衰减因子未定位。
2. **zhiji_note 通道机制未知**：该通道 matched_name 缺失 58.1%，缺失成因未追查。
3. **阈值敏感性未扫描**：TH_HIGH/MID/LOW 取自旧流水线隐含行为，本轮未做网格搜索。
4. **黑名单仅静态评估**：25 条规则的召回率以 41 条历史案例为分母，样本量小，单条规则的置信区间宽。
5. **触发词命中计数含重复**：一个 series 可命中多个触发词，命中量之和 > 1134。
6. **别名库在本稿评估中尚未接入**：R-07 收益为预估，实测见 `regression_test_report.md`。
7. **不含价格数据、策略与 PnL**：全部为静态文本/字符串比对模拟，无回测、无 API 调用。
