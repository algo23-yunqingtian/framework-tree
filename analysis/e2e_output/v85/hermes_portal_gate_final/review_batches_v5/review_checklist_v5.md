# 人工评审核对清单 v5 (Review Checklist v5)

> 工单: HERMES_V85_PORTAL_FINAL_INTEGRATE_GATE_FULL_CHECK_AND_REVIEW_BATCH_PACKAGE
> 适用批次: Batch-A / Batch-B / Batch-C (v5)
> v5新增: 别名核验项(§9) + 混淆指标核验项(§10)

---

## 使用说明

1. 按批次逐一评审，每评完一条在CSV中填写评审结果
2. 本清单为逐条核对参考，每项打 ✓ 或 ✗
3. 全部核对完成后提交评审结果，运行 `review_result_apply.py` 回写

---

## 一、图表组合合理性

- [ ] **1.1** 图表类型与数据特征匹配（时序→折线/柱状、占比→饼图、对比→堆叠）
- [ ] **1.2** Y轴单位一致（同一Y轴的series单位相同）
- [ ] **1.3** 双Y轴配置正确（左轴/右轴单位合理，刻度范围合理）
- [ ] **1.4** 时间粒度一致（日/周/月/季，同一图内不混用）
- [ ] **1.5** 数据量级差异过大时已做标准化/分面处理

## 二、指标名称歧义

- [ ] **2.1** 系列名与 zhiji 实际指标名语义一致
- [ ] **2.2** 系列名无误导性（如"产量"标签配"销量"数据 → 需确认或修正）
- [ ] **2.3** 单位标注正确（万吨/吨/%/亿元等）
- [ ] **2.4** 时间范围标注清晰（如"2024年"、"周度"、"月度"）
- [ ] **2.5** 口径描述完整（如"国产+进口"、"仅国产"、"不含加工"）

## 三、跨品种错配

- [ ] **3.1** 品种代码正确（AL/AO/CU/LC/LI/NI/SI/SN/ZN）
- [ ] **3.2** 系列名中品种与实际品种一致
- [ ] **3.3** zhiji 指标名的品种前缀正确
- [ ] **3.4** 无其他品种的指标混入本品种模板

## 四、复合图例

- [ ] **4.1** 图例名称唯一（无重复图例名）
- [ ] **4.2** 图例名称非空字符串
- [ ] **4.3** 图例颜色与线型可区分
- [ ] **4.4** 图例位置合理（不遮挡图表主体）

## 五、双Y轴检查

- [ ] **5.1** 左轴单位与series匹配
- [ ] **5.2** 右轴单位与series匹配
- [ ] **5.3** 双轴刻度范围合理（不过大/不过小）
- [ ] **5.4** 双轴标签清晰标注

## 六、同花顺模板适配质量 (THS 模板专用)

- [ ] **6.1** THS 模板已匹配 zhiji_id（pending_match 状态解除）
- [ ] **6.2** 适配后指标口径与原始 THS 推荐一致
- [ ] **6.3** 图表类型适配合理（THS 原推荐 vs 适配后）
- [ ] **6.4** 系列名适配后语义正确
- [ ] **6.5** 数据粒度与 THS 原始粒度一致

## 七、风险处理

- [ ] **7.1** P0 冲突已人工确认（产量vs销量、场内vs场外等）
- [ ] **7.2** P1 冲突已人工评估（拟合vs指数、社库vs仓单等）
- [ ] **7.3** 白名单条目已过期检查（expiry_date）
- [ ] **7.4** INVALID/MISSING zhiji_id 已确认处理方式

## 八、最终决策

- [ ] **8.1** 评审结论已填写（通过/驳回/临时白名单放行）
- [ ] **8.2** 备注已填写（评审理由）
- [ ] **8.3** 评审人已签名
- [ ] **8.4** 评审时间已记录

## 九、别名核验项（v5新增）

- [ ] **9.1** 别名库匹配结果已查看（alias_match字段）
- [ ] **9.2** 别名推荐指标已核对（alias_recommendation字段）
- [ ] **9.3** 别名相似度≥70分时确认匹配合理
- [ ] **9.4** 别名与原始指标名语义一致（非同名异义）
- [ ] **9.5** 别名对应zhiji_id有效（格式校验 ^ID[a-zA-Z0-9_]+$）

## 十、混淆指标核验项（v5新增）

- [ ] **10.1** 混淆对命中结果已查看（confusion_hit字段）
- [ ] **10.2** P0混淆对（口径对立）已确认处置方式（阻塞/替换/白名单）
- [ ] **10.3** P1混淆对（语义近似）已人工评估
- [ ] **10.4** BL-021修复的3条误报已确认（CONF-009/010/011）
- [ ] **10.5** 高危混淆对不在白名单中（或白名单已审批）
