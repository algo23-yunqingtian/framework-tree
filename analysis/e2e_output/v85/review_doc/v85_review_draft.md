## 一、项目概述

### 1.1 项目背景

DSHB（Direct-Smart-Hermes-Bridge）是 framework-tree 指标匹配引擎的核心验证工具链。项目目标：

- 验证 **匹配模型** 在铝产业链指标上的精确率与召回率
- 打通 **端到端数据链路**：匹配引擎 → 知几API → 元数据质检 → 看板渲染
- 识别并量化 **数据质量风险**，为上线决策提供数据支撑

### 1.2 评审目标

| 维度 | 评审内容 | 验收标准 |
|------|---------|---------|
| 匹配模型 | v4→v85 指标演进 | P=100%, F1≥85% |
| 数据链路 | zhiji API 拉取成功率 | ≥95% |
| 元数据覆盖 | indicators_v1 库收录率 | ≥80% (当前 29.1%) |
| 告警覆盖 | FP+POS 全量质检 | 100% 覆盖 |
| 数据质量 | 异常指标识别与分类 | 全部有标签 |
