## 七、模糊匹配校准逻辑

### 7.1 算法概述

```
匹配流程:
1. 从indicator_alias_library.csv加载864条别名
2. 计算: Dice(match_norm(series_name), canon_name(indicator_key))
3. 阈值判定:
   - Dice >= 0.85: HIGH_CONFIDENCE → 自动匹配
   - 0.60 <= Dice < 0.85: MEDIUM_CONFIDENCE → 需人工确认
   - Dice < 0.60: LOW_CONFIDENCE → 拒绝匹配
4. 黑名单校验: 对匹配结果应用31条规则
5. 输出: BLOCKED / PASS / NOT_BLOCKED
```

### 7.2 已知误判模式

| 误判类型 | 根因 | 受影响规则 | 缓解措施 |
|---------|------|-----------|---------|
| 跨品种误匹配 | 不同品种指标名称高度相似（Dice>0.9） | BL-018/019/020/021/022 | 跨品种规则拦截 |
| 口径冲突误匹配 | 不同统计口径术语相似 | BL-001/002/003/008/009/025 | 口径互斥规则 |
| 库存口径混淆 | 库存天数vs库存量 | BL-012 | 方案B前置过滤 |
| 方向性缺失 | 仅检查forward方向 | BL-009 | BL-009a候选 |
| 数据缺失盲区 | matched_name为空 | BL-020/021/022 | 需上游数据修复 |

### 7.3 DSHE辅助提示

- 409条high_risk_confusion_pairs作为算法层参考（非规则层）
- 102条P0级混淆对（Dice>=0.9）
- 307条P1级混淆对（Dice>=0.7）
- 覆盖品种: AL, AO, CU, LC, LI, NI, SI, SN, ZN
