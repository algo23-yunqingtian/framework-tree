## 3. 已知限制与边界

| # | 缺陷 | 根因 | 修复方式 |

- PDF 模板 6 品种（LC 100 / AO 63 / SI 48 / NI 47 / AL 38 / SN 37，无 CU/PB）
- 488 模板 = 333 PDF + 155 THS
- zhiji 时序缓存 248 个唯一 ID（已固化，禁止重拉）

### 3.3 不可变约束

- `feature/v85-chart-template` 分支锁定，禁止合并 main
- `indicators_v1.json` / `tree_config.json` 只读
- 原始 PDF/THS 模板只读
- zhiji API 零调用（缓存已固化）

1. `git checkout feature/v85-chart-template`
