## 3. Grafana 面板 PDF 布局调整

### 3.1 布局调整原则

```
┌─────────────────────────────────────────────────────────────┐
│  PDF 图表布局调整原则                                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  原则 1: 保持 Grafana 面板 ID 不变                             │
│  ├─ 仅调整 gridPos 坐标和子图顺序                             │
│  └─ 不修改面板 JSON 计算逻辑 (NO_PANEL_JSON_MODIFICATION)     │
│                                                             │
│  原则 2: PDF 图表子图顺序与 Grafana 面板顺序一致               │
│  ├─ Stat 指标在上行 (y=0)                                    │
│  ├─ 图表 (TS/Pie/Bar) 在中间行 (y=4)                         │
│  └─ Table 在底部行 (y=8)                                    │
│                                                             │
│  原则 3: 指标展示顺序按 PDF 规范排列                          │
│  ├─ 核心指标 (PASS率/歧义率/吞吐) 在左侧 (x=0)               │
│  ├─ 辅助指标 (门禁/告警) 在右侧 (x=12)                       │
│  └─ 对比指标 (V85 vs V86) 在底部 (y=8)                       │
│                                                             │
│  原则 4: 注释补充替代新增子图                                 │
│  ├─ 无数据源的指标使用 Text 注释展示                          │
│  └─ 告警规则在面板注释中说明                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
