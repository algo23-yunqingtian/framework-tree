### 3.2 偏差修正详解

#### D-01: PASS 率语义修正

**修正前**:
```
门户显示: P0 拦截率 87.5% (blocked / total)
V86 引擎: PASS 率 96.40% (pass / total)
```

**修正后**:
```
门户面板区分为:
┌─────────────────────────────────────────────────────┐
│  别名解析 PASS 率:    96.40%  (4,476 / 4,643)       │
│  规则拦截率:          100.0%  (488 / 488)           │
│  ─────────────────────────────────────────────────── │
│  口径说明:                                            │
│  alias_pass_rate = 别名正确解析为 canonical_key       │
│  rule_block_rate = 规则命中黑名单拦截                  │
│  两者独立计算, 不同语义, 不混用                       │
└─────────────────────────────────────────────────────┘
```

│  口径说明:                                            │
│  alias_block_rate = 黑名单/F4 抑制导致的别名阻断      │

## 4. 别名库统计口径统一

### 4.1 统一口径定义

| 指标 | 统一口径 | 计算方式 | 单位 |
|------|----------|----------|------|
| 别名条目总数 | 别名库 CSV 总行数 | `len(alias_library)` | 条 |
| Canonical Key 去重数 | 去重后的 canonical_key 数量 | `len(set(canonical_keys))` | 个 |
| 覆盖品种数 | 别名库中出现的品种数 | `len(set(varieties))` | 种 |
| 品种分布 | 各品种条目数及占比 | `count_by(variety) / total` | 条 / % |
