## §2 基线冻结概述

V86-RC2 G1 生产基线于 2026-10-18 全面冻结，标志着 G1 通道从开发验证阶段正式进入生产就绪状态。冻结范围涵盖以下六大策略域：

| 策略域 | 冻结范围 | 状态 |
|--------|----------|------|
| 流量策略 | 影子流量、V85流量、切换开关 | ✅ 已冻结 |
| 熔断阈值 | 错误率、延迟、健康检查 | ✅ 已冻结 |
| 降级规则 | L1~L4 四级降级 | ✅ 已冻结 |
| 告警规则 | LR-001~LR-010 长稳告警 + RB-001~RB-006 回滚触发 | ✅ 已冻结 |
| 回滚策略 | 4级优先级 + 6类触发 + 15项验证 | ✅ 已冻结 |
| 审计策略 | 8事件184字段、SHA256、三方对账 | ✅ 已冻结 |

**冻结依据**：Phase2 全链路长稳 + 故障注入测试通过（综合评分 93.85 → Phase3 复测 99.00），所有 P0/P1 阻断项归零，P2 跟踪项全闭环。

### 3.3 降级规则

| 级别 | 名称 | 触发条件 | 动作 | 恢复条件 |
|------|------|----------|------|----------|
| **L1** | 缓存降级 | 缓存命中率 **< 90%** | 启用本地缓存，降低后端负载 | 命中率恢复 ≥ 90% 持续 5min |
| **L2** | 异步降级 | 队列积压 **> 5000 条** | 非关键请求转为异步处理 | 积压 < 1000 条持续 5min |
| **L3** | 功能降级 | 错误率 **> 10%** | 关闭非必要功能模块 | 错误率 < 3% 持续 10min |
| **L4** | 流量降级 | **P0 故障告警** | 全部降级至安全模式 | P0 解除 + 人工确认 |

| 场景 | L1 | L2 | L3 | L4 |

| 轻微异常 | 启用 | 禁用 | 禁用 | 禁用 |
| 中度异常 | 启用 | 启用 | 禁用 | 禁用 |
| 严重异常 | 启用 | 启用 | 启用 | 禁用 |
| P0 故障 | 启用 | 启用 | 启用 | 启用 |
