## 1. 概述

### 1.1 评估背景

Phase22 阶段已完成 DSHB Bootstrap 系统从 0% 到 75% 流量梯度的分步提升，全程 72 小时观察。当前 DSHE V75-1.0 基线已锁定（`NO_MODIFY_V85=TRUE`），HERMES 全量检查项 60/60 PASS。Phase23 的任务是基于 Phase22 75% 流量 72 小时观察数据，通过容量建模与外推，评估系统在 **100% 全量流量** 下的容量表现，为生产准入决策提供量化依据。

```
┌─────────────────────────────────────────────────────────────────┐
│                Phase22 → Phase23 容量评估链路                      │
├─────────────────────────────────────────────────────────────────┤
│  Phase22 (75%, 72h观察)  ──线性/非线性外推──▶  Phase23 (100%)    │
│  DSHE V75-1.0基线锁定     ──蒙特卡洛模拟──▶   全量准入决策        │
│  HERMES 60/60 PASS        ──瓶颈矩阵──▶      容量规划建议         │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 评估目标

| 目标编号 | 描述 | 状态 |
|---------|------|------|
| G-01 | 基于 Phase22 数据，量化预测 100% 流量下各子系统容量指标 | ✅ 本报告覆盖 |
| G-02 | 识别全量流量下的潜在瓶颈点（≥8 个） | ✅ 矩阵化 |
| G-03 | 提供容量规划与扩容建议，含优先级、成本、预期效果 | ✅ 分级 |
| G-04 | 定义全量流量下的 RED/YELLOW/GREEN 阈值红线 | ✅ 三阶 |
| G-05 | 给出全量准入/有条件准入/禁止准入的明确建议 | ✅ 结论 |

### 1.3 方法论

本报告采用 **三线法**（Linear + Non-linear + Monte Carlo）进行容量外推：

1. **线性外推法**：基于 Phase22 各步骤间的线性斜率，直接投影至 100%
2. **非线性修正因子**：考虑系统负载超过阈值后非线性加速效应（修正系数 1.15-1.20×）
3. **蒙特卡洛模拟**：对关键参数施加随机扰动，计算容量指标的 P95/P99 置信区间

三线法的最终预测值为：`(线性预测 + 非线性修正预测) / 2`，并标记蒙特卡洛 P95 上界作为保守值。

## 2. 容量建模方法论

### 2.1 数据基础

Phase22 75% 流量 72 小时观察期覆盖了完整的流量爬坡过程：

| 梯级 | 流量占比 | 索引膨胀率(起始→峰值) | CPU(峰值) | CB-4(峰值) | DRIFT-002(峰值) | WAL P99 |
|------|---------|---------------------|----------|-----------|----------------|---------|
| Step 1 | 50% | 7.53% → 7.63% | 78% | 74ms | 3.72ms | 3.10ms |
| Step 2 | 60% | 7.65% → 7.72% | 82% | 76ms | 3.84ms | 3.25ms |
| Step 3 | 65% | 7.70% → 7.76% | 84% | 77ms | 3.90ms | 3.35ms |
| Step 4 | 70% | 7.75% → 7.82% | 87% | 79ms | 3.98ms | 3.48ms |
| Step 5 | 75% | 7.78% → 7.92% | 91% | 81ms | 4.08ms | 3.68ms |

### 2.2 线性外推法

线性外推假设各指标的增速在当前趋势下保持不变，投影至 100% 流量。

**线性斜率计算**（基于 Phase22 最后 5 个步骤）：

| 指标 | Δ 值/5% | 投影至 100% (×5) | 线性预测值 |
|------|--------|-----------------|----------|
| 索引膨胀率 | +0.14%/5% | 7.92% + 0.14%×5 | **8.62%** |
| CPU使用率 | +2%/5% | 91% + 2%×5 | **101%** 🔴 |
| CB-4延迟 | +2ms/5% | 81ms + 2ms×5 | **91ms** |
| DRIFT-002延迟 | +0.10ms/5% | 4.08ms + 0.10ms×5 | **4.58ms** |
| WAL P99 | +0.13ms/5% | 3.68ms + 0.13ms×5 | **4.33ms** |

### 2.3 非线性修正因子

系统负载超过阈值后存在非线性加速效应，需应用修正因子：

- **索引膨胀**：压缩策略在 75% 时的效率开始衰减，修正因子 **1.15×**
- **CPU**：线程竞争与 GC 压力非线性增加，修正因子 **1.18×**（已包含 100% 即 101% 的硬顶修正）
- **延迟类指标**：尾延迟加速效应，修正因子 **1.15×**

| 指标 | 线性预测值 | 修正因子 | 非线性预测值 |
|------|----------|---------|------------|
| 索引膨胀率 | 8.62% | 1.15× | **9.11%** |
| CPU使用率 | 101% | 1.18× → 封顶 | **101%** (封顶) |
| CB-4延迟 | 91ms | 1.15× | **104.7ms** |
| DRIFT-002延迟 | 4.58ms | 1.15× | **5.27ms** |
| WAL P99 | 4.33ms | 1.15× | **4.98ms** |

### 2.4 蒙特卡洛模拟方法

对每个关键指标，采用以下参数进行 10,000 次蒙特卡洛抽样：

| 参数 | 分布 | 均值 | 标准差 |
|------|------|------|-------|
| 索引膨胀系数 | Normal | 1.0 | 0.03 |
| 压缩效率波动 | Normal | 0.95 | 0.05 |
| 流量峰值因子 | Normal | 1.02 | 0.04 |
| GC停顿波动 | LogNormal | 1.0 | 0.08 |
| 网络抖动 | Normal | 0.01 | 0.02 |

蒙特卡洛模拟输出：
- **P50 中位值**：最可能结果
- **P95 上界**：保守估计值
- **P99 极端值**：极端场景

### 2.5 三线法融合

最终预测值计算方式：

```
最终预测值 = (线性预测值 + 非线性修正预测值) / 2
保守参考值 = 蒙特卡洛 P95 上界
极端参考值 = 蒙特卡洛 P99 值
```

**⚠️ 注意**：CPU 指标在线性外推下已达 101%（超出物理上限），修正后封顶为 101%，表明 CPU 在 100% 流量下存在硬性瓶颈。
