## 1. 工单概要

### 1.1 背景

DSHB V86-RC2 投产阶段自检发现：当前 zhiji API 服务端**不支持短ID (short_id) 前缀解析**，导致全部 178 项指标条目的 API 真实可取数率为 **0%**。

**核心阻塞**: DSHB 侧已将所有可自主修复项闭环（脚本造假重构、桥接表修订、元数据修正），剩余阻塞**完全依赖数据平台侧能力**。

### 1.2 需求概述

| 需求编号 | 需求名称 | 优先级 | 影响范围 |
|---------|---------|-------|---------|
| DEP-01 | short_id 前缀解析能力上线 | 🔴 P0 | 178 项指标全部阻塞 |
| DEP-02 | long_id-指标映射关系确认与修正 | 🔴 P0 | 8 项原有条目数据错配 |
| DEP-03 | API 权限模型调整 (permission_state=-4) | 🟡 P1 | 8 项原有条目中 i1-i7 |

## 2. 需求详情

### 2.1 DEP-01: short_id 前缀解析能力上线 (P0)

#### 2.1.1 问题描述

当前 zhiji API series 接口 (`/series?id={id}`) 仅支持完整 long_id 查询，**不支持** short_id 前缀解析。

DSHB 侧在构建 series API 请求时，使用 short_id 形式（如 `j25_tc`, `i1`-`i7`）作为查询参数，期望服务端自动解析 short_id 并定位对应数据系列。当前行为：

```
请求: GET /commodity/api/series?id=j25_tc
响应: HTTP 500 — {"error": "无法识别指标来源(id前缀): j25_tc"}

请求: GET /commodity/api/series?id=i1
响应: HTTP 200 — {"id": "i1", "permission_state": -4, "points": []}
```

#### 2.1.2 受影响指标

| 范围 | 数量 | 说明 |
|------|------|------|
| 8 项原有条目 | 8 | i1-i7 + j25_tc，短ID全部不可用 |
| 112 项 api_search 新增条目 | 112 | 短ID为 s_{semantic_id} 格式，不存在于 zhiji |
| 11 项 best_effort 新增条目 | 11 | 短ID同上 |
| 47 项 DERIVED 计算推导 | 47 | 依赖下游指标可取数 |
| **合计** | **178** | **全部阻塞** |

#### 2.1.3 需求内容

**功能需求**: zhiji API series 接口支持 short_id 前缀解析

| 项目 | 要求 |
|------|------|
| 接口 | `GET /commodity/api/series?id={short_id}` |
| 输入 | short_id (如 `j25_tc`, `i1`-`i7`) |
| 服务端行为 | 解析 short_id → 查找对应数据系列 → 返回完整数据 |
| 响应格式 | 与现有 long_id 查询一致: `{id, points, permission_state, ...}` |
| 不支持时 | 返回明确的错误信息 (非 HTTP 500)，如 `{error: "short_id_not_found"}` |

**测试用例**:
```
1. GET /series?id=j25_tc → 返回铅精矿TC加工费数据
2. GET /series?id=i1     → 返回铅锭社会库存数据
3. GET /series?id=i2     → 返回铅锭交易所库存数据
4. GET /series?id=i3     → 返回沪铅期货收盘价数据
5. GET /series?id=i4     → 返回铅锭现货价格数据
6. GET /series?id=i5     → 返回电解铅产量数据
7. GET /series?id=i6     → 返回沪铜期货收盘价数据
8. GET /series?id=i7     → 返回沪锌期货收盘价数据
9. GET /series?id=xxx_unknown → 返回 HTTP 404 + {error: "short_id_not_found"}
```

#### 2.1.4 验收标准

| # | 验收条件 | 验证方式 |
|---|---------|---------|
| AC-1 | 8 项原始 short_id 全部返回 HTTP 200 + 非空数据点 | DSHB 侧自动化复测 |
| AC-2 | 返回数据与预期指标语义匹配 | 人工抽样校验 (5 项) |
| AC-3 | 不支持的 short_id 返回明确错误 (非 HTTP 500) | DSHB 侧自动化测试 |
| AC-4 | 响应时间 ≤ 3 秒 | 压测报告 |
| AC-5 | 不影响现有 long_id 查询功能 | 回归测试 |

### 2.2 DEP-02: long_id-指标映射关系确认与修正 (P0)

#### 2.2.1 问题描述

使用 long_id 调用 series API 时，返回数据与预期指标**完全不匹配**。以下为实测样本：

| long_id | 预期指标 | 实际返回指标 | 匹配度 |
|---------|----------|--------------|--------|
| ID02226332 | 沪铅期货收盘价 | LME锌特高级库存 | 0% |
| ID02226333 | 铅锭现货价格 | LME有色库存 | 0% |
| ID02226334 | 铅锭社会库存 | LME钴库存 | 0% |
| ID02226335 | 铅锭交易所库存 | LME铝合金库存 | 0% |
| ID02226336 | 铅精矿TC加工费 | 碳酸锂回收料库存 | 0% |
| ID02226337 | 电解铅产量 | 碳酸锂回收料产量 | 0% |
| ID02226338 | 沪铜期货收盘价 | 碳酸锂回收料库存 | 0% |
| ID02226339 | 沪锌期货收盘价 | 碳酸锂回收料排产 | 0% |

**根因分析**: long_id 的分配规则可能为**顺序分配**而非**指标绑定分配**，导致 ID 与指标内容完全脱钩。

#### 2.2.2 需求内容

| 项目 | 要求 |
|------|------|
| 确认 ID 分配规则 | 说明 long_id 与指标的映射逻辑 |
| 修正映射关系 | 提供正确的 long_id → 指标映射表 |
| 提供指标反查能力 | 支持通过 long_id 查询指标名称/描述 |
| 支持搜索 API 精确匹配 | search API 返回结果应标记是否精确匹配 |

### 2.3 DEP-03: API 权限模型调整 (P1)

#### 2.3.1 问题描述

使用 i1-i7 调用 series API 时，返回 `permission_state=-4`，数据点数为 0。

```json
{
  "id": "i1",
  "permission_state": -4,
  "points": []
}
```

#### 2.3.2 可能原因

| 原因 | 概率 | 验证方式 |
|------|------|----------|
| DSHB 账号权限不足 | 中 | 数据平台确认账号权限配置 |
| 指标未绑定到数据源 | 高 | 数据平台确认指标-数据源映射 |
| 数据源已下线但索引未更新 | 低 | 数据平台核查数据源状态 |

#### 2.3.3 需求内容

- 确认 i1-i7 对应的数据源是否已绑定
- 如已绑定，确认 DSHB 账号权限配置
- 如数据源已下线，更新索引或删除过期条目
