## §1 概述

### 1.1 背景

StageD 30%灰度流量较20%增加50%，三项P1风险(索引膨胀、CB-4、DRIFT-002)在30%负载下余量极低。本SOP制定StageD 30%灰度完整应急预案，覆盖索引膨胀超限、CB-4延迟超限、DRIFT-002延迟超限、综合故障四大场景，确保回滚SLA ≤15min。

### 1.2 应急目标

| # | 目标 | 达成标准 |
|---|------|---------|
| 1 | 所有应急场景有预案 | 4/4场景覆盖 |
| 2 | 回滚SLA | ≤15min |
| 3 | 回滚验证 | 3次全部通过 |
| 4 | 应急响应时间 | <5min (从检测到开始执行) |
| 5 | 限流降级预案 | 9/9预案就绪 |

## §4 场景一: 索引膨胀超限应急

### 4.1 场景描述

30%灰度流量下，索引膨胀率可能突破WARN阈值(8.0%)。无缓解时预测8.06%，组合缓解后预测7.31-7.55%。如缓解措施效果不及预期，可能触发WARN/CRITICAL告警。

### 4.2 应急触发条件

| 级别 | 触发条件 | 持续时间 | 事件级别 |
|------|---------|---------|---------|
| WARN | ≥8.00% | 5min | P2 |
| 严重WARN | ≥8.50% | 2min | P1 |
| CRITICAL | ≥10.00% | 1min | P0 |

### 4.3 应急响应流程

```
索引膨胀率检测
       │
       ├── <7.80% ──→ 正常监控
       │
       ├── ≥7.80% ──→ L1预警
       │                │
       │                ├── 趋势可控 ──→ 继续监控
       │                └── 趋势恶化 ──→ L2限流
       │                                    │
       │                                    ▼
       │                          灰度限流至25%
       │                          + 执行重平衡
       │                                    │
       │                                    ├── 回落有效 ──→ 阶梯恢复
       │                                    └── 回落无效 ──→ L3降级
       │                                                        │
       │                                                        ▼
       │                                              灰度限流至20%
       │                                              + 压缩加密至每小时
       │                                                        │
       │                                                        ├── 回落有效 ──→ 稳定监控
       │                                                        └── 回落无效 ──→ L4熔断

```
