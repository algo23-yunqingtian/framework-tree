### 2.2 规则触发逻辑

```
采集指标值 → 对比基线冻结值 → 计算偏差百分比
  ├─ 偏差 ≤ ±15%: ✅ 正常，继续监控
  ├─ ±15% < 偏差 ≤ ±25%: ⚠️ WARN告警 (DRIFT-001/004/005/007)
  ├─ ±25% < 偏差 ≤ ±35%: 🔴 CRITICAL告警 (DRIFT-002/006/008)
  └─ 偏差 > ±35%: 🔴🔴 FUSE熔断 (DRIFT-003)
```
