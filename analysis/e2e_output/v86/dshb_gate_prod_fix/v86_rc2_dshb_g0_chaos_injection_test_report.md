## 1. 概述

### 1.1 背景

上一轮工单 `DSHB_V86_RC2_G0_SHADOW_TRAFFIC_ISOLATION` (commit `ba82d04`) 已完成 G0 影子投产底层流量路由切分、DEP-001 流量镜像配置、Gate V5 动态状态回调闭环、影子环境资源隔离加固。T3.1 联合预检已确认三方组件全部就绪 (106/106 PASS)。

本报告定义并验证混沌故障注入测试，在预发影子集群执行 5 类故障注入场景，验证自动熔断、流量保护、灰度决策回调触发 ROLLBACK、资源隔离的真实表现。

### 1.2 测试目标

1. 验证 DEP 实例宕机时熔断保护生效，V85 零影响
2. 验证网络抖动时延迟保护生效，指标采集完整性
3. 验证端口阻断时连接池保护生效，自动重连
4. 验证 mTLS 证书失效时鉴权拒绝，安全边界不泄露
5. 验证 Gate 服务下线时回调降级，状态切换正常
6. 观测熔断、限流、状态回调、指标采集完整性
7. 验证 HERMES 审计、DSHE 聚合大盘状态同步

### 1.3 测试范围
