## 1. 概述

### 1.1 背景

上游工单 `DSHB_V86_RC2_G0_G1_PREPARE_CROSS_CONSISTENCY_SYNC` (commit `0f8ef63`) 已完成 G0→G1 跨团队术语&指标对齐、DSHE 缺陷协同、G0 基线固化及 G1 预检准备，6 项交付物全部验证通过，P0 阻断项 0，V85 偏差 0.00%，跨团队一致性 100%。

本工单 `DSHB_V86_RC2_G0_TO_G1_RAMP_PHASE1_SHADOW_DEPLOY` 执行 G0→G1 Phase1 影子流量灰度放量部署，分 6 阶段灰度引流，持续采集 DEP/Gate 指标，执行实时预检、熔断保护、自动回滚验证，输出 Phase1 放量全量观测报告。

### 1.2 目标

1. 执行 G0→G1 全量预检脚本（106 项检查），确认所有组件就绪
2. 校验流量开关、熔断阈值、回滚钩子、审计事件采集链路连通性
3. 执行 6 阶段影子流量灰度放量：5%→15%→30%→50%→75%→100%
4. 采集全阶段 P99 分项时延、错误率、DEP 实例恢复时长、熔断触发耗时
5. 核对审计事件计数，与 HERMES、DSHE 大盘做三方比对
6. 校验 V85 基线偏差，保证全阶段 V85 侧 0.00% 影响
7. 记录所有告警事件，匹配 F1-TRIGGER~F5-TRIGGER 故障码，更新风险登记册 V1.2

### 1.3 放量阶段总览

```
阶段1: 5%  → 30min   基线验证
阶段2: 15% → 60min   稳定性验证
阶段3: 30% → 90min   性能验证
阶段4: 50% → 120min  容量验证
阶段5: 75% → 120min  长周期稳定性
阶段6: 100%→ 180min  满负载验证
─────────────────────────
总计:  180min (3h) 影子放量观测
```
