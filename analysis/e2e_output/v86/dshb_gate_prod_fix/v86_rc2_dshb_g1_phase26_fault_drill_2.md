## 1. 概述

### 1.1 演练背景

Phase26 30天长期稳定性运维期间, 第2轮故障注入演练于2026-11-20(Day 25)执行。本次演练为高难度场景, 包含流量脉冲(200%)和级联故障(上游依赖超时), 验证L0-L3全链路熔断降级能力, 特别是L3熔断链路的触发与恢复。

### 1.2 演练目标

1. 验证流量脉冲场景下自动限流能力
2. 验证级联故障场景下L3熔断能力
3. 验证L0-L3全链路熔断降级完整性
4. 测量L3熔断恢复耗时
5. 评估高压力场景下业务影响
6. 验证0数据丢失

### 1.3 演练时间

| 属性 | 值 |
|------|-----|
| 执行日期 | 2026-11-20 (Day 25) |
| 执行窗口 | 14:00-17:00 (3小时) |
| 执行方式 | 手动注入 + 自动响应 |
| 流量状态 | 100% (全量流量) + 脉冲 |
