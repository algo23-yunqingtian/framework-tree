### 3.3 基线漂移检测规则

#### 3.3.1 漂移检测算法

```
漂移检测算法 (Drift Detection Algorithm):

输入:
  - baseline_value: 冻结基线值
  - current_value: 当前观测值
  - check_interval: 检查间隔 (60s)
  - sample_window: 采样窗口 (5min)
  - drift_warn_pct: WARN阈值 (15%)
  - drift_critical_pct: CRITICAL阈值 (25%)
  - drift_fuse_pct: FUSE阈值 (35%)
  - consecutive_breach_count: 连续超阈次数 (3)

算法:
  1. 计算偏差比: deviation = |current_value - baseline_value| / baseline_value
  2. 计算百分比: deviation_pct = deviation * 100
  3. 判定等级:
     - deviation_pct ≤ drift_warn_pct → NORMAL
     - drift_warn_pct < deviation_pct ≤ drift_critical_pct → WARN
     - drift_critical_pct < deviation_pct ≤ drift_fuse_pct → CRITICAL
     - deviation_pct > drift_fuse_pct → FUSE
  4. 持续追踪:
     - 连续 consecutive_breach_count 次 WARN → 升级为 CRITICAL 告警
     - 连续 consecutive_breach_count 次 CRITICAL → 触发熔断
     - 连续 consecutive_breach_count 次 FUSE → 自动回滚

输出:
  - drift_level: NORMAL | WARN | CRITICAL | FUSE
  - drift_value: 当前偏差百分比
  - consecutive_breach_count: 连续超阈次数
  - action: NONE | ALERT | ESCALATE | CIRCUIT_BREAK | AUTO_ROLLBACK
```

#### 3.3.2 告警等级定义

| 等级 | 偏差范围 | 告警动作 | 通知对象 | 响应时间 |
|------|----------|----------|----------|----------|
| **NORMAL** | ≤ ±15% | 无告警，持续监控 | — | — |
| **WARN** | > ±15% 且 ≤ ±25% | 发送警告通知 | DSHB SRE团队 | 30min内确认 |
| **CRITICAL** | > ±25% 且 ≤ ±35% | 发送紧急告警 | DSHB SRE + Phase Lead | 15min内响应 |
| **FUSE** | > ±35% | 自动触发熔断/回滚 | 全团队 | 立即 |

#### 5.2.6 熔断触发逻辑

```
熔断触发逻辑:

FOR each metric in [idx_trace_P99, idx_fault_P99, idx_sev_ts_P99,
                    wal_write_P99, index_bloat, event_loss_rate]:
  
  1. 采集当前值 (5min窗口滑动平均)
  2. 计算偏差: deviation = |current - baseline| / baseline
  3. 判定等级:
     - deviation ≤ 15% → NORMAL
     - 15% < deviation ≤ 25% → WARN
     - 25% < deviation ≤ 35% → CRITICAL
     - deviation > 35% → FUSE
  
  4. 连续追踪 (连续N次超阈):
     - WARN 连续 3 次 → 升级为 CRITICAL 告警
     - CRITICAL 连续 3 次 → 触发熔断 (CIRCUIT_BREAK)
     - FUSE 连续 1 次 → 立即熔断 (IMMEDIATE_BREAK)
  
  5. 熔断动作:
     - CIRCUIT_BREAK → 停止G1灰度流量，全部切回V85
     - IMMEDIATE_BREAK → 立即停止G1，告警全团队
     - 恢复条件: 所有指标回到NORMAL 持续 15min → 重新允许灰度
```
