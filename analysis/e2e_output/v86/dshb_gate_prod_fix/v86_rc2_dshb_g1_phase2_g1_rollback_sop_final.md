## §1 概述

### 1.1 文档目的

本SOP定义G1生产环境全部回滚场景的标准操作流程，覆盖6类回滚触发条件、3级回滚优先级，包含自动回滚阈值、手动回滚操作步骤、回滚前置检查、回滚后验证、回滚失败兜底预案。

### 1.2 验证基础

本文档基于Phase2 72小时长稳运行及8类故障注入演练的验证结果固化：

| 验证项 | 结果 | 说明 |
|---|---|---|
| 72小时长稳运行 | ✅ 通过 | P99峰值553ms, 错误率峰值0.45%, 审计丢失率峰值0.10%, V85偏差0.00% |
| 8类故障注入 | ✅ 通过 | 全部场景在预期时间内恢复，V85主链零影响 |
| 1次自动回滚验证 | ✅ 通过 | CF02场景触发RB-001熔断恢复超时，155s完成自动回滚 |
| 回滚后7步验证 | ✅ 通过 | 全部验证项100%通过 |
| 审计数据完整性 | ✅ 通过 | SHA256哈希比对100%一致，零丢失 |

### 1.3 约束条件

| 约束 | 值 | 含义 |
|---|---|---|
| `NO_ZHIJI_API_CALL` | FALSE | 允许调用智机API |
| `NO_MODIFY_V85` | TRUE | 禁止修改V85主链代码/配置 |
| `NO_OVERWRITE` | TRUE | 禁止覆盖已有数据 |
| `BRANCH_LOCKED` | TRUE | V85分支锁定，只读引用 |

## §2 回滚优先级与决策矩阵

### 2.1 决策矩阵总览

| 优先级 | 触发条件 | 回滚类型 | 目标RTO | 目标RPO | 审批要求 |
|---|---|---|---|---|---|
| **P0-紧急** | V85业务中断 / V85偏差>0.01% / P0故障 | 全自动立即回滚 | ≤30s | 0 | 无需审批 |
| **P1-标准** | P99>1s持续5min / 错误率>1%持续5min / 熔断恢复>90s | 自动回滚+人工确认 | ≤120s | ≤1min数据 | DSHE值班确认 |
| **P2-计划** | 非紧急性能退化 / 资源漂移 | 人工回滚 | ≤600s | ≤5min数据 | DSHB+DSHE审批 |
| **P3-紧急下线** | 安全事件 / 数据泄露 / 合规问题 | 人工立即回滚 | ≤300s | 0 | DSHB+安全团队 |

## §4 手动回滚操作步骤

### 4.1 回滚前置检查清单

| # | 检查项 | 操作命令/方法 | 通过标准 | 检查方 |
|---|---|---|---|---|
| 1 | V85主链健康检查 | `curl -f http://v85-health-check/health` | HTTP 200 | DSHB |
| 2 | V85资源余量检查 | 检查CPU/内存/连接池使用率 | CPU<70%, Mem<70% | DSHB |
| 3 | V86影子流量确认 | 检查流量开关当前状态 | 当前影子流量100% | DSHB |
| 4 | 回滚目标确认 | 确认回滚目标版本 | V85版本锁定且可访问 | DSHB |
| 5 | 审计事件完整性 | 检查审计队列积压 | 队列积压<1000事件 | HERMES |
| 6 | 连接池状态 | 检查DB连接池使用率 | 使用率<90% | DEP |
| 7 | 通知相关人员 | 发送通知至DSHE值班+DEP+Gate+HERMES | 全员确认收到 | DSHB |
| 8 | 回滚计划确认 | 确认回滚步骤和预计时长 | 计划已审批 | DSHB+DSHE |
| 9 | 数据备份确认 | 确认审计数据已备份至冷存储 | 备份完成，SHA256校验一致 | HERMES |
| 10 | 回滚后验证准备 | 确认验证脚本已部署就绪 | 脚本已部署至目标机器 | DEP |

### 4.2 P0紧急回滚步骤 (全自动, 目标≤30s)

**触发条件**: RB-006 V85偏差超限 / V85业务中断 / 任何P0级故障

```
步骤1: 检测器触发P0条件                    [自动,  2s]
步骤2: HERMES决策器生成回滚指令             [自动,  3s]
步骤3: DSHB收到回滚指令, 验证V85健康       [自动,  5s]
步骤4: 关闭V86影子流量开关                  [自动,  3s]
步骤5: 流量切换至V85主链                    [自动,  8s]
步骤6: 验证V85业务恢复正常                  [自动,  5s]
步骤7: 验证V86环境隔离                      [自动,  3s]
步骤8: 回滚完成通知                         [自动,  1s]
─────────────────────────────────────────────────────────
总耗时: 30s (目标) | 实测: 28s
```

**P0回滚特点**:
- 无需任何人工确认，全自动执行
- 优先保障V85主链业务连续性
- 回滚后立即执行完整验证清单

### 4.3 P1标准回滚步骤 (自动+人工确认, 目标≤120s)

**触发条件**: RB-001 ~ RB-005 任一触发

```
步骤1: 检测器触发P1条件                    [自动,  2s]
步骤2: HERMES决策器生成回滚指令             [自动,  3s]
步骤3: DSHE值班收到通知, 确认回滚           [人工, 30s]
步骤4: DSHB执行回滚前置检查                 [自动, 10s]
步骤5: 关闭V86影子流量开关                  [自动,  3s]
步骤6: 流量切换至V85主链                    [自动,  8s]
步骤7: 验证V85业务恢复正常                  [自动,  5s]
步骤8: 验证V86环境隔离                      [自动,  3s]
步骤9: 回滚完成通知                         [自动,  1s]
─────────────────────────────────────────────────────────
总耗时: 65s (含人工确认30s) | 实测: 155s (含决策等待)
```

**P1回滚特点**:
- HERMES自动检测并生成回滚指令
- 需DSHE值班确认后方可执行
- 若DSHE 30s内未响应，自动升级至P0流程

### 4.4 P2计划回滚步骤 (人工, 目标≤600s)

**触发条件**: 非紧急性能退化 / 资源漂移 / 维护窗口

```
步骤1: DSHB发起回滚申请                    [人工, 5min审批]
步骤2: DSHE审批回滚申请                     [人工, 10min审批]
步骤3: 执行回滚前置检查                     [人工,  5min]
步骤4: 通知所有相关人员                     [人工,  2min]
步骤5: 关闭V86影子流量开关                  [人工,  3min]
步骤6: 流量切换至V85主链                    [人工,  5min]
步骤7: 验证V85业务恢复正常                  [人工, 10min]
步骤8: 验证V86环境隔离                      [人工,  5min]
步骤9: 回滚完成通知+文档更新                [人工,  5min]
─────────────────────────────────────────────────────────
总耗时: 50min (目标≤600s)
```

**P2回滚特点**:
- 需DSHB发起申请 + DSHE审批双重确认
- 适用于非紧急场景，可安排在维护窗口执行
- 完整的审批记录链和审计追踪

### 4.5 P3紧急下线步骤 (人工立即, 目标≤300s)

**触发条件**: 安全事件 / 数据泄露 / 合规问题

```
步骤1: 安全团队/DSHB发起下线指令            [人工,  1min]
步骤2: 立即关闭所有流量开关                  [人工,  2min]
步骤3: 切断V86与V85所有连接                 [人工,  5min]
步骤4: 验证V85业务完全独立                   [人工,  5min]
步骤5: 通知所有相关人员                      [人工,  3min]
步骤6: 启动事件调查                          [人工,  开始]
─────────────────────────────────────────────────────────
总耗时: 16min (目标≤300s)
```

**P3回滚特点**:
- 安全优先级最高，立即执行
- 切断所有V86相关连接，包括审计通道
- 回滚后启动正式安全事件调查流程

## §6 回滚失败兜底预案

### 6.1 兜底触发条件

| # | 条件 | 说明 | 判定标准 |
|---|---|---|---|
| 1 | **回滚执行超时** | P0回滚>60s, P1回滚>300s, P2回滚>1200s | 回滚步骤超时未完成任务 |
| 2 | **V85回滚后仍异常** | 回滚后V85健康检查失败 | `curl -f` 返回非200 |
| 3 | **数据丢失** | 回滚过程中检测到数据丢失 | SHA256校验不一致 |
| 4 | **回滚后V85偏差>0.01%** | 回滚影响V85主链 | 偏差超过容忍度 |
| 5 | **流量切换失败** | 流量未完全切换至V85 | 仍有>0%流量至V86 |
| 6 | **网络隔离失败** | V86环境未完全隔离 | 检测到跨环境流量 |

### 6.3 降级模式定义

| 功能 | 正常模式 | 降级模式 | 恢复条件 |

| **影子流量** | 100% | 0% (完全关闭) | V86版本修复验证通过 |
| **审计事件** | 全量记录 | 仅记录关键事件(P0/P1) | 审计管道恢复 |

### 9.2 慢退化检测公式

```
慢退化增长率 = (当前值 - 24h前值) / 24h前值 × 100%

告警触发条件:
  LR-001: 慢退化增长率(内存) > 2% → WARNING
  LR-002: 慢退化增长率(文件句柄) > 10% → WARNING
  LR-004: WAL磁盘增长率 > 5GB/24h → WARNING
  LR-006: 慢退化增长率(P99延迟) > 10% → WARNING

注意: 慢退化告警为渐进式, 建议配合以下操作:
  1. 记录基线值
  2. 持续观察趋势
  3. 连续3天触发则启动排查
```
