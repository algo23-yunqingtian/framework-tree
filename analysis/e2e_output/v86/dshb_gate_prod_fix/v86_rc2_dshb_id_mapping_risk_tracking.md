## 4. R-P04 API搜索匹配率风险 (NEW)

### 4.1 风险定义

| 维度 | 值 |
|------|-----|
| 风险ID | R-P04 |
| 风险名称 | API搜索匹配率不足 |
| 严重度 | 🟡 P2 |
| 当前状态 | 🟡 缓解中 |
| 发现来源 | Batch-1至Batch-3实际执行数据 |
| 影响范围 | 112项API搜索映射条目 |

### 4.2 问题描述

```
API搜索匹配率问题分析:

  根本原因:
    1. zhiji search API返回结果与目标指标不相关
    2. 所有返回结果的match_score=0 (0/200分)
    3. 返回的匹配名称与搜索目标无关联性
    4. 例如: 搜索"铜精矿 TC 加工费"→匹配"铜精矿：长单TC价（年）"(不同口径)
    5. 例如: 搜索"电解铜 社会库存"→匹配"美国铜发展协会：精炼铜：库存（年）"(非国内数据)
    6. 例如: 搜索"铜杆 开工率"→匹配"铝杆：开工率：安徽（月）"(完全无关品种)

  影响分析:
    - Batch-1: 8/8 API搜索返回LOW_SCORE (0%)
    - Batch-2: 22/22 API搜索返回LOW_SCORE (0%)
    - Batch-3: 14/14 API搜索返回LOW_SCORE (0%)
    - 合计: 44/44 API搜索条目全部LOW_SCORE
    - 实际有效匹配率: 0/44 = 0%

  根因推测:
    1. 搜索关键词与zhiji数据库中的命名不一致
    2. zhiji API返回结果按相关性排序但match_score计算异常
    3. 需要调整搜索策略: 增加中英文双关键词、模糊搜索、批量搜索
```

### 4.3 缓解措施

| # | 措施 | 状态 | 说明 |
|---|------|------|------|
| 1 | 优化搜索关键词 | ⏳ 待执行 | 增加中英文双关键词、行业术语变体 |
| 2 | 批量搜索策略 | ⏳ 待执行 | 按品种批量匹配, 而非逐条搜索 |
| 3 | 计算推导覆盖 | 🟡 部分执行 | 47项计算推导项可绕过API搜索 |
| 4 | 人工确认通道 | ⏳ 待执行 | 低分项标记PENDING_MANUAL, 人工确认 |
| 5 | 搜索阈值降低 | ⏳ 待执行 | 降低match_score阈值从6到3, 扩大候选集 |

### 4.4 影响评估
