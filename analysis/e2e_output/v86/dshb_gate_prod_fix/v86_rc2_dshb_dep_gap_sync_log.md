|---|---------|---------|--------|--------|------|

## 2. GAP详细跟踪记录

### 2.1 DEP-GAP-001: DEP登记ID缺失 (P1)

| 字段 | 值 |
|------|-----|
| **描述** | 部分DEP指标在数据平台侧无唯一登记ID，导致无法通过ID精确查询 |
| **影响** | 无法建立DEP指标的唯一标识映射，影响桥接表准确性 |
| **责任方** | 数据平台团队 |
| **协同方** | DSHB |
| **当前状态** | 🔴 待补齐 — 数据平台确认中 |
| **预计完成** | 2026-10-22 (下一周) |
| **跟踪记录** | 2026-10-15: 首次提出, 数据平台确认排期 |

### 2.2 DEP-GAP-002: DEP登记时间缺失 (P2)

| 字段 | 值 |
|------|-----|
| **描述** | DEP指标无首次登记时间戳，无法确定数据起算点 |
| **影响** | 影响时序分析的起始日期判定 |
| **责任方** | 数据平台团队 |
| **协同方** | DSHB |
| **当前状态** | 🔴 待补齐 — 低优先级排期中 |
| **预计完成** | 2026-10-29 |
| **跟踪记录** | 2026-10-15: 首次提出 |

### 2.3 DEP-GAP-003: 变更日志缺失 (P1)

| 字段 | 值 |
|------|-----|
| **描述** | DEP指标的历史变更（ID映射变更、数据源切换等）未记录 |
| **影响** | 审计链路断裂，无法追溯DEP指标变更历史 |
| **责任方** | 数据平台团队 |
| **协同方** | DSHB, HERMES |
| **当前状态** | 🔴 待补齐 — 数据平台正在开发变更日志功能 |
| **预计完成** | 2026-10-22 |
| **跟踪记录** | 2026-10-15: 首次提出, 数据平台确认开发计划 |

### 2.4 DEP-GAP-004: 最大暂停时长未定义 (P2)

| 字段 | 值 |
|------|-----|
| **描述** | DEP指标的最大可暂停时间无明确约束 |
| **影响** | DEP阻塞无限期持续，影响Gate准入评估 |
| **责任方** | DSHB + 数据平台 (协商中) |
| **协同方** | HERMES |
| **当前状态** | 🟡 协商中 — 双方对齐暂停时长策略 |
| **预计完成** | 2026-10-22 |
| **跟踪记录** | 2026-10-15: 提出, 待双方对齐策略 |
| **DSHB建议** | 建议最大暂停时长不超过90天, 超时自动升级为P0风险 |

### 2.5 DEP-GAP-005: 独立调用链证据缺失 (P1)

| 字段 | 值 |
|------|-----|
| **描述** | DEP指标的API调用链未独立记录，与DSHB内部指标混在一起 |
| **影响** | 无法独立验证DEP指标的取数能力，审计链路不完整 |
| **责任方** | 数据平台团队 |
| **协同方** | DSHB |
| **当前状态** | 🔴 待补齐 — 数据平台需建立独立调用日志 |
| **预计完成** | 2026-10-22 |
| **跟踪记录** | 2026-10-15: 首次提出, 数据平台确认需要独立日志系统 |

### 2.6 DEP-GAP-006: 回滚时间窗口未定义 (P2)

| 字段 | 值 |
|------|-----|
| **描述** | DEP指标异常时无回滚SOP时间约束 |
| **影响** | DEP异常回滚无时间窗口约束，可能导致数据不一致 |
| **责任方** | DSHB |
| **协同方** | 数据平台, HERMES |
| **当前状态** | 🟡 协商中 — DSHB起草回滚SOP草案 |
| **预计完成** | 2026-10-29 |
| **跟踪记录** | 2026-10-15: 首次提出, DSHB正在起草回滚SOP |
| **DSHB建议** | 建议回滚时间窗口: 异常发现后24小时内完成回滚决策 |

- **Internal P0/P1**: DEP_BLOCK不计入内部P0/P1缺陷统计
- **Gate约束**: DEP_BLOCK虽不计入内部缺陷，但约束Gate准入 (data_fetchable=0% → NOT_READY)

## 4. DEP周巡检机制

### 4.1 巡检频率

| 频率 | 内容 | 负责人 |
|------|------|--------|
| 每日 | DEP探测 (j25_tc/i1/i3) | dep_ready_trigger_v2.py |
| 每周 | GAP进度跟踪 + 风险台账更新 | DSHB |
| 每两周 | DSHE联合抽样 + 桥接快照同步 | DSHB + DSHE |
| 每月 | HERMES预审 + Gate状态评估 | HERMES |

### 4.2 巡检输出物

| 输出物 | 路径 | 频率 |
|--------|------|------|
| DEP探测事件 | dep_ready_trigger_events.json | 每次探测 |
| GAP同步日志 | v86_rc2_dshb_dep_gap_sync_log.md | 每周 |
| 风险台账 | v86_rc2_dshb_risk_re_evaluate_v4.md | 持续更新 |
| Gate预检查报告 | v86_rc2_dshb_gate_auto_check_report.md | 每次复测 |

### 4.3 巡检SOP

```
1. 每日: dep_ready_trigger_v2.py --mode once
   → 探测3个短ID, 检测DEP就绪状态
   → 就绪则自动触发全量复测

2. 每周: 更新本GAP同步日志
   → 检查6项GAP进度
   → 更新风险台账DEP_BLOCK条目
   → 记录跨团队协同记录

3. 每两周: DSHE联合抽样
   → 30%抽样验证桥接准确性
   → 更新桥接快照
   → 同步Gate预审包

4. 每月: HERMES预审
   → G01~G10全项检查
   → Gate状态评估
   → 审计规则更新
```
