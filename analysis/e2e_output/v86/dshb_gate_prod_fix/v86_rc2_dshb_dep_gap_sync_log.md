## 4. DEP周巡检机制

### 4.1 巡检频率

| 频率 | 内容 | 负责人 |
|------|------|--------|
| 每日 | DEP探测 (j25_tc/i1/i3) | dep_ready_trigger_v2.py |
| 每周 | GAP进度跟踪 + 风险台账更新 | DSHB |
| 每两周 | DSHE联合抽样 + 桥接快照同步 | DSHB + DSHE |
| 每月 | HERMES预审 + Gate状态评估 | HERMES |

### 4.2 巡检输出物

| 输出物 | 路径 | 频率 |
|--------|------|------|
| DEP探测事件 | dep_ready_trigger_events.json | 每次探测 |
| GAP同步日志 | v86_rc2_dshb_dep_gap_sync_log.md | 每周 |
| 风险台账 | v86_rc2_dshb_risk_re_evaluate_v4.md | 持续更新 |
| Gate预检查报告 | v86_rc2_dshb_gate_auto_check_report.md | 每次复测 |

### 4.3 巡检SOP

```
1. 每日: dep_ready_trigger_v2.py --mode once
   → 探测3个短ID, 检测DEP就绪状态
   → 就绪则自动触发全量复测

2. 每周: 更新本GAP同步日志
   → 检查6项GAP进度
   → 更新风险台账DEP_BLOCK条目
   → 记录跨团队协同记录

3. 每两周: DSHE联合抽样
   → 30%抽样验证桥接准确性
   → 更新桥接快照
   → 同步Gate预审包

4. 每月: HERMES预审
   → G01~G10全项检查
   → Gate状态评估
   → 审计规则更新
```
