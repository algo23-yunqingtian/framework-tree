## §1 概述

### 1.1 背景

Phase20 StageE 50% 灰度流量 72h 长程观测验证了回滚 SOP V2.9 的有效性：2 次回滚演练全部通过 (12.5min SLA, 6/6 验证项 PASS)。

Phase21 StageF 75% 灰度放量需要新增 **75%→50% 降级链路**，与 50%→0% 全量回滚链路并存。75% 回滚的特殊性在于：

- **部分降级**：75%→50% 仅削减 25% 流量 (非全量回滚)
- **用户粘性**：75% 灰度用户中 25% 需迁移至稳定通道
- **新 SLA 路径**：1 步直接 (≤15min) + 2 步渐进 (≤20min)

## §2 SOP V2.9→V2.0 升级说明

### 2.1 变更概要

| 维度 | V2.9 (Phase19/20) | V2.0 (Phase21) | 变更说明 |
|------|-------------------|----------------|----------|
| 支持路径 | 50%→0% | 75%→50%, 75%→0% | 新增 75% 降级链路 |
| 降级模式 | 全量回滚 | 部分降级 + 全量回滚 | 双模式支持 |

| 用户迁移 | — | 25% 流量重新路由 | 新增迁移逻辑 |
| 索引保护 | — | L0-L3 四层联动回滚 | 新增联动机制 |

### 2.2 新增功能

| # | 功能 | 说明 |
|---|------|------|
| 1 | 75%→50% 部分降级 | 25% 流量迁移，保留 50% 灰度 |
| 2 | 75%→60%→50% 渐进降级 | 15% + 10% 两步降级 |
| 3 | 回滚中途取消 | 60% 位置取消，保持当前状态 |
| 4 | 混沌中回滚 | L2 注入期间触发回滚 |
| 5 | 索引保护联动 | 索引膨胀触发自动降级 |

## §3 L1-L4 四层降级方案 (75%更新)

### 3.1 L1-L4 触发条件

| 层级 | 触发条件 | 动作 | 流量变化 | 执行方式 |
|------|---------|------|---------|---------|
| **L1** | CB-4 >78ms (PRE) | 预警通知 | 75% (不变) | 自动 |
| **L1** | CB-4 >80ms (WARN) | 15% 流量削减 | 75%→60% | 自动 |
| **L2** | CB-4 >85ms (CRITICAL) | 10% 流量削减 | 60%→50% | 自动 |
| **L3** | CB-4 FUSE / DRIFT WARN | 25% 流量削减 | 50%→25% | 半自动 (人工确认) |
| **L4** | P0 事件 / 数据丢失 | 全量回滚 | 25%→0% | 手动 |

### 3.2 L1-L4 与索引保护联动

| 索引膨胀率 | 索引保护层 | L1-L4 联动动作 |
|-----------|-----------|---------------|
| ≥7.50% | L0 MONITOR | 增强监控，1min 采样 |
| ≥7.75% | L1 PREVENT | 压缩 1x/hour，配合 L1 流量削减 |
| ≥7.90% | L2 MITIGATE | 批量限流 2000/s，配合 L2 流量削减 |
| ≥7.95% | L3 PROTECT | 自动流量削减 75%→60%，触发 L3 |
| ≥8.00% | L3+ | 自动流量削减 75%→50%，触发 L2+L3 |

### 3.3 降级方案流程图

```
触发条件评估
  ├── CB-4 >78ms → L1 PRE → 预警通知 (不变流量)
  ├── CB-4 >80ms → L1 WARN → 75%→60% (自动)
  │     ├── 60min 内恢复 → 维持 60%, 2h 后评估恢复 75%
  │     └── 60min 内未恢复 → L2 触发
  ├── CB-4 >85ms → L2 → 60%→50% (自动)
  │     ├── 60min 内恢复 → 维持 50%, 2h 后评估恢复 60%
  │     └── 60min 内未恢复 → L3 触发
  ├── CB-4 FUSE / DRIFT → L3 → 50%→25% (半自动)
  │     ├── 人工评估 → 恢复 50% 或继续 L4
  │     └── 评估失败 → L4 触发
  └── P0 / 数据丢失 → L4 → 25%→0% (手动)
        └── 全量回滚完成 → 启动事后分析
```
