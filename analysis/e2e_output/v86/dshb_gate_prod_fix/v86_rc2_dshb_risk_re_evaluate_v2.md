## 2. 全量复测结果摘要

### 2.1 双维度统计

| 指标 | V1推断值 | V2实测值 | 变化 |
|------|---------|---------|------|
| 元数据映射完成率 | 100% (178/178) | **73.6% (131/178)** | -26.4% |
| 真实可取数桥接率 | 0% (0/178) | **0% (0/178)** | 不变 |
| 外部依赖阻塞率 | 95.5% (170/178) | **100% (178/178)** | +4.5% |
| API调用总数 | 11次 | **131次** | +120 |

### 2.2 关键实测发现

| 发现 | 数量 | 影响 | 对应风险 |
|------|------|------|---------|
| 伪造短ID全部HTTP 500 | 123 | 123项无法取数 | R-S01, R-RETEST-01 |
| j25_tc HTTP 500 | 1 | 1项无法取数 | R-S01 |
| i1-i7 permission_state=-4 | 7 | 7项无法取数 | R-P03, R-DEP-03 |
| DERIVED无ID | 47 | 47项无元数据 | R-RETEST-02 |
| 长ID数据错配 | 8 | 8项数据语义错误 | R-AUDIT-07 |
| 长ID取数可用 | 3 | 数据存在但错配 | R-AUDIT-07 |

### 2.3 根因确认

```
根因1 (124项): zhiji API服务端不支持short_id前缀解析
  → j25_tc + 123项s_xxx 全部返回HTTP 500 "无法识别指标来源(id前缀)"
  → 影响: R-S01, R-RETEST-01, DEP-01

根因2 (7项): i1-i7短ID返回permission_state=-4
  → HTTP 200但0数据点, 权限/绑定问题
  → 影响: R-P03, DEP-03

根因3 (8项): 长ID取数可用但数据完全错配
  → ID02226332返回LME锌库存(预期沪铅收盘价)
  → 影响: R-AUDIT-07, DEP-02

根因4 (47项): DERIVED计算推导无API映射
  → 元数据不完整(无short_id/long_id)
  → 影响: R-RETEST-02
```
