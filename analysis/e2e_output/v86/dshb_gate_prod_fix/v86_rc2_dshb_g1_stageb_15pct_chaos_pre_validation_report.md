## 1. 概述

### 1.1 背景

Phase12 StageA 5%灰度72h观测完成了6场景轻量混沌注入验证(6/6 PASS)。本阶段(Phase13)在15%灰度流量下执行混沌预验证，目的：

1. 验证DRIFT-001~008规则在15%流量下触发逻辑
2. 验证熔断/降级在15%流量下正常工作
3. 验证优化后CB-4/DRIFT-002在15%流量下可控
4. 为StageB 15%灰度正式放量提供混沌验证支撑

### 1.2 注入场景设计
