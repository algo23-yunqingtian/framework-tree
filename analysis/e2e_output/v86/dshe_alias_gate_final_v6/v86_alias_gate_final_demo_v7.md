| 健康状态 | `v86_system_health` (联合管线) | `alias_engine_healthy` (别名引擎) | 范围不同 | 面板标注范围 |
| 运行时间 | `v86_system_uptime_seconds` (联合) | `alias_engine_start_time` (别名) | 范围不同 | 面板标注范围 |
| 吞吐 | `v86_throughput_evaluate_rate_per_sec` (联合) | `alias_resolve_per_second` (别名) | 范围不同 | 面板标注范围 |
| 延迟 | `v86_latency_evaluate_p95_ms` (E2E) | `alias_resolve_duration_ms` (别名) | E2E vs 单进程 | 面板标注范围 |
| 裁决 | `v86_throughput_evaluate_*_total` (联合) | `alias_verdict_total{verdict}` (别名) | 联合 vs 别名 | 引擎优先原则 |
| 错误率 | `v86_error_rate_per_sec` (联合) | `alias_error_rate` (别名) | 范围不同 | 引擎优先原则 |
| 队列 | `v86_queue_depth` (联合) | 无别名专属指标 | DSHB 独有 | 仅 DSHB 展示 |

| 规则命中 | `v86_rule_hit_total` (规则) | 无别名专属指标 | DSHB 独有 | 仅 DSHB 展示 |
| 缓存 | `v86_cache_hit_rate` (联合) | `alias_cache_hit_rate` (别名) | 语义一致 | 引擎优先原则 |

A: DSHB 全局指标主清单定义 90 个 Prometheus 指标, 分 8 类:
- System Health (6): 健康/就绪/运行时间/版本/引擎加载/规则数
- Throughput (12): 评估/BLOCKED/PASSED/DATA_MISSING/错误/速率/批量
- Latency (14): P50/P95/P99/max/avg + 直方图 + 别名延迟 + 批量延迟
- Rule Hits (24): 按规则命中/FP/延迟/状态 + 18 规则逐指标
- Errors (18): 18 种错误码 + 错误率 + 最后时间戳
- Queue (6): 深度/最大深度/等待时间/拒绝/接受
- Data Quality (5): DATA_MISSING/验证失败/NFKC/字段长度
- Memory (5): 引擎内存/总内存/GC 周期/GC 时间

**Q54: 冗余指标如何清理?**

A: 8 项冗余按引擎优先原则清理:
1. `alias_engine_healthy` ↔ `v86_system_health` → 保留 DSHE (别名引擎健康)
2. `alias_engine_start_time` ↔ `v86_system_uptime_seconds` → 保留 DSHE
3. `alias_error_rate` ↔ `v86_error_rate_per_sec` → 保留 DSHE
4. `alias_resolve_per_second` ↔ `v86_throughput_evaluate_rate_per_sec` → 保留 DSHE
5. `alias_resolve_duration_ms` ↔ `v86_latency_evaluate_total_seconds` → 保留 DSHE
6-8. `alias_verdict_total{PASS/REVIEW/BLOCK}` ↔ `v86_throughput_evaluate_*_total` → 保留 DSHE

清理结果: 0 项冗余, 8 项 DSHE 独有指标保留。

**Q55: 缺失指标如何降级展示?**

A: 10 项缺失指标降级展示:
- P0 (2): `alias_engine_load_method` (exec() ⚠️ + 补偿), `alias_engine_hash_mismatch` (SHA-256 ✅)
- P1 (6): `alias_manual_review_pending` (34 待审阅), `alias_degrade_history` (近5次无异常), `alias_alert_status` (0 P0/0 P1/3 P2), `alias_alert_history` (24h 无告警), 多进程对比 (单进程 2144/s), ALIAS_IMPACT diff (2 条)
- P2 (2): `alias_confidence_distribution` (T+7d), 联合管线裁决变化 (T+5d)

降级展示: 面板 Text/Note 注释, 包含当前快照值 + 实现时限。

**Q56: 别名引擎与联合管线指标如何区分?**

A: 6 项关键区分:
1. 健康: `alias_engine_healthy` (别名) vs `v86_system_health` (联合) → 面板标注 "别名引擎健康"
2. 吞吐: `alias_resolve_per_second` (别名单进程) vs `v86_throughput_evaluate_rate_per_sec` (联合) → 面板标注 "单进程"
3. 延迟: `alias_resolve_duration_ms` (别名) vs `v86_latency_evaluate_p95_ms` (E2E) → 面板标注 "单进程 vs E2E"
4. 裁决: `alias_verdict_total` (别名) vs `v86_throughput_evaluate_*_total` (联合) → 引擎优先, 不混用
5. 错误率: `alias_error_rate` (别名) vs `v86_error_rate_per_sec` (联合) → 引擎优先
6. 队列/内存/规则: DSHB 独有, 仅联合面板展示

**Q57: DSHB 指标不可用原因?**

A: 10 项不可用:
- 批量接口未实现 (6): `v86_throughput_batch_*`, `v86_latency_batch_*`, `v86_throughput_evaluate_batch_size_avg`
- GC 运维专用 (2): `v86_memory_gc_cycles_total`, `v86_memory_gc_time_total_ms`
- 内部预处理 (1): `v86_data_nfkc_applied_total`
- 别名延迟 histogram 未实现 (1): `v86_latency_alias_resolve_total_seconds`

**Q58: 降级展示与实时展示的区别?**

A: 
| 维度 | 实时展示 | 降级展示 |
|------|---------|---------|
| 数据源 | Prometheus | 文档快照 |
| 更新频率 | 实时 (15s) | 手动更新 |
| 面板元素 | Stat/TS/Table | Text/Note 注释 |
| 告警支持 | ✅ | ❌ |
| 历史趋势 | ✅ | ❌ |
| 数据准确性 | 100% | 当前快照 |

**Q59: 口径差异风险如何缓解?**

A: 6 项口径差异, 4 种缓解措施:
1. 范围标注: 面板注释标注 "别名引擎" vs "联合管线" vs "E2E"
2. 引擎优先: 冗余指标保留 DSHE 命名, 不引入 DSHB 替代
3. 文档标注: V85 vs V86 差异在指标口径文档中说明
4. 注释增强: 每个差异指标在面板注释中说明口径

**Q60: V7 与 V6 的核心区别?**
