### 1.4 新增异常场景

#### 场景 7: P0 缺口未闭环 (新增)

```
场景描述: SHA-256 校验失败, 别名库哈希不匹配
触发条件: alias_engine_hash_mismatch == 1
告警级别: P0
处置流程:
  1. 立即停止别名引擎 (自动 halt)
  2. 执行 Strategy B 回退 (V85 alias, RTO 30s)
  3. 检查别名库完整性 (MD5 比对)
  4. 如哈希不一致, 检查数据源安全
  5. 修复后重新部署, 重新验证 SHA-256
回退方案: Strategy B (V85 alias, RTO 30s)
验收: SHA-256 校验通过, hash_mismatch == 0
```

#### 场景 8: 上线后巡检异常 (新增)

```
场景描述: 上线后 72h 巡检发现 P1 告警持续活跃
触发条件: P1 告警活跃 >2 个, 持续 >2h
告警级别: P1 → 升级 P0 (如 >4h)
处置流程:
  1. 识别告警类型 (吞吐下降 / 队列堆积 / ALIAS_IMPACT)
  2. 检查根因 (GIL 限制 / 规则回归 / 歧义新增)
  3. 如 GIL: 考虑 4-worker 多进程部署
  4. 如回归: 执行 Strategy B 回退
  5. 生成 72h 总结报告, 标注异常
升级条件: P1 >4h 未解决 → 升级 P0 → 考虑回退
验收: P1 告警清零, 72h 总结报告完成
```
