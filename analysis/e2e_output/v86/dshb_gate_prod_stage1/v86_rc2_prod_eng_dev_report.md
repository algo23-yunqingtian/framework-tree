#### 2.4.2 冷却窗口触发逻辑

```python
class AlertCooldownManager:
    def __init__(self):
        self.cooldown_registry = {}
        self.active_alerts = {}
    
    def should_alert(self, rule_id, severity):
        """判断是否应发送告警 (冷却窗口逻辑)"""
        now = time.time()
        last_alert_time = self.active_alerts.get(rule_id)
        
        if last_alert_time is None:
            return True
        
        cooldown = DUAL_THRESHOLD_REGISTRY[severity]['cooldown']
        elapsed = now - last_alert_time
        
        if elapsed < cooldown:
            # 仍在冷却窗口内，抑制告警
            self.suppressed_count[rule_id] += 1
            return False
        else:
            # 冷却窗口已过，允许告警
            self.active_alerts[rule_id] = now
            return True
```

#### 3.4.1 核心比对逻辑

```python
class CaliberComparisonEngine:
    def __init__(self, config):
        self.rules = config['comparison_rules']
        self.metrics = config['metric_definitions']
        self.thresholds = config['thresholds']
    
    def run_comparison(self):
        """执行全量指标口径交叉比对"""
        results = {}
        start_time = time.time()
        
        for metric_id, metric_def in self.metrics.items():
            # 1. 加载 DSHB 引擎口径
            dshb_caliber = self.load_dshb_caliber(metric_id)
            
            # 2. 加载 DSHE 展示层口径
            dshe_caliber = self.load_dshe_caliber(metric_id)
            
            # 3. 执行口径比对
            diff = self.compare_caliber(dshb_caliber, dshe_caliber)
            
            # 4. 标记差异
            severity = self.classify_diff(diff)
            results[metric_id] = {
                'dshb_caliber': dshb_caliber,
                'dshe_caliber': dshe_caliber,
                'diff': diff,
                'severity': severity,
                'mc_mapping': self.get_mc_mapping(metric_id)
            }
        
        elapsed = time.time() - start_time
        
        # 5. 生成比对报告
        report = self.generate_report(results, elapsed)
        
        # 6. 差异告警
        if any(r['severity'] == 'BLOCK' for r in results.values()):
            self.send_alert(report)
        
        return report
```

#### 5.4.2 接口详细规格

**API-01: 图表数据查询**
```
GET /api/chart/data?chart_id={id}&date_range={start}~{end}&metrics={ids}

Request:
  - chart_id: string (必填, 图表ID)
  - date_range: string (必填, 时间范围)
  - metrics: string[] (可选, 指标ID列表)
  - batch: number (可选, 批次数, 默认全部)
  - page: number (可选, 页码, 默认1)

Response:
  - status: string (success/error)
  - data: object {
      metrics: array,
      time_range: {start, end},
      chart_config: object,
      pagination: {total, page, batch}
    }
  - meta: {request_id, timestamp, duration_ms}

Error Codes:
  - 400: INVALID_PARAMETER (参数无效)
  - 404: CHART_NOT_FOUND (图表不存在)
  - 500: INTERNAL_ERROR (内部错误)
  - 503: DATA_SOURCE_UNAVAILABLE (数据源不可用)
```

**API-04: 别名解析**
```
GET /api/alias/resolve?alias={name}&canonical={id}

Request:
  - alias: string (必填, 别名名称)
  - canonical: string (可选, 规范ID)

Response:
  - status: string (success/not_found)
  - data: object {
      canonical_id: string,
      canonical_name: string,
      aliases: string[],
      mapping_confidence: number (0~1)
    }
  - meta: {request_id, timestamp, duration_ms}
```

**API-07: 健康检查**
```
GET /api/health

Response:
  - status: string (healthy/degraded/unhealthy)
  - checks: object {
      rule_engine: {status: 'up', latency_ms: 12},
      alias_engine: {status: 'up', latency_ms: 8},
      data_source: {status: 'up', latency_ms: 45},
      monitor: {status: 'up', latency_ms: 15}
    }
  - version: 'V86-RC2'
  - uptime: '72h'
```
