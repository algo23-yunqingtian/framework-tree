### 5.4 关联准确率详细验证

#### 5.4.1 准确率计算方法

```
准确率 = TP / (TP + FP)
召回率 = TP / (TP + FN)
F1 = 2 × (Precision × Recall) / (Precision + Recall)

其中:
  TP = 正确关联的告警对 (真阳性)
  FP = 错误关联的告警对 (假阳性)
  FN = 遗漏的关联告警对 (假阴性)
```
