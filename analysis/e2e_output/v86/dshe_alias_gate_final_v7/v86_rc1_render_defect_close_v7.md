#### 3.1.1 问题描述

Panel 3 (歧义率分析) 使用 ECharts 饼图展示 9 种大宗商品品种 (NI/LI/SI/SN/ZN/AL/PB/CU/AO) 的歧义率分布。当前图例使用默认垂直布局 (`legend.orient='vertical'`)，导致在视口宽度低于 1024px 时，品种名称发生重叠或截断。

**受影响品种列表 (9 种):**

| 序号 | 品种代码 | 品种名称 | 缩写 |
|:----:|:--------:|:---------|:----:|
| 1 | NI | Nickel | 镍 |
| 2 | LI | Lithium | 锂 |
| 3 | SI | Silicon | 硅 |
| 4 | SN | Tin | 锡 |
| 5 | ZN | Zinc | 锌 |
| 6 | AL | Aluminum | 铝 |
| 7 | PB | Lead | 铅 |
| 8 | CU | Copper | 铜 |
| 9 | AO | Other/Aggregate | 其他 |

#### 3.1.2 修复前状态 (BEFORE)

```javascript
// ❌ 修复前配置 — V7 基线
option = {
  legend: {
    orient: 'vertical',        // 垂直布局 → 导致拥挤

    data: ['NI', 'LI', 'SI', 'SN', 'ZN', 'AL', 'PB', 'CU', 'AO']
  },

    type: 'pie',
```

**修复前视口表现:**

| 视口宽度 | 图例布局 | 品种名称状态 | 重叠/截断 | 可接受度 |
|:--------:|:--------:|:------------:|:---------:|:--------:|
| 1920px | 垂直(右侧) | ✅ 完整显示 | ❌ 无 | ✅ 可接受 |

| 480px  | 垂直(右侧) | ❌ 完全不可读 | ❌ 严重重叠 | ❌ 不可接受 |

#### 3.1.3 修复方案 (FIX)

采用**图例水平布局 + 饼图半径缩减**双重修复策略：

```javascript
// ✅ 修复后配置 — V7-RC1
option = {
  legend: {
    orient: 'horizontal',      // ✅ 改为水平布局
    left: 'center',            // ✅ 居中对齐
    top: 0,                    // ✅ 顶部定位
    itemGap: 8,                // ✅ 适当减小间距
    itemWidth: 12,             // ✅ 缩小图例色块
    itemHeight: 12,            // ✅ 缩小图例色块
    textStyle: {
      fontSize: 11,            // ✅ 微调字体大小
      color: '#333'
    },
    data: ['NI', 'LI', 'SI', 'SN', 'ZN', 'AL', 'PB', 'CU', 'AO']
  },
  series: [{
    type: 'pie',
    radius: ['35%', '55%'],    // ✅ 缩小半径 (从 ['40%','70%'] 降至 ['35%','55%'])
    center: ['50%', '55%'],    // ✅ 居中偏下，为图例留出空间
    avoidLabelOverlap: true,   // ✅ 避免标签重叠
    data: [/* 9 种品种数据 */]
  }]
};
```

**修复要点总结:**

| 修复项 | 修复前 | 修复后 | 变更原因 |
|:------:|:------:|:------:|:---------|
| legend.orient | `'vertical'` | `'horizontal'` | 水平布局解决垂直方向空间不足 |
| legend.left | `'right'` | `'center'` | 居中对齐，充分利用水平空间 |
| legend.top | (未设置) | `0` | 顶部固定，避免与饼图重叠 |
| pie radius | `['40%', '70%']` | `['35%', '55%']` | 缩小半径，为图例腾出空间 |
| pie center | `['45%', '50%']` | `['50%', '55%']` | 居中偏下，平衡整体布局 |
| avoidLabelOverlap | (未设置) | `true` | 防止数据标签相互重叠 |

#### 3.2.1 问题描述

Panel 4 (性能趋势) 展示队列深度 (Queue Depth) 的时序变化。Y 轴标签 (2000/1500/1000/500/0) 在视口宽度低于 768px 时被截断，导致数据可读性受损。根本原因是 Grafana 面板宽度 (`gridPos.w`) 设置不当，以及轴标签放置位置 (`axisPlacement`) 未做响应式优化。

#### 3.2.2 修复前状态 (BEFORE)

```json
// ❌ 修复前配置 — V7 基线 (Grafana Panel JSON 片段)
{
  "title": "性能趋势 - 队列深度",
  "type": "timeseries",
  "gridPos": {
    "h": 8,
    "w": 12,                    // ❌ 默认宽度 12/24
    "x": 12,
    "y": 8
  },
  "fieldConfig": {
    "defaults": {
      "custom": {
        "axisPlacement": "left",  // ❌ 轴标签左侧 → 小屏幕截断
        "show": "always"
      },
      "unit": "short",
      "min": null,               // ❌ 未设置最小值
      "max": null                // ❌ 未设置最大值
    }
  },
  "options": {
    "legend": { "show": true, "placement": "bottom" },
    "tooltip": { "mode": "single" }
  }
}
```

**修复前视口表现:**

| 视口宽度 | Y轴标签显示 | 截断情况 | 可接受度 |
|:--------:|:-----------:|:--------:|:--------:|
| 1920px | 2000 / 1500 / 1000 / 500 / 0 | ✅ 无截断 | ✅ 可接受 |
| 1024px | 2000 / 1500 / 1000 / 500 / 0 | ✅ 无截断 | ✅ 可接受 |
| 768px  | 200... / 150... / 100... / 500 / 0 | ⚠️ 部分截断 | ⚠️ 边界 |
| 480px  | 2... / 1... / 1... / 5... / 0 | ❌ 严重截断 | ❌ 不可接受 |

#### 3.2.3 修复方案 (FIX)

采用**轴标签底部对齐 + 面板宽度调整 + Y轴范围固定**三重修复策略：

```json
// ✅ 修复后配置 — V7-RC1 (Grafana Panel JSON 片段)
{
  "title": "性能趋势 - 队列深度",
  "type": "timeseries",
  "gridPos": {
    "h": 8,
    "w": 10,                    // ✅ 缩小至 10/24，减少面板宽度
    "x": 14,
    "y": 8
  },
  "fieldConfig": {
    "defaults": {
      "custom": {
        "axisPlacement": "bottom",  // ✅ 改为底部放置
        "show": "always"
      },
      "unit": "short",
      "min": 0,                    // ✅ 固定最小值 0
      "max": 2000                  // ✅ 固定最大值 2000
    }
  },
  "options": {
    "legend": { "show": true, "placement": "bottom" },
    "tooltip": { "mode": "single" },
    "axisBorderShow": false,       // ✅ 隐藏轴边框
    "axisLineColor": "#e0e0e0",    // ✅ 轻量轴颜色
    "axisLabelFontSize": 10        // ✅ 微调轴标签字体
  }
}
```

**修复要点总结:**

| 修复项 | 修复前 | 修复后 | 变更原因 |
|:------:|:------:|:------:|:---------|
| axisPlacement | `'left'` | `'bottom'` | 底部放置，避免左侧空间不足导致截断 |
| gridPos.w | `12` | `10` | 缩小面板宽度，减少水平方向标签挤压 |
