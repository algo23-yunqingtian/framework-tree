#### 2.1.4 技术实现要点

| 技术点 | 实现方案 | 关键参数 |
|--------|----------|----------|
| **预连接** | `<link rel="preconnect" href="https://cdn.example.com">` | DNS + TLS 握手并行, 节省 100-200ms |
| **预加载** | `<link rel="preload" as="script" href="...">` | 关键 JS 模块提前 100ms 加载 |
| **按需渲染** | IntersectionObserver + 渲染队列 | 视口外延迟 200ms 后渲染 |
| **虚拟化滚动** | 仅渲染可见区域 + 缓冲 3 行 | DOM 节点 56→<20 |
| **Canvas 分层** | 离屏 Canvas 预渲染 + 合成层 | GPU 争抢减少 60% |
| **进度条** | requestAnimationFrame 节流 + 后端进度回调 | 更新间隔 ≤ 200ms |
