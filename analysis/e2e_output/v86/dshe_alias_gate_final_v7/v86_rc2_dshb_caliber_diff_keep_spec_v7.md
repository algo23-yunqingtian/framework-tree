## 3. 保留差异详细归档 (3项)

### 3.1 MC-02: P1阈值保留差异

| 维度 | 值 |
|------|-----|
| **MC ID** | MC-02 |
| **指标名称** | P1缺陷/事件阈值 |
| **DSHB口径** | P1≤3（允许P1缺陷存在，要求有缓解计划） |
| **DSHE口径** | P1=0（展示层不允许任何P1缺陷） |
| **差异原因** | 展示层对用户体验要求更高，P1缺陷直接影响终端用户；底层允许有缓解计划的P1存在 |
| **约定处理方式** | **保留差异** — 双方各自维护本层阈值，不强制统一 |
| **业务影响** | DSHB底层监控告警按P1≤3触发，DSHE展示层Gate准入门槛按P1=0执行 |
| **风险等级** | 🟡 中 |
| **风险描述** | 若DSHB P1=3而DSHE P1=0，可能导致展示层Gate不通过但底层告警未升级 |
| **缓解措施** | DSHE Gate准入时以DSHE P1=0为准，DSHB P1降级为P2展示 |
| **HERMES校验规则** | `MC-02_CHECK: DSHB_P1_count > 0 AND DSHE_P1_count = 0 → WARNING(展示层降级,底层允许)` |
| **投产处理** | DSHB P1>0时自动降级为P2展示，DSHE以0 P1为硬门槛 |
| **关联Gate** | C2 (错误率) |
| **关联回填字段** | — |
| **关联图表** | — |
| **关联ENG/MON任务** | ENG-01 (误报率优化) |

### 3.2 MC-05: 可用性阈值保留差异

| 维度 | 值 |
|------|-----|
| **MC ID** | MC-05 |
| **指标名称** | 系统可用性阈值 |
| **DSHB口径** | 99.9%（允许0.1%不可用时间） |
| **DSHE口径** | 100%（展示层要求完全可用） |
| **差异原因** | 底层系统允许短暂不可用（如维护窗口），展示层要求100%可用保证用户体验 |
| **约定处理方式** | **保留差异** — DSHB 99.9% SLA，DSHE 100% 展示要求 |
| **业务影响** | DSHB可用性<99.9%时触发P1告警；DSHE可用性<100%时触发P1降级 |
| **风险等级** | 🟡 中 |
| **风险描述** | DSHB 99.9%可用但DSHE 100%要求可能导致降级频率高于底层告警频率 |
| **缓解措施** | DSHE降级时自动重试3次，3次失败后标记为DSHB侧问题 |
| **HERMES校验规则** | `MC-05_CHECK: DSHB_AVAIL < 99.9% → P1; DSHE_AVAIL < 100% → P1(展示层更严格)` |
| **投产处理** | DSHB以99.9%为SLA基线，DSHE以100%为展示基线，差异部分由重试机制消化 |
| **关联Gate** | C2 (错误率), C3 (稳定性SLA) |
| **关联回填字段** | — |
| **关联图表** | — |
| **关联ENG/MON任务** | MON-01 (覆盖率), MON-02 (降级SOP) |
