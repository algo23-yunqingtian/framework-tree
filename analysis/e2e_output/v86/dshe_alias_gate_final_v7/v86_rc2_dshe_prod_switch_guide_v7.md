## 9. 回滚流程

### 9.1 回滚级别

| 级别 | 名称 | 场景 | 时间 | 复杂度 |
|------|------|------|------|--------|
| L1 | 单图表回滚 | 单个图表降级异常 | <5min | 🟢低 |
| L2 | 批量回滚 | 多图表/多页面异常 | <15min | 🟡中 |
| L3 | 全量回滚 | 系统级故障 | <30min | 🔴高 |

### 9.2 L1 单图表回滚

```
L1 单图表回滚步骤:
┌──────────────────────────────────────────────────────────────┐
│  Step 1: 识别异常图表 (监控告警/人工发现)                        │

│  Step 4: 验证兜底生效 (静态快照/占位图)                          │

│  影响范围: 1个图表                                             │
│  用户影响: 低 (显示降级标记, 不影响其他图表)                      │
```
