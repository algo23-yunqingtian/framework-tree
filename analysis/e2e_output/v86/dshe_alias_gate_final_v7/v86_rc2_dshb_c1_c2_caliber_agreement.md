## 3. C2错误率阈值口径约定

### 3.1 差异根源

| 差异项 | DSHB口径 | DSHE口径 |
|--------|---------|---------|
| P0阈值 | 0 | 0 |
| P1阈值 | ≤3（有缓解计划） | 0（无P1缺陷） |
| P1定义 | 引擎层宽松标准，容忍少量P1 | 展示层严格标准，零容忍P1 |

**根因**: DSHB作为引擎层，P1阈值≤3是考虑误报率优化过程中的临时容忍阈值。DSHE作为展示层，P1=0是保证页面质量的严格标准。

### 3.2 两套口径定义

#### 口径A：Gate验收口径（DSHE标准）

| 维度 | 值 | 说明 |
|------|-----|------|
| **P0阈值** | 0 | 零容忍P0阻断缺陷 |
| **P1阈值** | 0 | 零容忍P1高风险缺陷 |
| **判定标准** | P0=0 AND P1=0 | 严格标准 |
| **适用场景** | PREP Gate验收判定、UT/IT/SR Gate流程 | — |
| **当前状态** | ✅ 68/68 UT PASS，C1-C5 A+ 10/10 | — |
| **责任方** | DSHE | — |

#### 口径B：投产告警口径（DSHB标准）

| 维度 | 值 | 说明 |
|------|-----|------|
| **P0阈值** | 0 | 零容忍P0阻断缺陷 |
| **P1阈值** | ≤3 | 容忍少量P1缺陷（有缓解计划） |
| **判定标准** | P0=0 AND P1≤3 | 宽松标准 |
| **适用场景** | 投产线上告警、监控大盘告警 | — |
| **当前状态** | 误报率60.7%→目标<30%（ENG-01优化中） | — |
| **责任方** | DSHB | — |

### 3.3 P1定义边界

| 维度 | DSHB P1定义 | DSHE P1定义 |
|------|------------|------------|
| **P1-1** | 告警误报率>30% | 页面P99>3.0s |
| **P1-2** | 监控覆盖率<95% | 图表渲染失败率>5% |
| **P1-3** | API延迟P95>10ms | 首屏加载>2.0s |
| **P1-4** | 别名解析失败率>2% | 降级图表兜底失败 |
| **P1-5** | 规则引擎冷启动>15s | CDN加载>2.2s |
| **P1容忍度** | ≤3项同时存在 | 0项同时存在 |

### 3.4 C2统一收敛路径

```
T+0d:   DSHB P1≤3 (引擎层宽松标准，当前状态)
         DSHE P1=0  (展示层严格标准，当前状态)
         ↓
T+3d:   ENG-01误报率优化完成 (60.7%→<30%)
         ↓
T+7d:   评估DSHB P1阈值是否收紧至0
         ↓
T+14d:  如评估通过，统一为P1=0
         ↓
稳态:   DSHB P1=0 = DSHE P1=0 (双端统一)
```

## 5. Gate评审判定规则

### 5.1 C1 Gate判定伪代码

```
# C1 Gate评审判定
FUNCTION C1_GATE_REVIEW_JUDGEMENT():
    full_match = DSHE_FULL_MATCH  // 29
    degraded = DEGRADED_COUNT     // 7
    total = TOTAL_CHARTS          // 36

    IF full_match + degraded != total:
        RETURN FAIL  // 降级数不匹配
    
    FOR EACH chart IN DEGRADED_CHARTS:
        IF NOT has_fallback_strategy(chart):
            RETURN FAIL  // 降级图表无兜底方案
    
    FOR EACH chart IN DEGRADED_CHARTS:
        IF NOT fallback_verified(chart):
            RETURN FAIL  // 降级图表兜底未验证
    
    RETURN PASS  // C1 PASS
```

### 5.2 C2 Gate判定伪代码

```
# C2 Gate评审判定
FUNCTION C2_GATE_REVIEW_JUDGEMENT():
    p0_count = GET_P0_COUNT()
    p1_count = GET_P1_COUNT()

    IF p0_count > 0:
        RETURN FAIL  // P0阻断
    
    IF p1_count > 0:
        RETURN FAIL  // P1非阻断但Gate不通过
    
    RETURN PASS  // C2 PASS
```

```
# C1 投产告警判定
FUNCTION C1_PRODUCTION_ALERT():
    full_match = DSHB_FULL_MATCH  // 32
    total = TOTAL_CHARTS          // 36
    match_rate = full_match / total * 100  // 88.9%

    IF match_rate < 85:
        ALERT_LEVEL = CRITICAL
        NOTIFY_ON_CALL()
    ELSE IF match_rate < 90:
        ALERT_LEVEL = HIGH
        LOG_WARNING()
    ELSE:
        ALERT_LEVEL = NORMAL
        LOG_INFO()
    
    RETURN ALERT_LEVEL
```
