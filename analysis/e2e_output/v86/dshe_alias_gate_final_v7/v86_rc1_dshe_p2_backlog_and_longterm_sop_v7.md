### 2.2 P2-001: Gate大盘切换后首次加载耗时增加

| 项目 | 详情 |
|------|------|
| **异常编号** | P2-001 |
| **发现来源** | 发布窗口值守 OBS-10 (S10 版本切换 V85→V86-RC1) |
| **发现时间** | T+23min |
| **现象描述** | Gate大盘(6个监控面板)在版本切换后首次加载耗时从正常的2.1s增加至2.8s |
| **观测值** | 2.8s |
| **正常基准** | 2.1s |
| **偏差幅度** | +0.7s (+33%) |
| **复现路径** | 版本切换 V85.0 FROZEN → V86.0-RC1 → 首次访问Gate大盘页面 |
| **出现时机** | 仅版本切换后首次加载, 第二次加载恢复至2.1s |
| **影响页面** | 6个Gate面板 (风险监控/Gate大盘/P1跟踪/别名网关/版本状态/降级体系) |
| **影响用户场景** | 发布窗口执行人员首次查看Gate大盘时感知到轻微延迟 |
| **原因分析** | 版本切换后浏览器端缓存部分失效, Gate大盘触发一次重新计算 |
| **底层引擎问题** | 否 (纯前端缓存行为, 无指标计算或别名引擎异常) |
| **数据准确性** | 无影响 (数据展示正确, 仅加载速度边际变化) |
| **24h稳定性关联** | 无复发 (P2-004为并发场景, 非同一现象) |
| **用户影响** | 无 (2.8s在可接受范围内, 仅首次) |
| **处置建议** | 记录为已知行为, 后续可优化Gate大盘缓存预热策略 |
| **严重度** | P2 (低优) |
| **是否阻塞** | 否 |
