## 1. 执行摘要

本报告对 DSHE 展示层 72 个 Gate 验收用例与 DSHB 底层 36 个冒烟测试用例进行逐条比对评审，识别重复校验项、指标阈值不一致、字段缺失、时序不匹配问题，建立差异台账，提出去重与合并建议。

### 1.1 评审总览

| 维度 | DSHE | DSHB | 合并后 |
|------|------|------|--------|
| 用例总数 | 72 (68 DSHE + 4 COORD) | 36 (10 UT + 12 IT + 8 SR + 6 GA) | 108 → 去重后 101 |
| 直接对应 | — | 4 (IT-003/004/008/009→COORD) | 4 去重 |
| 间接关联 | 24 DSHB 用例 | 32 DSHE 用例 | 间接覆盖 |
| 独立用例 | 48 DSHE 独立 | 16 DSHB 独立 | 64 独立 |
| 差异项 | — | — | 12 项 (5 口径冲突 + 3 字段缺失 + 2 时序 + 2 阈值) |
| 去重后统一 | — | — | 101 用例 (72 DSHE + 29 DSHB 独立) |

### 1.2 关键发现

1. **4 项直接对应已去重**: DSHB IT-003/004/008/009 与 DSHE COORD-001~004 完全对应，DSHE 不再重复测试
2. **5 项指标口径冲突**: P99 vs P95、首屏 vs 冷启动、图表匹配率定义、C5 监控范围、约束数量
3. **3 项字段缺失**: DSHB UT-009 别名映射数 (4643) 与 DSHE GATE-DSHE-028 (351 查询) 口径不同
4. **2 项时序不匹配**: DSHB ENG-03 Schema 交付 (T+7d) vs DSHE #9 API 需求 (T+3d)
5. **2 项阈值差异**: DSHB C5 覆盖率 95% vs DSHE 降级监控 100%；DSHB 冷启动<15s vs DSHE 首屏<2.0s

## 2. 评审方法与范围

### 2.1 评审方法

```
双端用例比对方法:
┌──────────────────────────────────────────────────────────────┐
│  Step 1: 用例分类标记                                        │
│  ├─ DSHE 72 用例按维度分类 (页面/渲染/别名/降级/演示/COORD)  │
│  ├─ DSHB 36 用例按阶段分类 (UT/IT/SR/GA)                    │
│  └─ 标记每用例的测试目标与验证指标                            │
│                                                              │
│  Step 2: 逐条比对映射                                        │
│  ├─ 直接对应: 测试目标完全相同                                │
│  ├─ 间接关联: 测试目标上下游互补                              │
│  ├─ 独立用例: 无对应关系                                      │
│  └─ 冲突项: 指标口径/阈值/范围不一致                          │
│                                                              │
│  Step 3: 差异识别                                            │
│  ├─ 口径冲突: 同一指标不同定义                                │
│  ├─ 阈值不一致: 同一指标不同通过标准                           │
│  ├─ 字段缺失: 一方有另一方无                                  │
│  └─ 时序不匹配: 交付窗口冲突                                  │
│                                                              │
│  Step 4: 去重与合并建议                                      │
│  ├─ 删除重复用例                                              │
│  ├─ 修正口径冲突                                              │
│  ├─ 补充缺失字段                                              │
│  └─ 协调时序差异                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 评审范围

| 范围 | 用例数 | 说明 |
