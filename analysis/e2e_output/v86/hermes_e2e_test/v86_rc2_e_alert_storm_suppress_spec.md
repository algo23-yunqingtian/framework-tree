## 2. 告警风暴问题定义与影响分析

### 2.1 告警风暴定义

告警风暴是指在短时间内大量告警同时触发的现象，通常由单点故障触发多个告警规则、多个故障并发、故障恢复时告警集体恢复等原因导致。

```
告警风暴判定标准:
- 30s窗口内告警数 > 50
- 5min窗口内告警数 > 200
- 告警去重率 < 30%
- 告警处理延迟 > 2s
```

### 2.2 告警风暴影响分析

| 影响维度 | 具体影响 | 量化影响 | 严重程度 |
|----------|----------|----------|----------|
| 排障效率 | 告警刷屏淹没核心信息 | 有效告警占比<10% | P0 |
| 运维疲劳 | 大量重复告警导致告警疲劳 | 告警处理准确率下降50% | P0 |
| 性能影响 | 告警处理链路过载 | 告警处理延迟>2s | P1 |
| 通知风暴 | 大量重复通知 | 通知量膨胀10x | P1 |
| 存储压力 | 告警事件写入压力 | 写入吞吐翻倍 | P2 |
| 决策干扰 | 决策标签被覆盖 | 决策延迟>5s | P0 |

### 2.3 告警风暴场景分类

| 类型 | 描述 | 典型场景 | 告警量级 |
|------|------|----------|----------|
| 单点故障风暴 | 单点故障触发多个告警规则 | DEP HTTP500 → 15规则触发 | 15~30 |
| 级联故障风暴 | 故障级联传播 | DEP→Gate→审计→面板 | 30~60 |
| 并发故障风暴 | 多故障同时发生 | F1+F2+F5并发 | 30~50 |
| 恢复风暴 | 故障恢复时告警集体恢复 | DEP恢复→15规则恢复 | 15~30 |
| 切换风暴 | 数据源切换触发大量告警 | Mock→Real切换 | 20~40 |

## 4. 告警聚合策略

### 4.1 聚合策略设计

| 聚合级别 | 聚合维度 | 聚合窗口 | 聚合键 | 聚合后效果 |
|----------|----------|----------|--------|------------|
| L1 时间聚合 | 同规则+同严重级别 | 60s | rule_id+severity | 同规则告警合并为1组 |
| L2 来源聚合 | 同源+同规则 | 60s | source_id+rule_id | 同源告警合并 |
| L3 规则聚合 | 同根因跨规则 | 120s | root_cause | 跨规则同根告警合并 |
| L4 严重级别聚合 | P0+P1 | 60s | severity_group | P0+P1合并为CRITICAL组 |

### 4.2 时间聚合 (L1)

| 参数 | 默认值 | 可调范围 | 说明 |
|------|--------|----------|------|
| 聚合窗口 | 60s | 10s~300s | 窗口期内同规则告警合并 |
| 聚合键 | rule_id + severity | — | 聚合判断依据 |
| 最大聚合数 | 100 | 10~1000 | 超过后拆分 |
| 告警计数展示 | 是 | — | 聚合组显示告警数量 |
| 告警时间戳 | 保留首条+末条 | — | 最早+最晚触发时间 |

**聚合示例:**


## 5. 告警抑制策略

### 5.1 抑制策略设计

| 抑制ID | 抑制类型 | 抑制条件 | 被抑制告警 | 抑制效果 |
|--------|----------|----------|------------|----------|
| SI-01 | 层级抑制 | P0存在时抑制P1 | P1告警 | P1不单独展示 |
| SI-02 | 标签抑制 | 标签含`_suppressed` | 标记告警 | 告警不展示 |
| SI-03 | 频率抑制 | 同规则>5次/min | 重复告警 | 仅展示计数 |
| SI-04 | 阈值抑制 | 阈值边界±5% | 边界告警 | 标记为观察 |
| SI-05 | 窗口抑制 | 静默窗口内 | 窗口告警 | 告警不推送 |
| SI-06 | 去重抑制 | 相同告警5min内 | 重复告警 | 合并计数 |

### 5.2 层级抑制 (SI-01)

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 抑制方向 | P0→P1, P1→P2 | 高抑制低 |
| 抑制范围 | 同根因 | 仅同根因抑制 |
| 抑制标记 | suppressed_by | 记录被谁抑制 |
| P0展示 | 始终 | P0永远展示 |
| P1展示 | 条件 | 无P0时展示, 有P0时折叠 |

**抑制示例:**

```
场景: F1 DEP故障
原始告警: SA-01(CRITICAL), SA-02(HIGH), SA-03(HIGH)
层级抑制后: SA-01(CRITICAL) + [SA-02, SA-03 被抑制]
展示: "SA-01 DEP持续异常 ×1 (CRITICAL) [抑制2条HIGH]"
```

### 5.3 频率抑制 (SI-03)

| 参数 | 默认值 | 可调范围 | 说明 |
|------|--------|----------|------|
| 频率阈值 | 5次/min | 1~20 | 超过此频率抑制 |
| 频率窗口 | 60s | 10s~300s | 滑动窗口 |
| 抑制行为 | 仅展示计数 | 计数/详情/折叠 | 被抑制告警只计数 |
| 首次告警 | 保留 | — | 首次告警始终保留 |
| 告警升级 | 是 | — | 频率超10x→升级 |

**抑制示例:**

```
场景: F5 DEP抖动
原始告警: SA-12触发×12次 (60s内)
频率抑制后: SA-12组 (计数=12, 首次时间T+0s, 末次时间T+59s)
展示: "SA-12 DEP抖动告警 ×12次 (60s窗口, 频率12/min)"
```

### 5.4 去重抑制 (SI-06)

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 去重窗口 | 300s | 5min内相同告警去重 |
| 去重键 | rule_id + source_id + severity + value | 告警唯一标识 |
| 去重行为 | 合并计数 | 合并为1条+计数 |

## 18. 告警有效性与信息密度度量

### 18.1 各场景度量汇总

| 场景 | 原始告警 | 抑制后组数 | 抑制率 | 信息密度 | 核心告警保留率 | 抑制准确率 |
|------|----------|------------|--------|----------|----------------|------------|
| ST-01 | 10 | 3 | 70% | 3.3x | 100% | 100% |
| ST-02 | 5 | 1 | 0% | 5.0x | 100% | — |

| ST-07 | 25 | 3 | 60% | 2.0x | 100% | 100% |
| ST-08 | 30 | 2 | 85% | 4.5x | 100% | 100% |
| **平均** | **26.25** | **3.125** | **70.6%** | **3.3x** | **100%** | **99.4%** |

### 18.2 告警有效性定义

```
告警有效性 = 有效告警数 / 总告警数

有效告警: 
- 首次触发的核心告警 (P0)
- 非重复告警
- 不在静默窗口内的告警

无效告警:
- 重复告警 (5min内同规则同来源)
- 被层级抑制的告警 (P0存在时P1)
- 被频率抑制的告警 (>5次/min)
- 被静默窗口抑制的告警
```

### 18.3 信息密度提升

```
信息密度 = 原始告警数 / 抑制后组数

ST-01: 10/3 = 3.3x
ST-02: 5/1 = 5.0x
ST-03: 24/1 = 4.0x
ST-04: 45/5 = 2.5x
ST-05: 40/7 = 3.5x
ST-06: 30/2 = 3.0x
ST-07: 25/3 = 2.0x (注: 25→3是3.1x, 但保留较多)
ST-08: 30/2 = 4.5x

平均信息密度: 3.3x (提升330%)
```
