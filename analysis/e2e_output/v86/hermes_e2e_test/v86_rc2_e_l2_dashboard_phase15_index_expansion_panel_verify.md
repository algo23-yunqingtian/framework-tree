## 7. 索引膨胀应急观测流程

### 7.1 应急响应流程 (5步)

```
阶段1: WARN触发 (8.0%)
  ├─ IE-AL-001告警 → SRE值班通知 (IM+邮件)
  ├─ 面板高亮 + 黄色标识
  ├─ 确认膨胀率趋势 (检查面板24h时序)
  ├─ 判断: 自然增长 vs 异常膨胀
  └─ 若自然增长: 执行手动重平衡 (约15min)

阶段2: 持续观察 (8.0%~10.0%)
  ├─ 面板持续显示黄色区域
  ├─ 每小时检查膨胀率趋势
  ├─ 执行每日定时压缩 (凌晨03:00 UTC)
  └─ 确认膨胀率回落至7.5%以下

阶段3: CRITICAL逼近 (≥9.5%)
  ├─ 面板颜色变为红色警告
  ├─ 通知升级至技术负责人
  ├─ 立即执行索引重平衡 + 全量压缩
  └─ 评估是否需要暂停放量

阶段4: CRITICAL触发 (10.0%)
  ├─ IE-AL-002告警 → P1全员通知 (电话+IM+短信)
  ├─ 面板红色标识 + 弹窗
  ├─ 启动自动保护: 索引写入限流 (降至50%)
  ├─ 执行紧急重平衡 (reindex + compact)
  └─ 启动StageC回滚预案 (12min SLA)

阶段5: 恢复确认
  ├─ 膨胀率回落至7.5%以下
  ├─ 告警自动恢复 (IE-AL-001恢复窗口10min)
  ├─ 面板恢复正常绿色
  ├─ 确认查询P99延迟正常 (<50ms)
  └─ 记录事件时间线
```
