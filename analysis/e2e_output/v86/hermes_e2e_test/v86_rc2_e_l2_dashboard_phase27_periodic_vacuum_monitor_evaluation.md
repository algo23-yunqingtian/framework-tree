## 2. 周期调整依据 — 从30天→15天的调整原因

### 2.1 周期调整背景

Phase26期间DSHB执行首次全流量vacuum(2026-11-10), 实现索引膨胀率从9.50%降至6.80%(28.4%降幅), 查询P99从168ms降至138ms(17.9%改善)。DSHB在Phase26作业总结中提出中期建议: 评估是否将vacuum周期从30天调整为21天。基于Phase26观测数据, Phase27最终决定采用15天周期。

### 2.2 调整原因详细分析

#### 2.2.1 膨胀率增长速率评估

| 时段 | 观测周期 | 日均膨胀增长 | 月均增长 |
|------|---------|------------|---------|
| Phase24 (全量上线期) | 2026-08-19至2026-09-06 | 0.090% | 2.70% |
| Phase25 (稳定性基线期) | 2026-09-07至2026-10-06 | 0.070% | 2.10% |
| Phase26 (30天维护期) | 2026-10-07至2026-11-06 | 0.075% | 2.25% |
| Phase27 (90天运营期) | 2026-11-07至2026-08-19 | 0.068% | 2.04% |

**结论**: Phase27日均膨胀增长0.068%, 较Phase26的0.075%略有下降(↓9.3%), 主要得益于Phase26 vacuum后的索引物理优化效果延续。但15天周期下日均增量仅1.02%, 仍处于可控范围。

#### 2.2.2 15天周期合理性论证

| 论证维度 | 数据 | 结论 |
|---------|------|------|
| 15天膨胀增量 | 0.068%×15天=1.02% | ✅ 远低于WARN阈值1.5%裕度 |
| 30天膨胀增量 | 0.068%×30天=2.04% | ⚠️ 接近WARN阈值2.0% |
| 60天膨胀增量 | 0.068%×60天=4.08% | 🔴 远超阈值 |
| Vacuum恢复余量 | 每次vacuum后降至6.5-7.5% | ✅ 15天周期可保持膨胀率<9.0% |
| 维护窗口频率 | 每15天1次 | ✅ 不影响业务连续性 |
| 快照存储空间 | 2.85TB×6次=17.1TB(滚动删除) | ✅ 7天滚动保留, 峰值存储可控 |

#### 2.2.3 与Phase26周期对比

| 对比维度 | Phase26(30天) | Phase27(15天) | 评估 |
|---------|-------------|-------------|------|
| Vacuum次数/月 | 1次 | 2次 | 更主动 |
| 每次vacuum降幅 | avg 0.34% | avg 0.42% | ↑23.5% |
| 膨胀率峰值 | 8.45% | 9.50%(首次) | Phase26遗留 |
| 膨胀率谷值 | 8.05% | 6.80%(首次) | 更优基线 |
| 膨胀率波动范围 | 8.05%-8.45% | 6.80%-9.50%(首次) | 稳定收敛 |
| 告警触发频率 | 7次/30天 | 6次/90天 | ↓88.9% |
| 误报率 | 0% | 0% | 一致 |
| 漏报率 | 0% | 0% | 一致 |
| **综合评级** | **✅ 良好** | **✅ 优秀** | **↑** |
