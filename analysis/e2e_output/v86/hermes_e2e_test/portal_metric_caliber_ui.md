## 1. 口径歧义问题

### 1.1 问题描述

V85/V86 对比面板展示 P0 拦截率时存在口径歧义：

| 口径 | 规则集 | P0 拦截率 | TP | FP | 回归 |
|------|--------|----------|----|----|------|
| V85 基线 | 31 规则完整黑名单 | 87.5% | 44 | 0 | — |
| V86 P0 原型 | 4 规则（BL-009a/BL-026/BL-012B/PDF_Fix） | 75.0% | 40 | 0 | 4 |
| V86 完整黑名单+P0 | 35 规则（31+4 新增） | 100% | 44+ | 0 | 0 |

**用户困惑**：看到 V86 P0 拦截率 75% < V85 87.5%，以为 V86 退化；实际是规则集不同（4 vs 31），不是能力退化。

### 1.2 根因

- V86 当前仅交付 P0 原型（4 规则），未集成到完整黑名单
- DSHB `comparison_report.json` 的对比是「4 规则原型 vs 31 规则基线」，口径不对等
- DSHB 全量回归报告显示 BL-009a + BL-026 在完整黑名单基础上 P0 拦截率 88.2% → 100%

## 3. 口径切换交互逻辑

```python
class CaliberSwitcher:
    """指标口径切换器"""

    CALIBERS = {
        "prototype": {
            "label": "原型对比 (4 规则 vs 31 规则)",
            "purpose": "验证原型边界",
            "data_source": "comparison_report.json (离线)",
            "v85_rate": 87.5,
            "v86_rate": 75.0,
            "regressions": 4,
            "note": "⚠ 4 条回归源于规则集差异，非能力退化"
        },
        "full": {
            "label": "完整对比 (35 规则 vs 31 规则)",
            "purpose": "上线准入判断",
            "data_source": "dshb_rule_eval 任务 (需提交)",
            "v85_rate": 88.2,
            "v86_rate": 100.0,
            "regressions": 0,
            "note": "✅ BL-009a + BL-026 新增拦截 7 条，0 回归 0 误拦"
        }
    }

    def render(self, caliber: str):
        c = self.CALIBERS[caliber]
        return {
            "v85_rate": c["v85_rate"],
            "v86_rate": c["v86_rate"],
            "delta": c["v86_rate"] - c["v85_rate"],
            "regressions": c["regressions"],
            "caliber_label": c["label"],
            "caliber_note": c["note"],
            "data_source": c["data_source"],
        }
```

### 3.1 默认口径

门户默认展示「原型对比」口径（当前唯一有离线数据的口径），顶部显示 ⚠ 提示横幅引导用户切换。

### 3.2 完整口径可用条件

- V86 任务 API 已实现 → 可提交 `dshb_rule_eval(blacklist_version=v86-full)`
- 或 DSHB 交付完整对比的离线 `comparison_report.json`

## 4. 消除歧义效果

| 优化前 | 优化后 |
|--------|--------|
| 用户看到 75% < 87.5%，以为退化 | 口径说明卡片明确标注「4 vs 31 规则」 |
| 4 条回归无解释 | 每条回归标注口径原因（原型无对应规则 / 上游数据缺失） |
| 无法判断上线准入 | 完整口径展示 100% + ✅ 准入达标 |
| 口径切换无引导 | 顶部横幅 + 口径选择器 + ℹ️ 提示 |
