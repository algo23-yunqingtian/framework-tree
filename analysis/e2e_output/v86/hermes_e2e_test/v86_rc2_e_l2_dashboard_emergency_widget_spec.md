## 2. 应急操作面板总体设计

### 2.1 SP6面板定位

SP6是灰度全阶段聚合大盘的第6个主面板, 定位为应急操作入口面板, 为运维人员在混沌故障、大盘异常等紧急场景下提供快捷操作入口。

| 面板 | 名称 | 子面板数 | 定位 |
|------|------|----------|------|
| SP1 | DEP健康 | 12 | 监控DEP-001状态 |
| SP2 | Gate状态 | 14 | 监控Gate V5预检 |
| SP3 | HERMES决策 | 12 | 展示gray_gate_decider决策 |
| SP4 | 告警时序 | 12 | 展示告警事件时序 |
| SP5 | 面板性能 | 12 | 监控大盘性能 |
| **SP6** | **应急操作** | **10** | **应急操作入口** |

## 4. 影子镜像开关功能

### 4.1 功能定义

影子镜像开关用于控制V86影子流量的镜像启停。开启时, V86影子大盘接收真实流量镜像; 关闭时, 影子大盘不接收流量, 仅保留配置。

| 参数 | 值 |
|------|-----|
| 功能ID | EMO-01 / EMO-02 |
| 操作目标 | V86影子流量镜像 |
| 操作类型 | 切换 (ON↔OFF) |
| 影响范围 | 仅V86影子大盘 (不影响V85生产面板) |
| 操作耗时 | ≤1s |
| 可逆性 | 是 (开关切换即回滚) |

### 4.2 操作接口

```
POST /api/l2/dashboard/emergency/mirror-toggle

Request:
{
  "action": "toggle",           // "enable" | "disable"
  "operator": "admin@dshe",
  "reason": "混沌演练准备",       // 必填, 操作原因
  "timestamp": "2026-10-15T10:00:00Z",
  "session_id": "sess-abc123"
}

Response:
{
  "status": "success",
  "action": "enable",
  "mirror_state": "ON",
  "effective_time": "2026-10-15T10:00:01Z",
  "latency_ms": 450,
  "audit_event_id": "AE-20261015-001"
}
```

### 4.3 操作执行流程

```
1. 用户点击镜像开关按钮
2. SP6面板显示确认弹窗
3. 用户输入操作原因
4. RBAC权限校验
   ├── 权限不足 → 返回403, 显示权限不足提示
   └── 权限充足 → 继续
5. 调用镜像切换接口
6. 显示进度条
7. 接口返回成功/失败
   ├── 成功 → 更新面板状态, 记录审计事件
   └── 失败 → 显示错误提示, 记录失败审计事件
8. 大盘状态自动刷新
9. 操作完成
```

### 4.4 操作状态定义

| 状态 | 语义 | 面板展示 | 可执行操作 |
|------|------|----------|-----------|
| ON | 影子镜像开启 | 绿色ON按钮 | 可关闭 |
| OFF | 影子镜像关闭 | 灰色OFF按钮 | 可开启 |
| PENDING | 操作执行中 | 黄色待处理 | 等待 |
| ERROR | 操作失败 | 红色错误 | 可重试 |

### 4.5 镜像开关配置

```json
{
  "mirror_switch": {
    "enabled": true,
    "default_state": "ON",
    "toggle_latency_ms": 450,
    "toggle_timeout_ms": 5000,
    "retry_on_timeout": true,
    "max_retries": 3,
    "audit_log": true,
    "reason_required": true,
    "confirm_required": true
  }
}
```

## 5. L2一键回滚按钮功能

### 5.1 功能定义

L2一键回滚按钮用于在紧急情况下快速回滚L2面板到安全状态。回滚执行`rollback_l2_panel.sh`脚本, 执行4个回滚动作。

| 参数 | 值 |
|------|-----|
| 功能ID | EMO-03 |
| 操作目标 | L2面板全量回滚 |
| 操作类型 | 执行 (4动作) |
| 影响范围 | L2全部6面板 (SP1~SP6) |
| 操作耗时 | ≤3s |
| 可逆性 | 是 (手动切回生产) |

### 5.2 回滚动作定义

| 动作ID | 动作名称 | 配置变更 | 目的 |
|--------|----------|----------|------|
| A-1 | 告警适配器→sandbox | `--deploy-env sandbox` | 隔离告警路由 |
| A-2 | 数据源→mock | `datasource_mode=mock` | 切断DEP-001依赖 |
| A-3 | 暂停指标采集 | `metric_collector_enabled=false` | 停止消耗配额 |
| A-4 | 启用告警静默 | `alert_silence_enabled=true` | 防回滚误报 |

### 5.3 操作接口

```
POST /api/l2/dashboard/emergency/rollback

Request:
{
  "action": "rollback",
  "operator": "admin@dshe",
  "reason": "F1链路级故障应急回滚",  // 必填
  "scope": "full",                   // "full" | "partial" | "alert_only" | "datasource_only"
  "actions": [1, 2, 3, 4],           // 执行动作列表
  "confirm_code": "CONFIRM",         // 确认码
  "timestamp": "2026-10-15T10:00:00Z",
  "session_id": "sess-abc123"
}

Response:
{
  "status": "success",
  "actions_completed": 4,
  "actions_failed": 0,
  "action_details": [
    {"id": 1, "status": "success", "latency_ms": 200},
    {"id": 2, "status": "success", "latency_ms": 150},
    {"id": 3, "status": "success", "latency_ms": 100},
    {"id": 4, "status": "success", "latency_ms": 120}
  ],
  "total_latency_ms": 850,
  "audit_event_id": "AE-20261015-002",
  "rollback_state": "ROLLED_BACK"
}
```

### 5.4 操作执行流程

```
1. 用户点击一键回滚按钮
2. SP6面板显示确认弹窗 (需输入CONFIRM确认码)
3. RBAC权限校验
   ├── 权限不足 → 返回403, 显示权限不足提示
   └── 权限充足 → 继续
4. 验证确认码
   ├── 确认码错误 → 返回400, 显示确认码错误
   └── 确认码正确 → 继续
5. 调用回滚脚本 rollback_l2_panel.sh
6. 执行4个回滚动作 (顺序执行)
7. 显示进度条 (4/4完成)
8. 返回执行结果
   ├── 全部成功 → 更新面板状态, 记录审计事件
   ├── 部分成功 → 显示部分失败信息, 记录审计事件
   └── 全部失败 → 显示错误提示, 记录失败审计事件
9. 大盘状态自动刷新 (SP1→BLOCKED, SP2→NOT_READY, SP3→ROLLBACK)
10. 告警静默窗口开启 (SW-04)
11. 操作完成
```

## 6. RBAC权限校验

### 6.1 角色定义

| 角色ID | 角色名称 | 描述 | 权限级别 |
|--------|----------|------|----------|
| ROLE-ADMIN | Admin | 完全权限 | EXECUTE + VIEW + AUDIT |
| ROLE-OPERATOR | Operator | 操作权限 | EXECUTE + VIEW |
| ROLE-VIEWER | Viewer | 查看权限 | VIEW |
| ROLE-AUDITOR | Auditor | 审计权限 | VIEW + AUDIT |

### 6.2 权限定义

| 权限ID | 权限名称 | 描述 | 操作影响 |
|--------|----------|------|----------|
| PERM-VIEW | 查看权限 | 查看面板状态和操作历史 | 无影响 |
| PERM-EXECUTE | 执行权限 | 执行镜像开关和回滚操作 | 影响面板状态 |
| PERM-AUDIT | 审计权限 | 查看审计事件和追溯链路 | 无影响 |

### 6.3 角色-权限矩阵

| 角色 | PERM-VIEW | PERM-EXECUTE | PERM-AUDIT | 可执行操作 |
|------|-----------|--------------|------------|-----------|
| Admin | ✅ | ✅ | ✅ | 镜像开关+一键回滚 |
| Operator | ✅ | ✅ | ❌ | 镜像开关+一键回滚 |
| Viewer | ✅ | ❌ | ❌ | 仅查看 |
| Auditor | ✅ | ❌ | ✅ | 查看+审计 |

### 6.4 权限校验流程

```
1. 用户触发操作
2. 提取用户身份信息 (session_id → user_id)
3. 查询用户角色 (user_id → role_id)
4. 查询角色权限 (role_id → permissions)
5. 检查操作所需权限
   ├── 镜像开关需要 PERM-EXECUTE
   ├── 一键回滚需要 PERM-EXECUTE
   └── 查看操作历史需要 PERM-VIEW
6. 权限判定
   ├── 权限充足 → 允许操作, 记录审计事件
   └── 权限不足 → 拒绝操作, 返回403, 记录审计事件(拒绝)
```

## 10. 操作安全性设计

### 10.1 安全特性

| 特性 | 实现方式 | 说明 |
|------|----------|------|
| 二次确认 | 确认弹窗+CONFIRM码 | 防止误操作 |
| 操作原因 | 强制填写原因 | 操作可追溯 |
| RBAC权限 | 4角色3权限 | 权限最小化 |
| 操作审计 | 23字段审计事件 | 全操作可追溯 |
| 操作幂等 | 重复操作不影响状态 | 重复回滚不破坏 |
| 操作超时 | 10s超时+自动恢复 | 防操作卡死 |
| 操作互斥 | 同一时间仅允许1个操作 | 防并发冲突 |
| 操作回滚 | 所有操作可逆 | 操作可恢复 |

### 10.2 二次确认设计

```
镜像开关确认:
1. 用户点击开关
2. 弹出确认弹窗
3. 用户输入操作原因 (必填)
4. 点击"确认"
5. 操作执行

一键回滚确认:
1. 用户点击回滚按钮
2. 弹出确认弹窗 (红色高亮)
3. 用户输入确认码 "CONFIRM" (必填)
4. 用户输入操作原因 (必填)
5. 点击"确认执行"
6. 操作执行

安全性:
- 镜像开关: 需要输入原因, 防止误触
- 一键回滚: 需要CONFIRM码+原因, 防止误触
- 所有操作: 审计记录, 可追溯
```

### 10.3 操作幂等性

| 操作 | 幂等性 | 说明 |
|------|--------|------|
| 镜像ON (已ON) | 幂等 | 重复开启, 状态不变, 不报错 |
| 镜像OFF (已OFF) | 幂等 | 重复关闭, 状态不变, 不报错 |
| 回滚 (已回滚) | 幂等 | 重复回滚, 跳过已完成动作, 不报错 |
| 切回 (已切回) | 幂等 | 重复切回, 状态不变, 不报错 |

### 10.4 操作互斥

| 场景 | 处理 | 说明 |
|------|------|------|
| 回滚执行中+镜像开关 | 拒绝镜像开关 | 回滚期间禁止其他操作 |
| 镜像开关中+回滚 | 拒绝回滚 | 镜像操作期间禁止回滚 |
| 回滚执行中+回滚 | 幂等跳过 | 重复回滚, 跳过已完成动作 |

### 11.1 错误分类

| 错误ID | 错误类型 | 错误码 | 错误信息 | 恢复方式 |
|--------|----------|--------|----------|----------|
| ERR-401 | 认证失败 | 401 | 用户未认证 | 重新登录 |
| ERR-403 | 权限不足 | 403 | 权限不足 | 联系管理员 |
| ERR-400 | 参数错误 | 400 | 参数无效 | 修改参数 |
| ERR-409 | 操作冲突 | 409 | 操作冲突 | 等待重试 |
| ERR-500 | 内部错误 | 500 | 服务器错误 | 重试 |
| ERR-503 | 服务不可用 | 503 | 服务不可用 | 等待恢复 |
| ERR-TIMEOUT | 操作超时 | — | 操作超时 | 自动重试 |

### 11.2 错误恢复流程

```
操作失败
    │
    ├── 401 认证失败 → 重新登录 → 重试
    │
    ├── 403 权限不足 → 联系管理员 → 不可自动恢复
    │
    ├── 400 参数错误 → 修改参数 → 重试
    │
    ├── 409 操作冲突 → 等待冲突操作完成 → 重试
    │
    ├── 500 内部错误 → 自动重试(3次, 指数退避) → 通知运维
    │
    ├── 503 服务不可用 → 自动重试(3次, 指数退避) → 通知运维
    │
    └── TIMEOUT 操作超时 → 自动重试(3次, 指数退避) → 通知运维
```

### 11.3 自动重试策略

| 参数 | 值 |
|------|-----|
| 最大重试次数 | 3 |
| 重试间隔 | 1s, 2s, 4s (指数退避) |
| 总超时时间 | 10s |
| 重试失败后 | 通知运维 + 记录审计 |
