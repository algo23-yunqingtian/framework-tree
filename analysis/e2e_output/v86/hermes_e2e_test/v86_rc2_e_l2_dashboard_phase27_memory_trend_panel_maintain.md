### 7.2 优化一：365天预测叠加层

**背景**: Phase26 面板仅支持 24h/7d/30d 视图，缺少对未来的预测能力，用户无法预判下次扩容时间。

**优化内容**:
- 基于扩容后历史数据线性回归，在时间轴右侧叠加 365 天预测曲线（灰色虚线）
- 预测曲线延伸至 Day 365（约一年）
- 预测触阈值点显示"预计警告阈值" / "预计严重阈值"标签
- 支持预测开关切换

**验证结果**:

| 校验项 | 结果 |
|-------|------|
| 预测曲线渲染正确 | ✅ 与实际增长趋势一致 |

| 置信区间显示 | ✅ 浅灰半透明填充 |
| 预测触阈值点标记 | ✅ "预计 2027-03-31 触警告" |
| 预测开关切换 | ✅ 开启/关闭正常 |
| 预测曲线与历史数据衔接 | ✅ 无缝连续 |
| 预测精度回测 | ✅ 回溯7天预测误差 <0.1pp |

### 7.3 优化二：扩容事件标记

**优化内容**:

- 事件上方显示标签，包含变更类型、时间、工单号
- Hover 展开事件详情面板
- 支持按事件类型筛选（扩容/重启/配置变更）

**验证结果**:

| 校验项 | 结果 |
|-------|------|
| 扩容事件标记可见 | ✅ Day 20 (2026-12-17) |
| 事件标签正确 | ✅ "扩容 16GB→32GB" |

| 事件标记时间精度 | ✅ 精确到分钟 |

### 7.4 优化三：周平均线

**背景**: 日粒度数据波动较大（±0.08pp），短周期趋势线不够平滑，难以识别中长期增长趋势。
