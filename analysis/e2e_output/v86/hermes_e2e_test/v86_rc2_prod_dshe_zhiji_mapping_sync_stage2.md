#### 3.1.2 三批次zhiji_id映射明细

**批次1 (59项)**:
- 时间维度指标 (zj_time_*): 覆盖日/周/月/季度/年度时间粒度
- 地域维度指标 (zj_region_*): 覆盖省/市/区/县地域粒度
- 业务维度指标 (zj_biz_*): 覆盖交易/支付/清结算业务粒度
- 用户维度指标 (zj_user_*): 覆盖活跃/新增/留存用户粒度
- 财务维度指标 (zj_fin_*): 覆盖收入/成本/利润财务粒度
- 技术指标 (zj_tech_*): 覆盖延迟/吞吐/可用率技术粒度

**批次2 (49项)**:
- 组合维度指标 (zj_combo_*): 时间×地域/业务×用户等交叉维度
- 聚合维度指标 (zj_agg_*): 多指标聚合计算结果
- 趋势维度指标 (zj_trend_*): 同比/环比/移动平均等趋势计算
- 异常维度指标 (zj_alert_*): 异常检测/阈值告警/异常分类
- 衍生维度指标 (zj_derived_*): 基于基础指标的衍生计算

**批次3 (82项)**:
- 高级分析维度指标 (zj_advanced_*): 机器学习预测/聚类/分类结果
- 多维交叉指标 (zj_cross_*): 4维以上交叉分析结果
- 实时流指标 (zj_stream_*): 实时数据流处理指标
- 批处理指标 (zj_batch_*): 批量数据处理指标
- 混合指标 (zj_hybrid_*): 实时+批处理混合指标

### 3.2 zhiji_id格式规范
