## 4. 丢包率偏差根因分析

### 4.1 数值分析

| 维度 | 值 |
|------|---|
| 预测丢包率 | 0.00455% |
| 实测丢包率 | 0.00402% |
| 绝对偏差 | 0.00053pp |

| 阈值 | ≤0.01% |
| 实测 vs 阈值 | 0.00402% < 0.01% ✅ |

### 4.2 根因

丢包率是小基数泊松波动指标：
- write_fail 概率固定 4×10⁻⁵
- 72h 预期写失败次数 ≈ 68 次
- 泊松分布相对波动 ≈ 1/√68 ≈ **12.1%**
- 实测偏差 11.6% 完全在泊松理论波动范围内
