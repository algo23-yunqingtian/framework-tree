### 3.2 监控大盘设计原则

| 原则 | 说明 | 实现方式 |
|------|------|---------|
| **灰度/生产隔离** | 灰度流量与生产流量完全隔离 | 独立面板组 + shadow_traffic 标签 |
| **误报控制** | 灰度告警不干扰生产告警 | 独立告警通道 + 误报率阈值 |
| **实时可视化** | 异常事件实时可视化 | 6视图实时渲染 |
| **阶段可观测** | 每个灰度阶段独立观测 | G1-G4 四阶段独立面板 |
| **V85基线保护** | V85展示基线不受影响 | 新面板使用独立 namespace |
| **自动升级** | 灰度异常自动升级至 HERMES | 告警升级链配置 |
