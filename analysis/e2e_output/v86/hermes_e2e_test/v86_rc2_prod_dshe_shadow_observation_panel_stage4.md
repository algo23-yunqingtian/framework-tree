### 3.2 面板设计原则

| 原则 | 说明 | 实现方式 |
|------|------|---------|
| **影子/生产隔离** | 影子测试流量与生产流量完全隔离 | 独立面板组 + 独立数据源 + 独立告警规则 |
| **双ID可追溯** | 每项指标同时展示 zhiji 长短ID + 语义ID | 三列 ID 展示 + 悬浮提示 |
| **Mock/Real 切换** | 支持 Mock 数据与真实数据无缝切换 | 数据源路由策略 + 手动/自动切换 |
| **HERMES 就绪即用** | HERMES 就绪后可直接执行影子测试 | 所有面板预配置，无需额外调整 |
| **V85 基线保护** | V85 展示基线完全不受影响 | 新面板使用独立 namespace |
| **告警降噪** | 避免影子测试误告警干扰生产 | 独立告警通道 + 影子流量标签 |
