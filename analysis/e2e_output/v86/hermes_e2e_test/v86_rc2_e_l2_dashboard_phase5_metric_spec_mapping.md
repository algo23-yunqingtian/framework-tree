## 3. HERMES审计4项CRITICAL差异根因分析

### 3.1 差异总览

HERMES Phase4灰度审计WAL链路验证报告§7发现4项CRITICAL跨团队指标口径差异：

| # | 维度 | DSHB自报 | DSHE自报 | HERMES实测 | 最大相对偏差 | 级别 |
|---|------|----------|----------|------------|------------|------|
| 1 | 审计事件吞吐 | 2847 | 102000 | 324.21 | 99.7% | CRITICAL |
| 2 | 事件丢失率 | 0.05% | 0.0082% | 0.00322% | 93.6% | CRITICAL |
| 3 | P99告警/审计延迟 | 460ms | 32ms | 13.63ms | 97.0% | CRITICAL |
| 4 | 72h事件总量 | 27000000 | 72000 | 1167144 | 99.7% | CRITICAL |

### 3.2 差异①: 审计事件吞吐 (DSHB 2847 vs DSHE 102000 vs HERMES 324.21 ev/s)

**根因**: 三者并非同一链路：
- DSHB 2847 = DEP业务事件流 (单源原始流)
- DSHE 102000 = L2大盘聚合后事件 (6个数据源汇入聚合值)
- HERMES 324.21 = 审计持久化事件

**整改方案**: 禁止将三者相加或互相替代。DSHE指标计算逻辑增加链路归属标注：
```
吞吐指标拆分:
  - dshb_business_throughput: DEP单源原始流 (ev/s)
  - dshe_aggregated_throughput: L2大盘聚合流 (ev/s, 6源汇入)
  - hermes_audit_throughput: 审计持久化流 (ev/s)
  - 三者独立展示，禁止合并
```

### 3.3 差异②: 事件丢失率 (DSHB 0.05% vs DSHE 0.0082% vs HERMES 0.00322%)

**根因**: 阈值口径冲突 — DSHE用"<5%"判定PASS，而工单T6要求≤0.01%。DSHE按其自设阈值100%PASS，但按工单标准DSHB的0.05%直接不达标。

**整改方案**: 统一为工单T6标准≤0.01%：
```
事件丢失率统一:
  阈值: ≤0.01% (工单T6标准)
  判定: 实际值 ≤ 0.01% → PASS
  三方: DSHB/DSHE/HERMES 全部采用≤0.01%阈值
  DSHE旧阈值(<5%)已废弃
```

### 3.4 差异③: P99延迟 (DSHB 460ms vs DSHE 32ms vs HERMES 13.63ms)

**根因**: 不是矛盾，是完全不同的度量对象，但被混在同一列比较：
- DSHB 460ms = 业务告警端到端链路 (含前端渲染)
- DSHE 32ms = 审计入库链路
- HERMES 13.63ms = WAL写入+入库

**整改方案**: 拆分不同链路的延迟指标，禁止并列对比：
```
P99延迟拆分:
  - business_end2end_p99: 业务告警端到端 (DSHB链路, 含前端渲染)
  - audit_ingestion_p99: 审计入库 (DSHE链路)
  - wal_write_p99: WAL写入 (HERMES链路)
  - 三类时延独立面板展示，禁止合并
```

### 3.5 差异④: 72h事件总量 (DSHB 2700万 vs DSHE 7.2万)

**根因**: 对账基数不一致 — DSHB统计72h全量业务事件；DSHE统计抽样窗口事件(72000=8条链×9000抽样)。

**整改方案**: 统一对账窗口与事件口径：
```
对账基数统一:
  时间窗口: 72h 滑动窗口
  事件口径: DEP/Gate 源事件 (不含派生事件)
  抽样规则: 全量 (非抽样) — 72h内全部事件
  DSHB: 全量业务事件 (72h)
  DSHE: 全量审计事件 (72h, 非抽样)
  HERMES: 全量持久化事件 (72h)
  基数差异时以DEP/Gate源事件为准
```

### 7.3 置信区间计算

```
Wilson score confidence interval:
  z = 1.96 (95% confidence)
  n = total samples
  p = suppressed / n (sample proportion)
  
  lower = (p + z²/(2n) - z*sqrt(p*(1-p)/n + z²/(4n²))) / (1 + z²/n)
  upper = (p + z²/(2n) + z*sqrt(p*(1-p)/n + z²/(4n²))) / (1 + z²/n)
  
  输出: "抑制率 74.3% (95%CI: [72.8%, 75.8%], n=523)"
```

### 7.4 统计输出示例

| 指标 | 值 | 置信区间(95%) | 样本量 | 状态 |
|------|-----|--------------|--------|------|
| 告警抑制率 | 74.3% | [72.8%, 75.8%] | 523 | ✅ 充足 |
| 告警保留率(P0) | 100.0% | [99.5%, 100.0%] | 180 | ✅ 充足 |
| 误抑制率 | 2.1% | [1.3%, 3.3%] | 523 | ✅ 可控 |
| 抖动告警抑制率 | 76.47% | [66.8%, 84.1%] | 17 | ⚠️ 样本不足 |
