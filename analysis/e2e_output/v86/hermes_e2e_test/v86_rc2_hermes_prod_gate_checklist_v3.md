
### 4.2 判定规则

```
所有 P0 项通过 + 所有 P1 项有补救计划 → READY
所有 P0 项通过 + 任一 P1 项无补救计划 → CONDITIONAL
任一 P0 项未通过 → NOT_READY
```
