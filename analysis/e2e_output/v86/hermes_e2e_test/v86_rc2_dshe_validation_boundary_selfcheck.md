### 4.3 P0缺陷详细分析

#### BC-01: 历史校验100%为元数据层面

| 维度 | 说明 |
|------|------|
| 影响 | 170项/9批次 + 60项/ID_ALIGN_FIX + 全部Stage4校验 |
| 后果 | 所有历史校验结论仅代表UI层面通过，不代表底层数据可用 |
| 根因 | 校验模型仅定义了展示层维度，未定义底层取数维度 |
| 修复 | 本工单T3.3更新校验规则，增加`data_fetchable`前置判断 |

#### BC-02: 桥接表`data_fetchable`状态未纳入校验

| 维度 | 说明 |
|------|------|
| 影响 | 367项桥接条目中`data_fetchable`字段未被任何校验读取 |
| 后果 | DSHB标记取数不可用的条目，DSHE仍判定为PASS |
| 根因 | 校验脚本未读取桥接表`data_fetchable`字段 |
| 修复 | 本工单T3.3更新校验脚本，增加前置依赖检查 |

#### BC-03: UI渲染PASS但底层可能不可用

| 维度 | 说明 |
|------|------|
| 影响 | 229项指标中可能存在UI渲染正常但底层无数据的情况 |
| 后果 | 用户看到面板有数据显示（可能是缓存/默认值），实际底层无数据 |
| 根因 | 展示层校验与底层取数校验完全脱节 |
| 修复 | 本工单T3.2增加`data_fetchable`状态可视化，T3.3更新校验规则 |
