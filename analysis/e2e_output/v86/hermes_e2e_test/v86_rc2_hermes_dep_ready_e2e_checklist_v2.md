## 1. 门禁分级定义（P0/P1/P2）

### 1.1 分级语义

| 级别 | 名称 | 语义 | 未通过后果 | 自动化能力 |
|------|------|------|-----------|-----------|
| **P0** | 强制阻断 | DEP 就绪的前置硬条件 | **流水线禁止启动**，需三方会签解除 | 脚本自动判定 |
| **P1** | 条件放行 | 可修复后重提 | 当前包阻断，修复后放行 | 脚本自动判定 + 人工确认 |
| **P2** | 观测项 | 记录不阻断 | 记录至事件存储，不阻断流转 | 自动记录 |

### 1.2 判定规则

```
P0 项全部通过 → 进入 P1 评估
P1 项全部通过 → 进入 P2 观测
P2 项仅记录，不参与阻断判定
```

### 1.3 门禁状态机

```
[未启动] --P0全通过--> [P1评估中] --P1全通过--> [可灰度] --灰度达标--> [可放量]
    |                      |                        |
    |                      |                        +--灰度失败--> [回滚]
    |                      |
    |                      +--P1未通过--> [退回修复] --> [P1重评]
    |
    +--P0未通过--> [阻断] --> [DEP 未就绪]
```
