### 2.2 抑制策略处理流水线

```
原始告警 (N条)
    │
    ▼ [第0层: 去重 SI-06]
    │ 去重告警 (N × (1 - 去重率))
    ▼ [第一层: 聚合 L1-L4]
    │ 聚合告警 (聚合后组数)
    ▼ [第二层: 抑制 SI-01~SI-06]
    │ 抑制告警 (组数 - 被抑制数)
    ▼ [第三层: 静默 SW-01~SW-04]
    │ 静默后告警 (有效告警数)
    ▼ [第四层: 分组 D1-D3]
    │ 分组告警 (根因组数)
    ▼ [第五层: 3D动态阈值]
    │ 动态调整后告警
    ▼ [第六层: 误抑制防护 G1-G7]
    │ 最终告警
    ▼
L2大盘展示 + HERMES审计 + 通知路由
```

### 7.6 三维矩阵计算算法

```
def calculate_suppression_rate(traffic_level, fault_type, concurrency_level):
    """
    三维动态抑制率计算
    traffic_level: L1-L5 (0-4 index)
    fault_type: F1-F5, CF01-CF03 (0-7 index)
    concurrency_level: C1-C10 (0-9 index)
    """
    # 基础抑制率 (按故障类型)
    base_rates = {
        'F1': 0.70, 'F2': 0.00, 'F3': 0.60, 'F4': 0.60, 'F5': 0.80,
        'CF01': 0.735, 'CF02': 0.78, 'CF03': 0.78
    }
    
    # 流量层级系数 (L1-L5)
    traffic_coeff = [0.95, 0.98, 1.00, 1.02, 1.03]
    
    # 并发度系数 (C1-C10)
    concurrency_coeff = [0.95, 0.97, 0.98, 0.99, 1.00, 
                         1.00, 1.00, 1.00, 1.00, 1.00]
    
    # 计算原始抑制率
    base = base_rates[fault_type]
    rate = base * traffic_coeff[traffic_level] * concurrency_coeff[concurrency_level]
    
    # 应用锁定区间
    rate = max(0.735, min(0.790, rate))
    
    return rate
```

| 对齐维度 | DSHB基线 | DSHE终版 | 一致性 | 状态 |
|----------|----------|----------|--------|------|
