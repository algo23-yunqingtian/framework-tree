## 4. P1重要缺陷

### P1-01: CF03复合故障期事件丢失

| 属性 | 值 |
|------|-----|
| 缺陷ID | DSHE-PH2-P1-001 |
| 名称 | CF03复合故障期事件丢失 |
| 严重程度 | P1 (重要) |
| 发现时间 | T+60h~T+72h |
| 场景 | CF03 全链路复合型故障 (F1+F2+F3+F4) |
| 描述 | CF03全链路复合故障期间, 16条事件丢失 (0.074%) |
| 影响 | 审计事件不完整, 36条中16条来自CF03期 |
| 根因 | WAL写入边界效应 — 四故障并发导致消费压力剧增, 队列堆积峰值89, 部分事件在WAL写入时丢失 |
| 阈值 | 事件丢失率≤1% (实际0.028%远低于阈值) |
| 判定 | **可接受** — 丢失率0.028%远低于1%阈值, 且集中在最复杂的CF03复合故障期 |
| 建议 | 增加WAL写入缓冲, 调整队列溢出策略 |
| 优先级 | V86-RC3 |
| DSHB同步 | V86-RC3-RISK-001 |
| Phase3修复 | 增加WAL写入缓冲(512KB→2MB), 调整队列溢出策略为背压模式 |
| Phase3复测 | 事件丢失率0.074%→≤0.01%, 远低于1%阈值 |
| 状态 | ✅ CLOSED |
