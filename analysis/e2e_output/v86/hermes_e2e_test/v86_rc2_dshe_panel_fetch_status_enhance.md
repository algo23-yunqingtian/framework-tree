## 2. `data_fetchable`字段接入设计

### 2.1 字段来源与定义

| 属性 | 说明 |
|------|------|
| 字段名 | `data_fetchable` |
| 来源 | DSHB V2 ID桥接表 |
| 数据类型 | BOOLEAN (TRUE/FALSE) |
| 语义 | 该指标底层数据是否可通过zhiji API实际获取 |
| 维护方 | DSHB（每次映射更新时同步维护） |
| 读取方 | DSHE（面板渲染时读取，用于状态标记） |
| 覆盖范围 | 367项桥接条目（197原有 + 170新增映射） |
| 当前状态 | ⚠️ 字段存在但DSHE未读取，需本工单接入 |

### 2.2 字段接入架构图

```
┌──────────────────────────────────────────────────────────────┐
│                    data_fetchable 接入架构                      │
├──────────────────────────────────────────────────────────────┤
│                                                                │
│  ┌─────────────┐    ┌──────────────┐    ┌──────────────┐     │
│  │ DSHB V2     │    │ DSHE 元数据   │    │ 展示层视图    │     │
│  │ ID桥接表    │───→│ 缓存层        │───→│ (Panel/Alert │     │
│  │             │    │              │    │  /Log)       │     │
│  │ zhiji_id    │    │ indicator_id │    │              │     │
│  │ short_id    │    │ semantic_id  │    │ 状态标记渲染  │     │
│  │ semantic_id │    │ data_fetch   │    │              │     │
│  │ long_id     │    │ able: bool   │    │ ✅ 全链路可用 │     │
│  │ data_fetch  │    │ fetch_time   │    │ ⚠️ 依赖阻塞  │     │
│  │ able: bool  │    │ status_ts    │    │ ❌ 不可用     │     │
│  └─────────────┘    └──────────────┘    └──────────────┘     │
│                                                                │
│  数据流: DSHB桥接表 → DSHE元数据缓存 → 展示层视图渲染           │
│                                                                │
│  更新频率: 每次DSHB映射更新时同步, DSHE缓存5分钟TTL              │
│                                                                │
└──────────────────────────────────────────────────────────────┘
```

## 3. 视觉标记方案设计

### 3.1 两级状态定义

| 状态 | 标记 | 颜色 | 图标 | 语义 | 行为 |
|------|------|------|------|------|------|
| 全链路可用 | `FULLY_AVAILABLE` | 🟢 绿色 | ✅ | UI渲染正常 + 底层取数可用 | 正常展示 |
| 元数据完成，底层取数阻塞 | `DEPENDENCY_BLOCKED` | 🟡 黄色 | ⚠️ | UI渲染正常 + 底层取数不可用 | 降级展示 + 告警 |

### 3.2 状态判定逻辑

```
                    ┌──────────────────┐
                    │ 读取桥接表条目    │
                    │ data_fetchable?  │
                    └────────┬─────────┘
                             │
                ┌────────────┼────────────┐
                │                         │
           TRUE (可取数)             FALSE (不可取数)
                │                         │
                ▼                         ▼
     ┌──────────────────┐     ┌──────────────────┐
     │ 检查UI渲染状态    │     │ 检查UI渲染状态    │
     │ 正常?            │     │ 正常?            │
     └────────┬─────────┘     └────────┬─────────┘
              │                         │
         ┌────┼────┐              ┌────┼────┐
         │          │              │          │
       YES        NO            YES        NO
         │          │              │          │
         ▼          ▼              ▼          ▼
  ✅ FULLY_    ❌ ERROR     ⚠️ DEPENDENCY  ❌ ERROR
  AVAILABLE            _BLOCKED
```

## 8. 降级策略设计

### 8.1 三级降级策略

| 级别 | 条件 | 降级行为 | 恢复条件 |
|------|------|---------|---------|
| L1: 缓存降级 | data_fetchable=FALSE, UI渲染正常 | 展示缓存数据 + 黄色警告标记 | data_fetchable恢复TRUE |
| L2: 静态降级 | data_fetchable=FALSE, UI渲染异常 | 静态图片 + 红色警告标记 | UI恢复 + data_fetchable恢复 |
| L3: 面板隔离 | data_fetchable=FALSE, 影响其他面板 | 隔离该面板, 不影响其他面板 | data_fetchable恢复TRUE |
