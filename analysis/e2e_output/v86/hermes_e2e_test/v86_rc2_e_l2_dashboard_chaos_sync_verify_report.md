### 5.3 时间线

```
T+0s    ─── 混沌注入开始: DEP HTTP 500全量注入

         ├─ SP5 性能指标: 采集吞吐→0 (T+5s)

T+60s   ─── 故障恢复: DEP HTTP 200恢复

         ├─ SP1 DEP健康: BLOCKED → RECOVERY (T+60s)
         ├─ SP2 Gate状态: NOT_READY → READY (T+90s)
         ├─ SP3 决策标签: ROLLBACK(F1) → ADVANCE (T+90s)
         ├─ SP4 告警时序: CRITICAL恢复 (T+5s)
```

### 5.4 各面板状态同步验证

#### SP1 DEP健康面板

| 时间点 | 期望状态 | 实际状态 | 延迟 | 校验 |
|--------|----------|----------|------|------|
| T+0s | ACTIVE | ACTIVE | 0s | ✅ |
| T+10s | BLOCKED | BLOCKED | 10s | ✅ |
| T+30s | BLOCKED | BLOCKED | 20s | ✅ |
| T+60s | RECOVERY | RECOVERY | 0s | ✅ |
| T+90s | RECOVERED | RECOVERED | 30s | ✅ |

DEP健康子面板状态机 (5态):
- ACTIVE: DEP正常, HTTP 200, 熔断器RECOVERED
- BLOCKED: DEP异常, HTTP 500, 熔断器OPEN
- FALLBACK: 使用历史快照兜底
- RECOVERY: DEP恢复中, HTTP 200, 熔断器RECOVERY
