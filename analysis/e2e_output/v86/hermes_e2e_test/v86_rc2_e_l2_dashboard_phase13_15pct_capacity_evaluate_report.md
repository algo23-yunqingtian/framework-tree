### 3.2 15%流量预估模型

```
预估公式:
  15%流量 = 5%流量 × 3 (流量放大系数)
  但数据采集频率不变 (每5分钟), 数据点数不变 (288/天/指标)
  变化的是事件量(QPS/事件数)和查询负载
  
  采集负载 = f(采集频率) × 指标数 = 不变 (1x)
  查询负载 = f(事件量) × 面板数 = 3x (线性增长)
  渲染负载 = f(数据量) × 面板数 = 3x (线性增长)
  存储负载 = f(事件量) × 存储系数 = 3x (线性增长)
```
