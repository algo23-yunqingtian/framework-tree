### 3.2 漂移分类标准

| 类别 | 标准 | 判定条件 | 示例 |
|------|------|---------|------|
| 正常波动 | 偏差≤±10%, 无持续趋势 | 波动后回到基线附近 | 渲染P99在196-220ms间波动 |
| 轻微漂移 | 偏差>±10%, 持续3天+ | 缓慢偏离基线但幅度小 | CPU +1.2%缓慢上升 |
| 显著漂移 | 偏差>±20%, 持续7天+ | 明显偏离基线 | 无 |
| 系统性漂移 | 偏差持续增大, 线性趋势 | 持续单向变化 | 无 |

### 3.3 漂移量化方法

| 方法 | 公式 | 用途 |
|------|------|------|
| 绝对偏差 | Δ = (实测值 - 基线值) / 基线值 × 100% | 偏差幅度计算 |
| 7天移动平均 | MA7 = Σ(Day[i-6]~Day[i]) / 7 | 平滑短期波动 |
| 30天移动平均 | MA30 = Σ(Day[i-29]~Day[i]) / 30 | 趋势识别 |
| 线性回归斜率 | β = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)² | 系统性漂移判定 |
| 线性度R² | R² = 1 - SS_res/SS_tot | 趋势可靠性评估 |
| 波动系数 | CV = σ/μ × 100% | 波动幅度评估 |
