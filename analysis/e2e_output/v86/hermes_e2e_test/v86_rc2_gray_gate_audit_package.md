```
灰度 Gate 评审
│
├── G-01~G-03（PREP 基础）

│   ├── 有缓解计划 → 有条件通过
│   └── 无缓解计划 → ⚠️ 需专项评审
│
├── G-05~G-08（投产就绪）
│   ├── 全满足 → 🟢 灰度上线通过
│   ├── ≥3 项满足 → 🟡 有条件灰度（缩小范围）
│   └── <3 项满足 → 🔴 不通过，延期
│
└── 灰度上线
    ├── 灰度期 7 天观测无异常 → 🟢 全量上线
    └── 触发回滚条件 → L1/L2/L3 回滚
```
