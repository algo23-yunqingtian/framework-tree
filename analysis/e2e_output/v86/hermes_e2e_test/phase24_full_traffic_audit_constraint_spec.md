## 3. 索引 vacuum 周期

### 3.1 触发条件

| 条件 | 动作 | 优先级 |
|------|------|--------|
| 膨胀 > 8.0%（WARN） | 评估 vacuum 时机 | 中 |
| 膨胀 > 8.5% | 立即执行 vacuum | 高 |
| 膨胀 > 9.0% | 紧急 vacuum + 降速 50% | 高 |
| 膨胀 > 10.0%（CRITICAL） | 紧急 vacuum + 回滚至 30% | 紧急 |
| 定期（预防性） | 每 30 天评估一次 | 中 |

### 3.2 Vacuum 执行流程

1. 确认膨胀率超过触发条件
2. DSHB 暂停流量写入（降速至 30%）
3. 执行索引 vacuum / rebuild
4. 确认膨胀率重置至 7.8% 以下
5. DSHB 恢复流量
6. 记录 vacuum 事件 + 前后膨胀率对比
7. **首次 vacuum 后重新校准膨胀模型**（vacuum 后增长模式可能变化）

### 3.3 Vacuum 后预期

| 维度 | vacuum 前 | vacuum 后 |
|------|----------|----------|
| 膨胀率 | ~8.x% | ~7.8% |
| 索引 P99 | ~6.5ms | ~5.0ms |
| 日均增量 | ~0.033pp | 重新校准 |

## 4. 风险触发干预动作

### 4.1 降级干预矩阵

| 膨胀率 | 当前动作 | 吞吐影响 | 恢复条件 |
|--------|---------|---------|---------|
| < 8.0% | 正常运行 | 无 | — |
| 8.0% ~ 8.5% | 监控+评估 vacuum | 无 | vacuum 后 <7.8% |
| 8.5% ~ 9.0% | vacuum + 降速 50% | ~420 ev/s | vacuum 后 <7.8% |
| 9.0% ~ 10.0% | 紧急 vacuum + 降速 30% | ~250 ev/s | vacuum 后 <7.8% |
| ≥ 10.0% | 回滚至 30% + 紧急 vacuum | ~250 ev/s | vacuum 后 <7.8% + 复审 |

### 4.2 性能干预矩阵

| 指标 | WARN | CRITICAL | 动作 |
|------|------|----------|------|
| WAL P99 | >1500ms | >2000ms | 降速至 75% / 回滚至 50% |
| 索引 P99 | >8ms | >10ms | 评估 vacuum / 降速至 50% |
| 丢包率 | >0.01% | >0.05% | 降速 / 回滚 |
| 链断裂 | >0 | — | 立即回滚 |
| 去重率 | <100% | — | 排查去重逻辑 |

## 6. 应急处置流程

### 6.1 索引膨胀 CRITICAL

```
触发: 膨胀率 ≥ 10.0%
1. DSHB 立即回滚至 30% 流量
2. 执行紧急索引 vacuum
3. 通知值班运维
4. 确认膨胀率 < 9.0%
5. 评估恢复 50% 流量
6. 复审审计 → Gate 重审
```

### 6.2 链断裂 > 0

```
触发: chain_broken > 0
1. 立即停止流量写入
2. 排查 seq 序列断裂原因
3. 修复断裂事件
4. 三方对账验证完整性
5. Gate 重审 → 确认 chain=0
```

### 6.3 三方对账偏差超阈值

```
触发: 任一窗口事件偏差 > 0.5%
1. 冻结当前窗口数据
2. 逐条比对 HERMES/DSHB/DSHE 事件
3. 定位偏差来源（计数/去重/丢失）
4. 修正偏差
5. 重跑对账验证
```
