## 1. RV-07 现状

### 1.1 DSHB 预案定义（V1.2）

| 阈值档位 | 原值（V1.2） | 说明 |
|---------|-------------|------|
| 警告线 | 40% | 触发观察，不阻断 |

来源：`analysis/e2e_output/v86/dshb_gate_prod_fix/v86_rc2_dshb_g1_index_prod_plan_revised_v1.2.md` 第 83 行。

### 1.2 调整背景

DSHB V1.2 预案将原 20/25/30% 上调至 40/45/50%，理由："3 索引基线 38.2%，需提高阈值"。

## 2. 生产实测数据（Phase8 三源校准）

### 2.1 膨胀率三源对比

| 数据源 | 样本规模 | 膨胀率 | 落区 |
|--------|---------|--------|------|
| HERMES 沙箱 | 500 万行合成 | 38.63% | ✅ 警告线以下 |
| DSHE 生产 | 117 万行真实 | **46.9%** | ⚠️ **严重区间**（45~50%） |
| 72h 趋势 | 1,194,312 事件 | 46.9% → 41.3% | **微降**（CV=0.0035） |

### 2.2 膨胀率落在严重区间的根因

- **3 核心索引**（idx_trace + idx_fault + idx_sev_ts）存储开销为基线表的 **46.9%**
- 生产 117 万行真实数据基数分布不同于沙箱合成数据（run_id 基数更大 → B-Tree 页填充率不同）
- skill 教训验证："绝对量不可跨规模/分布外推"——沙箱 38.63% 不可外推到生产

### 2.3 微降趋势分析

72h 观测显示膨胀率从 46.9% → 41.3%（降幅 5.6 个百分点），与 §7.9.1「索引边际成本随规模递减」结论一致：
- 随事件累积，B-Tree 页填充率饱和，新事件增量存储成本递减
- CV=0.0035 表明波动极小，趋势稳定
- 预计 7 天后降至 ~38%（回到警告线以下）

## 3. 阈值调整评估

### 3.1 建议方案

| 阈值档位 | 原值（V1.2） | **建议值** | 理由 |
|---------|-------------|-----------|------|
| 警告线 | 40% | **40%（不变）** | 生产 41.3% 已接近，保持观察灵敏度 |
| **严重线** | **45%** | **48%** | 生产首即 46.9% 落严重区间，但 72h 微降证明非异常；48% 给 3 个百分点安全余量 |
| 熔断线 | 50% | **50%（不变）** | 50% 为物理上限回滚红线，不变 |

### 3.2 评估结论

| 维度 | 判定 |
|------|------|
| 建议来源 | Phase8 B-16（commit `1cd3815`，已归档追溯规范 v1.5 §7.9） |
| 数据支撑 | 三源实测（沙箱+生产+72h 趋势），样本充分 |
| 趋势验证 | 72h 微降 46.9%→41.3%，CV=0.0035，稳定 |
| 风险等级 | P2（阈值偏紧，非阻断；72h 趋势向好） |
| DSHB/DSHE 采纳 | ❌ **未采纳**（B-16 在 DSHB/DSHE Phase9-14 文档中 0 次出现） |
| StageC 20% 影响 | 20% 灰度流量下事件增长率更低，膨胀率预计维持微降趋势 |

### 3.3 不调整的后果

- 生产首日即落严重区间 → DSHB 预案要求"触发告警，需评估是否回滚"
- 若 DSHB 按预案严格执行 → **可能误触发回滚**，导致 3 核心索引被回滚，审计链路检索退化 248~383×
- 72h 趋势证明非异常 → 严重线 45% 过于保守

## 4. 审计建议

1. **DSHB 预案 V1.2 → V1.3**：将 RV-07 严重线从 45% 调整为 **48%**，与生产实测基线对齐
2. **保持 B-02 不关闭**：索引膨胀风险持续监控，72h 观测窗口延长至 7 天
3. **熔断线 50% 不变**：物理红线，不可放松
4. **StageC 20% 灰度阶段**：膨胀率预计 42~45%，落在新严重线 48% 以下，不会误触发
