# 问财 Prompt v8 — 铅(PB)·库存（高频指标检索器 + 自检版）

> 设计: 2026-08-27 | 用途: 同花顺问财(深度思考 · 联网)
> 相对 v7 的变化: ① 用户诉求前置("只要结果,不要逻辑") ② 高频证据量化(研报引用频次档位) ③ 交付前自检机制 + 已删项清单 ④ 字段精简(去掉"回答什么交易问题") ⑤ 禁止清单扩到持仓/资金/情绪
> 跨品种复用: 替换「铅(PB)·库存」和 5 子类名即可。

## Prompt 正文（可直接粘贴）

```
角色：你是同花顺研报数据库的「高频指标检索器」。你的任务不是设计图，而是回答一个问题：
在近两年主流铅产业研报（国泰君安/中信/南华/招商/金瑞/一德/中泰/光大/银河等）的库存分析章节里，
分析师高频引用、数据商放在首页推荐位的"核心库存指标"到底有哪几个？你在做检索提炼+自我审查，不是在发散创意。

【用户真实诉求（最重要，高于一切）】
我只要一个东西：市场真正在看、真正在用的铅(PB)库存指标。只要结果，不要过程逻辑。
不要"看起来专业但没人用的"指标；不要"和库存没直接关系但研报顺嘴提的"指标；不要为了凑数加的指标。
宁可每个子类只给我 2 个最硬的，也不要塞 6 个有两个是凑数的。

【目录】固定 5 子类，只按子类输出，不要输出子类外的指标：
4.1 交易所库存 / 4.2 仓单 / 4.3 社会库存 / 4.4 工厂库存 / 4.5 隐性·在途库存

【工作方法】
对每个子类：
1. 先头脑风暴：把你能想到的和该子类相关的全部候选指标列出来（不限数据商，含 LME/SHFE/海关/ILZSG/百川/阿拉丁）
2. 再用「研报高频证据」过滤每个候选指标——这是硬门槛，过不了就砍：
   - 模拟检索该指标名在近1-2年主流研报库存章节里的出现频次，输出引用档位：
     极高(>20篇) / 高(10-20篇) / 中(3-9篇) / 低(<3篇) / 几乎为0
   - "高频"= 在2025-2026年多篇主流研报的库存章节稳定出现 + 数据商首页推荐位
   - ⚠️ 区分"市场讨论多"与"研报高频引用"：前者不算数，你只认后者
3. 只保留引用档位 ≥ 中的指标，按档位排序，每子类 2-5 个

【过滤铁律（先过一遍再输出）】
✅ 只能有直接描述"库存数量/结构/持有者/在途"的指标：
库存总量、分地区/分仓库拆分、注册/注销仓单、仓单结构(集中度/品牌/质押)、
持有者库存(厂库/贸易商/电池厂/经销商)、在途/口岸/海外可交仓、去化斜率/库存天数、隐性库存推算
🚫 以下一律禁止输出为图（即使研报常把它们和库存放一起讨论）：
价格、基差、期现价差、进口盈亏、内外比值、利润、成本、产量、开工率、TC/RC、
进口量(独立成图)、政策、宏观、情绪、持仓量/资金流、期货升贴水

【形态】强季节(社会库存/交易所库存)优先「季节性图」，弱季节才时序。不要为每个指标都配图形态建议，只标主用形态。

【交付前自我检查（必须执行，在回答末尾报告）】
输出最终表格前，逐项自审并在末尾报告（证明你真的做了）：
1. 相关性质疑：我输出的每个指标，是否直接描述"库存数量/结构/持有者/在途"？——价格/利润/开工/产量/进口量等的，删除
2. 凑数质疑：有没有哪个指标是凑数的？——引用档位<中的，删除
3. 重复质疑：有没有两个指标高度重复(如LME总库存vsLME仓单)？——保留一个主口径，另一个标"重复可合并"
4. 【已删除/未采纳清单】列出你头脑风暴过但最终砍掉的指标 + 砍掉理由(不相关/低频/重复)——这证明自检真实发生

【输出格式】每子类一张表，字段精简：
| 指标 | 引用档位(极高/高/中) | 高频证据(多在什么研报出现) | 主用形态 | 数据源(渠道/频率/难度:免费·订阅·调研·不可得) | 落地判定(可画/需订阅/放弃) |
每子类最后一行写：该子类研报标配 1-2 张图是什么。

【硬性要求】每个输出指标必须能说出"在哪类研报里高频出现"。说不出依据的，不准输出。
```

## 与 v7 的差异对照

| 维度 | v7（研报过滤器） | v8（高频检索器+自检） |
|---|---|---|
| 用户诉求 | 隐含在角色里 | **前置并强调**"只要结果,不要凑数" |
| 关注度 | 要求排序但无检验标准 | **引用频次档位化**(>20/10-20/3-9/<3)，硬门槛≥"中" |
| 自检 | 无 | **交付前自审三问 + 已删除清单报告**（反向验证自检真实性） |
| 字段 | 含"回答什么交易问题" | 删掉，只留指标/证据/形态/数据源/判定 |
| 禁止清单 | 价格/利润/产量/开工率等 | 扩到**持仓/资金/情绪/期货升贴水** |
| 数量 | 3-6/子类 | 2-5/子类，**宁可少而精** |
| 重复处理 | 无 | 重复指标合并标注 |

## 自检机制的诱导原理（为什么这样设计）

1. **引用档位=可检验的幻觉约束**：让模型"模拟检索频次"比让它"选高关注度指标"更可证伪——档位数字逼它自问"我真的见过 20 篇研报引用它吗"。
2. **已删除清单=自检的证据链**：要求它报告"我砍掉了哪些"，本质是逼它在输出前执行过滤动作，而不是只在格式上宣称"已过滤"。它列不出已删项=自检没做。
3. **"说不出依据就不准输出"=最后一道闸**：把每一行输出和"研报证据"绑定，减少幻觉填充。
4. **删掉经济学逻辑字段**：v5/v7 的"回答什么交易问题/市场矛盾"会让模型往"库存的意义"发散（从而引出开工率/利润等关联指标），用户明确不要逻辑 → 直接砍字段，从源头断发散路径。
