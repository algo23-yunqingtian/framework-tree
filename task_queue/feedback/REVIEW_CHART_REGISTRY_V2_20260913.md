### ③ chart_dual 消歧 ⚠️ 部分通过

**代码已修**（`scripts/chart_kits.py`，+420 字节）：

```python
def disambig_title(mid_a, name_a, mid_b, name_b):
    # 过滤：完全相同的 mid = 无意义自身对比
    if mid_a == mid_b:
        return None  # 调用方应跳过
    ...
```

三级兜底：`mid_a==mid_b` 返回 None → `_origin` 关键词标签 → `mid` 后缀 → "左轴/右轴"。✅ 设计正确。

**⚠️ 待二次修复：存量 62 张 A-vs-A 图仍在 HTML 中**

实测分支全部 HTML 的 `chart-title`，`A vs A` 自比图仍为 **62 条**（与修复前完全一致，零减少）：


**根因**：`disambig_title` 是**生成期**函数，只对新跑 build 的页面生效；未重新执行 `scripts/build_*.py` 的存量页面不受影响。

**建议**：批量重跑受影响页面的 build 脚本（涉及 AL/CU/LI/NI 等约 20 个页面），或在 build 脚本加"跳过返回 None 的 chart_dual"断言。
